sample_description: The study used three types of biological samples: (i) 22 human urine samples, (ii) 19 beer samples, and (iii) fecal (stool) samples. For urine, 5 μL was extracted with 200 μL of chloroform/methanol/water (1:3:1 v/v/v) at 4 °C, vortexed for 5 min at 4 °C, centrifuged at 13,000 g for 3 min at 4 °C, and the supernatant stored at −80 °C. For fecal samples, stool material was freeze-dried, and 5 mg of lyophilized material was extracted in 200 μL of chloroform/methanol/water (1:3:1) at 4 °C, homogenized using a FastPrep-24 homogenizer for 60 s at stroke setting 5, then vortexed, centrifuged, and processed identically to urine. All samples were analyzed via LC–MS/MS using HILIC chromatography and Orbitrap-based detection.
software_configuration_description: The MS2LDA+ model is an extension of standard Latent Dirichlet Allocation (LDA) designed for mass spectrometry fragmentation data, where a single shared set of Mass2Motifs (topics) is inferred across multiple samples. It employs a Variational Bayes inference scheme in which each sample is modeled with standard MS2LDA, but motif updates are pooled across all samples. The model outputs Mass2Motifs (collections of co-occurring fragment ions and neutral losses) and per-sample prevalence vectors α_f, where each element α_k^f represents the proportion of total feature intensity in sample f explained by Mass2Motif k. The implementation includes two complementary linking scores: (1) Mass2Motif–molecule probability (proportion of a molecule’s spectrum explained by the Mass2Motif), and (2) overlap score (proportion of the Mass2Motif present in the molecule’s spectrum, i.e., how many Mass2Motif fragments/losses are observed). The model enforces that every MS2 spectrum is assigned to at least one Mass2Motif. The software implementation is available on GitHub (https://github.com/sdrogers/lda); no specific version or command-line parameters are stated, but inference details are described in Supporting Information section S4. Input data consisted of .mzXML (full-scan) and .mzML (fragmentation) files preprocessed with XCMS, MzMatch, and RMassBank for peak detection, MS1–MS2 pairing, and alignment.

software_configuration_description: MS2LDA is implemented using variational inference in NumPy/SciPy, as in the original publication. Users can specify two key algorithm parameters via the web interface: the number of Mass2Motifs to infer and the number of iterations for the variational inference algorithm. Fragment and neutral loss features are extracted from mzML (and other supported) files using pymzML. The resulting feature matrix is decomposed into Mass2Motifs (co-occurring fragment/neutral loss patterns), and results are stored in PostgreSQL. The implementation uses Django for the web framework and Celery for asynchronous job execution.
source_paper: Joe et al. (2018), Bioinformatics (Oxford, England), DOI: 10.1093/bioinformatics/btx582, PMID: 28968802
