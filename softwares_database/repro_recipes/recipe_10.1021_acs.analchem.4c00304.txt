  Step 1: Mass spectrum preprocessing and peak detection
    tool: Custom Python pipeline

    parameters: snr_threshold=3, min_distance=5
    input: Raw .imzML files
    output: Peak lists (m/z, intensity, spatial coordinates)
    confidence: low
  Step 2: Generation of augmented training data
    tool: Custom Python script
    algorithm: Self-supervised data augmentation: synthetic mass shifts + noise injection
    parameters: shift_range_ppm=[-100, 100], noise_std=0.05, augmentation_factor=10
    input: Observed m/z values from reference spectra
    output: Augmented spectral pairs (original m/z, shifted m/z)
    confidence: medium
  Step 3: Neural network training for mass shift estimation
    tool: PyTorch
    algorithm: Convolutional neural network (CNN) with residual connections
    parameters: learning_rate=0.001, batch_size=64, epochs=100, loss_function=MAE
    input: Augmented spectral pairs
    output: Trained MassShiftNet model (mass shift predictor)
    confidence: high
  Step 4: Mass recalibration of MSI spectra
    tool: MassShiftNet (inference mode)
    algorithm: Per-spectrum m/z correction using predicted shift
    parameters: interpolation_method=linear, calibration_window_size=100
    input: Raw .imzML spectra
    output: Recalibrated .imzML spectra (corrected m/z axis)
    confidence: medium
  Step 5: Evaluation of recalibration performance
    tool: Custom Python evaluation script
    algorithm: Absolute mass error (ppm) and relative alignment score computation
    parameters: reference_peaks_file=peptide_theoretical_masses.csv, tolerance_ppm=5
    input: Recalibrated spectra + theoretical peptide masses
    output: Quantitative metrics (mean absolute error, alignment score)
    confidence: high
