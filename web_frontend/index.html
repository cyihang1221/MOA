      在下拉框中选择图例系列，再用颜色块修改该系列颜色；可拖动标题和图例位置。

      模型 API 设置

      可选用自己的 OpenAI 兼容 API。Key 仅保存在本机浏览器，不会写入服务器数据库；请求时临时发给后端调用模型，错误信息会脱敏。

      样本 metadata

      编辑 metadata.csv：至少包含 Sample（样本名）与 Group（分组）。保存后将在 PCA、mixOmics 等分析中用于着色与分组比较。

      描述你想修改的内容，例如：标题改为「PCA 分组比较」，Control 用 #4DBBD5，Case 用 #E64B35，标题字号 20。

      文献作图参考

      描述要调整的拼图样式，例如：标签改成小写、标签字号 36、不要标签、改成 3 列。

      合并图片

      点击缩略图选择/取消图片，再点「自动排版」。
