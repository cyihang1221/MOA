Prospective isolates were limited to ~10 per species to ensure broad taxonomic diversity, while retrospective isolates supplemented coverage of less common pathogens. All isolates were cultured on appropriate media—Columbia agar with 7% sheep blood, chocolate agar with PolyViteX, and MacConkey II agar—at 35–37°C for 18–24 h (aerobes) or 24–48 h (anaerobes). Quality control strains included Escherichia coli ATCC 8739 (calibrator for VMP), Klebsiella aerogenes ATCC 13048 (positive control for VMP), and IVD Bacterial Test Standard (BTS) for BS.
complete_workflow_description: The study compared two MALDI-TOF MS systems: VITEK MS PRIME (VMP) and MALDI Biotyper Sirius (BS). For VMP: sample preparation used the VITEK PICKME pen; 1.0 µL of CHCA matrix (50% acetonitrile, 2.5% trifluoroacetic acid) was applied per spot; for yeasts, 0.5 µL of 25% formic acid was added prior to matrix. Daily calibration used E. coli ATCC 8739 spotted in three designated positions on VITEK MS-DS; each acquisition group included a calibrator spot. Positive control: K. aerogenes ATCC 13048; negative control: 1.0 µL matrix only. Identification used VMP Software Version 1.1.2 with IVD Knowledge Base V3.2; confidence thresholds: ≥99.9% (high-confidence), 60–99.8% (low discrimination), <60% (no identification); unidentified isolates were re-analyzed once in IVD mode, then once in RUO mode if still unresolved. For BS: colonies were directly smeared using a single-use loop onto MBT Biotarget 96 plates; 1.0 µL of IVD HCCA-matrix applied per spot; for yeasts, 1.0 µL of 70% formic acid was applied before matrix. Calibration used IVD Bacterial Test Standard (BTS) per target. Identification used BS Software Version 5.2.300, Server Version 4.1.100, and MBT Compass Library 2023; log score thresholds: ≥2.0 (high-confidence), 1.7–1.99 (low-confidence), <1.7 (no identification). Workflow analysis measured hands-on time (HOT) and time-to-result (TTR) across 16 target slides (16 spots each = 256 isolates/system), simulating routine lab workflow; steps included slide preparation (scanning/naming spots for VMP vs. BTS spotting and colony smearing for BS), drying time (with parallel slide preparation allowed), loading (VMP LOAD&GO carrier vs. manual slide info entry and BTS validation in BS software), system run (automated measurement timing), and issue handling (VMP: entire run fails if ATCC calibrator fails; BS: BTS spot can be re-dropped and slide reloaded, with reloading time added). Statistical analysis used chi-square test (GraphPad Prism v10.0); significance threshold: P < 0.05. Discrepant identifications were resolved via NGS (Illumina NovaSeq 9000 PE150) and Sanger sequencing (16S-rDNA, tuf, rpoB, gyrB genes) performed by BaseClear B.V., followed by FastANI v1.33 comparison against 53,836 NCBI reference genomes (bacteria, complete/chromosome assembly level, excluding atypical).

========== paper_workflow entry 2 ==========
related_tool: SIRIUS
sample_description: The study utilized the Tox21 Data Challenge dataset (12,699 instances), cleaned to retain 7,691 unique compounds based on the first 14 characters of their InChIKey. From this, a subset of 4,274 compounds with available positive-mode LC/ESI/HRMS MS² spectra was compiled into the 'MS² dataset' by aggregating spectra from MassBank Europe (v06.2024), MoNA (August 2024, downloaded 17.08.2024), GNPS (downloaded 25.07.2024), and NIST (HRMS 2023). Spectra were cleaned, averaged across all reported collision energies, and processed using matchms (v3.11.8) with 0.2 Da peak matching tolerance. The MS² dataset was split via anticlustering into a 3K training set (3,413 compounds, 80%) and a test set (861 compounds, 20%), ensuring no overlap with compounds used to train SIRIUS+CSI:FingerID (v5.8.6). A separate 7K training set (6,830 compounds) disjoint from the test set was also compiled for extended model training. Wastewater influent and effluent samples were stored at −20 °C, filtered (0.45-µm syringe filter), mixed with methanol (20% final concentration), and analyzed via LC/ESI/HRMS on a Q Exactive Orbitrap in positive mode using data-dependent acquisition (top5 + 176 NORMAN suspect list contaminants). Features were processed with MS-DIAL (v5.3.240719) and prioritized based on intensity changes (±20% for persistence; ≥50% increase for transformation products).
complete_workflow_description: Three assay endpoint prediction approaches were implemented: (1) MN-MS² (unsupervised molecular networking): MS² spectral similarity networks were constructed using three metrics—CosineGreedy() and ModifiedCosine() from matchms (v3.11.8, 0.2 Da tolerance) and MS2DeepScore (Siamese neural network trained on RDKit Daylight 2048-bit Tanimoto similarity, per GitHub instructions); similarity thresholds (0.0–0.9, 0.1 increments) and edge filtering (top-6 vs. all-above-threshold) were optimized; voting schemes included majority voting (Eq. 1) and weighted voting (Eq. 2); performance evaluated via modified ROC-AUC (mTPR/mFPR accounting for unconnected positives/negatives, Eqs. 3–4). (2) Conformal Prediction (CP): Mondrian CP framework (v38) applied post-hoc to a Random Forest (RF) base model using MS2DeepScore similarities to all training compounds as features; calibration set drawn randomly from training data; significance levels tested from 0.15 to 0.30. (3) MS2Tox models: XGBoost classifiers trained in Python 3.11.9 using SIRIUS+CSI:FingerID v5.8.6 fingerprints; hyperparameter optimization via Optuna (v3.6.1) with RandomSampler over 500 trials and 5-fold stratified cross-validation; feature cleaning removed zero/near-zero-variance and highly correlated fingerprint bits; two variants trained—MS2Tox-3K (3,413 compounds) and MS2Tox-7K (6,830 compounds). All models evaluated using FPR@TPR=0.5 and FPR@TPR=0.9 for toxicity-based feature prioritization.

========== paper_workflow entry 3 ==========
related_tool: SIRIUS
sample_description: The sample used in the research consists of tandem mass spectrometry (MS/MS) data compiled from multiple public and internal sources: NIST20, NIST23, MoNA, GNPS, Agilent PCDL, and an internal dataset. The internal dataset was generated by acquiring 1424 compounds from APExBIO and measuring their MS/MS spectra using a Waters Synapt G2 mass spectrometer at 40 eV collision energy, covering diverse precursor ion types including [M+H]+, [M+Na]+, [2M+H]+, [M+2H]2+, and [M−H]−. To reduce environmental interference (e.g., H2O and CO2), peaks below m/z 50 were excluded. Additionally, three community benchmarking datasets—CASMI 2016, CASMI 2017, and EMBL-MCF 2.0—were incorporated. All spectra underwent rigorous filtering: (1) exclusion of spectra with fewer than five peaks; (2) restriction of m/z range to (0, 1500]; (3) retention only of molecules composed of common atoms (C, H, O, N, F, S, Cl, P, B, I, Br, Na, K); (4) inclusion only of spectra associated with specified common precursor types across positive and negative modes (e.g., [M+H]+, [M+Na]+, [M−H]−, [2M+2H]2+, [M+2H]2+, and adducts involving neutral losses like H2O, NH3, CH2O2, CH4O2); (5) capping total atom count at 300 to focus on small molecules; and (6) enforcing strict precursor mass tolerance (10 ppm for Q-TOF, 5 ppm for Orbitrap instruments). Instrument-specific metadata is provided in Table 2, listing Q-TOF instruments (Agilent 6530/6545/6550, Waters Xevo G2) and Orbitrap instruments (Thermo Elite, Q Exactive HF/Plus). Precursor m/z values from theoretical sources (NIST20/23, CASMI) were simulated with Gaussian-distributed random shifts (σ = 1/3 × tolerance) to reflect real instrument error distributions. Precursor types were simplified by incorporating neutral losses (e.g., NH3, H2O, CO2, CH2O2, CH4O2) into the molecular formula—e.g., C6H12N2O2 with [M+H+NH3]+ becomes C6H15N3O2 with [M+H]+—enabling consolidation of rare precursor types into common ones while preserving reversibility. Training/test splits were performed by canonical SMILES to ensure no compound overlap (including stereoisomers), using either random splitting or reserving NIST23 compounds for evaluation. Data augmentation applied Gaussian noise (N(0, 0.1)) to Q-TOF intensities (generating two augmented spectra per original, tripling Q-TOF training size), validated by cosine similarity (0.936 vs. replicate similarity 0.977); no augmentation was applied to Orbitrap due to sufficient training size and poor noise robustness observed.
complete_workflow_description: The research employed a deep learning framework named FIDDLE, implemented in PyTorch 1.13.1, comprising two main models: (1) a formula prediction model and (2) a confidence score prediction model. The formula prediction model uses a two-stage representation learning architecture: first, MS/MS embedding via dilated convolutional blocks (kernel sizes: 45, 43, 41, 39, 37, 35; dilation factors: 1, 2, 4, 8, 8, 8) with ReLU, dropout, residual connections, and max-pooling (kernel=2, stride=2), achieving an effective receptive field (ERF) of 1153; second, elimination of experimental condition effects by concatenating the 1024-dimensional global-pooled MS/MS feature with 16-dimensional embeddings of precursor type, normalized collision energy, and simulated precursor m/z, followed by sequential linear layers. Training uses contrastive loss (Lc) with margin m=1.0 to pull together spectra from the same molecule and push apart those from different molecules, plus three auxiliary MSE losses (atom count, molecular mass, H/C ratio) weighted at 0.01, 1.0, and 10.0 respectively. Training was conducted for 200 epochs with batch size 512, initial learning rate 0.001, AdamW optimizer, and ReduceLROnPlateau scheduler (patience=5). Hardware: two NVIDIA RTX A6000 GPUs (48 GB each). The confidence score model takes concatenated condition-independent MS/MS features and predicted formula embeddings as input, processes them through five linear layers (dimensions: 416→208→104→26→13) with batch normalization, ReLU, dropout, and final sigmoid activation to output a 0–1 confidence score. Its training data comprises top-5 refined candidates from the formula refinement algorithm, labeled as correct (0) or incorrect (1), subsampled to ≤10,000 instances to prevent overfitting. The candidate formula refinement algorithm (Algorithm 1) starts from an initial formula (e.g., from FIDDLE, SIRIUS, or BUDDY), iteratively edits heavy atom counts (±1) while adjusting hydrogens to match target precursor mass within tolerance ΔM, enforces SENIOR chemical validity rules, tracks visited formulas, limits search depth Dmax, and returns up to K valid candidates. The open-source Python package 'msfiddle' was released with optimized GPU/CPU inference pipelines and standardized APIs. BUDDY v0.3.6 (PyPI, Jan 29th, 2024) was installed from https://github.com/Philipbear/msbuddy and run under identical hardware/software conditions as SIRIUS for benchmark comparison.

All MATLAB-based analyses used custom scripts.

========== paper_workflow entry 8 ==========
related_tool: SIRIUS
sample_description: The study used 24,025 all-cause mortality data sources, including 28,652 location-years of vital registration (VR) data (3,726 new location-years across all age groups compared to GBD 2021), 1,644 location-years of sample VR data, and 5,208 other sources (355 new surveys, 15 new censuses, and 2,213 other new sources). Additional data included 532 location-years from 38 INDEPTH Health and Demographic Surveillance System (HDSS) sites across 15 countries—mostly in sub-Saharan Africa—and 8,754 location-years of VR data with all-age death counts. Data were sourced via systematic search of government websites, statistical annuals, demographic compendia, large-scale surveys, and collaborator input; metadata and citations are available via the GBD 2023 Sources Tool in the Global Health Data Exchange (GHDx). Age-specific mortality rates were derived from complete birth histories (for ages <15 years), summary birth histories (using a new age-sex splitting algorithm), sibling survival histories (for ages 15–49 years), and VR data (with a new age-sex splitting algorithm applied to aggregate VR age groups). Data for ages 15–19 and 20–24 from complete birth histories, and for ages 50–54 and 55–59 from sibling survival histories, were excluded due to downward bias and sparse availability.
complete_workflow_description: The study employed the novel OneMod tool—a unified, stagewise statistical model for estimating all-cause mortality—to produce estimates across location, age, sex, and time (1950–2023) using both parametric and non-parametric components. OneMod comprises two main stages: (1) SpXMod—a generalized linear modelling tool implementing stage-wise regression with correlated, dimension-specific intercepts and covariate coefficients—using five covariates: Socio-demographic Index (SDI), HIV mortality rate (zero before 1981), age-standardized COVID-19 mortality rate (zero before 2020), island binary indicator, and an all-risk-factor summary covariate (population attributable fraction for all risk factors combined, available only from 1990 onward). SpXMod operates in four stages: stage 1 fits a global age-specific covariate model with age- and location-specific intercepts; stage 2 uses those results as an offset to fit super-region- and age-specific trends and intercepts; stage 3 adds country-specific and age-specific intercepts; and stage 4 (for subnational locations) adds subnational intercepts. A custom splicing step combines models fitted for 1950–onward and 1990–onward datasets. (2) KReg—a Kronecker-factored multivariate kernel regression model—applies non-parametric smoothing to SpXMod residuals across age, time, and location dimensions using kernel methods, starting from the parametric fit and leveraging correlations encoded in the overall likelihood. Binomial likelihood is used throughout. Preprocessing includes compactification techniques to ensure binomial parameters remain <1 (especially for neonatal and oldest age groups) and weight adjustments to account for non-sampling variation. Uncertainty propagation uses 1000 Monte Carlo draws per location-year-sex combination; calibration ensures scaled Pearson residuals have unit variance at chosen geographical granularity. Final outputs include single-year-age life tables incorporating fatal discontinuities (sex- and age-redistributed by cause), abridged life tables for standard GBD age groups, life expectancy at birth, and final mortality envelopes. Software used includes Python (v3.10.4), Stata (v15.1), and R (v4.2 and v4.4); code is publicly available. Expected SDI-based mortality was estimated separately using MR-BRT (meta-regression–Bayesian, regularised, trimmed) with cubic B-splines (five knots between 0–1, enforced linearity at extremes) and an ensemble of >50 randomly knot-placed models per age-sex group.

(6) The burden-of-proof meta-regression framework was used for relative risk estimation, incorporating ensemble spline models for non-linear risk–outcome relationships, robust likelihood-based outlier trimming, covariate selection/adjustment for study design characteristics, and quantification of between-study heterogeneity; (8) All statistical code is publicly available; (9) DALYs were calculated as the sum of YLDs (prevalence × disability weights, adjusted for comorbidity multiplicatively) and YLLs (deaths × standard life expectancy at age of death); (10) HALE (healthy life expectancy) was computed using Sullivan’s method with YLDs per capita and age-specific mortality rates; (11) Risk-attributable burden was estimated using the comparative risk assessment framework, computing population attributable fractions (PAFs) from exposure, relative risk, and theoretical minimum risk exposure level (TMREL), with mediation adjustments via a 2023-specific mediation matrix (165 mediated pairs); (12) Uncertainty was propagated throughout using 250 draws from the ensemble posterior distribution.

The initial formula prediction is then refined using a breadth-first algorithm that adjusts atom counts to satisfy SENIOR rules and match the observed precursor mass within instrument-specific mass tolerances (10 ppm for Q-TOF, 5 ppm for Orbitrap), generating up to k=5 candidate formulas. Finally, an auxiliary deep learning model estimates confidence scores for each candidate using the learned spectral features and candidate formula representations, and candidates are ranked by these scores. This full pipeline — from spectrum binning and deep encoding, through formula prediction, rule- and mass-constrained refinement, to confidence-scoring and ranking — constitutes a self-contained, reproducible workflow for formula identification.
