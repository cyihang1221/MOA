  Step 2: Retention time correction using endoRI
    tool: Custom R/Python script

    parameters: reference_acylcarnitines=['C0', 'C2', 'C4', 'C6', 'C8', 'C10', 'C12', 'C14', 'C16', 'C18', 'C20', 'C22', 'C24', 'C26'], interpolation_method=linear
    input: Feature table with uncorrected t_R and m/z
    output: Feature table with endoRI-corrected t_R
    confidence: medium
  Step 3: Quantitative prediction of missing acylcarnitine t_R
    tool: Custom R/Python script
    algorithm: Linear regression model (t_R ~ L_C) applied to predict t_R for absent acylcarnitines
    parameters: model_form=log10(t_R) = a * L_C + b, prediction_scope=C0–C26
    input: Acylcarnitine presence/absence matrix + calibration parameters
    output: Predicted t_R values for missing acylcarnitines
    confidence: medium
