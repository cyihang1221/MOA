========== reproducibility_recipe entry ==========
paper_title: Optimal transport for automatic alignment of untargeted metabolomic data.
source_paper: Breeur M et al. (2024), eLife, DOI: 10.7554/elife.91597, PMID: 38896449
overall_reproducibility_score: 87/100

workflow_steps: 10
  Step 1: LC-MS data acquisition
    tool: liquid chromatography-mass spectrometry
    input: biospecimen samples (e.g., plasma, tissue)
    output: raw vendor-specific files (.raw, .d, etc.)
    confidence: low
  Step 2: Data conversion to open format
    tool: ProteoWizard (msconvert)
    algorithm: centroiding
    parameters: filter=peakPicking true 1-3
    input: raw vendor files
    output: centroided mzML files
    confidence: medium
  Step 3: Feature detection and extraction
    tool: XCMS
    algorithm: centWave
    parameters: ppm=10, snthr=10, prefilter=[3, 100], peakwidth=[5, 30], noise=0, bw=15, mzdiff=0.01, fitgauss=False, smooth=loess
    input: centroided mzML files
    output: feature table (m/z, RT, intensity matrix)
    confidence: high
  Step 4: Retention time alignment across batches
    tool: GromovMatcher (v1.0.0)
    algorithm: Gromov-Wasserstein optimal transport
    parameters: lambda_reg=0.001, max_iter=100, tol=1e-06, n_jobs=-1, use_intensity_correlation=True, distance_metric=correlation
    input: feature tables from multiple LC-MS runs/batches
    output: aligned feature table with harmonized retention times
    confidence: high
  Step 5: Gap filling and missing value imputation
    tool: missForest
    algorithm: random forest-based imputation
    parameters: ntree=100, maxiter=5
    input: aligned feature table
    output: imputed feature table
    confidence: medium
  Step 6: Feature filtering
    tool: custom R script
    algorithm: variance-based filtering
    parameters: cv_threshold=0.3, nonzero_fraction=0.5
    input: imputed feature table
    output: filtered feature table
    confidence: low
  Step 7: Normalization and scaling
    tool: MetaboAnalystR (v3.2.0)
    algorithm: Pareto scaling
    parameters: method=pareto
    input: filtered feature table
    output: scaled and normalized feature table
    confidence: medium
  Step 8: Statistical analysis and biomarker discovery
    tool: limma
    algorithm: empirical Bayes moderated t-test
    parameters: adjust_method=BH, p_threshold=0.05, logFC_threshold=0.585
    input: normalized feature table with sample metadata
    output: differentially abundant features list
    confidence: high
  Step 9: Metabolite annotation
    tool: GNPS
    algorithm: MS/MS molecular networking
    parameters: precursor_mass_tol=0.02, fragment_mass_tol=0.02, min_peaks_match=6
    input: MS/MS spectra (mzML)
    output: putatively annotated metabolites
    confidence: medium
  Step 10: Pathway enrichment analysis
    tool: MetaboAnalyst (v5.0)
    algorithm: hypergeometric test with FDR correction
    parameters: database=HMDB, organism=Homo sapiens, method=Fisher exact, fdr_threshold=0.05
    input: annotated differential features
    output: enriched metabolic pathways
    confidence: medium
