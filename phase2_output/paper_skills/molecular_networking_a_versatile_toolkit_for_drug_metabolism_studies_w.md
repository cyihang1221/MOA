## Pipeline Coverage（含软件参数）

| Step | Task | Tool | Algorithm | Parameters |
|------|------|------|-----------|------------|
| 1 | Feature-based molecular networking (FBMN) | GNPS2 | FBMN | `mass_tolerance_ppm=10, retention_time_tolerance_sec=30, min_peak_intensity=1000, min_matched_peaks=6, top_k_best_matches=10, cosine_score_threshold=0.7` |
| 2 | Time-course metabolite quantification and visualization | GNPS Dashboard | XIC extraction and box plot generation | `x_ic_mz_tolerance_ppm=20, x_ic_rt_tolerance_sec=30, integration_method=peak area, normalization=internal_standard_or_total_ion_current` |
| 3 | In silico metabolite structure prediction and annotation | ChemWalker + Biotransformer 3.0 (v3.0) | biotransformation rule-based prediction + MS/MS spectral matching | `biotransformation_rules=['oxidation', 'glucuronidation', 'dealkylation', 'hydrolysis'], max_transformations=3, ms_ms_similarity_threshold=0.65, fragmentation_model=CFM-ID 4.0` |
| 4 | Modification site localization using spectral interpretation | ModiFinder | likelihood-based modification site scoring from MS/MS | `site_likelihood_threshold=0.3, fragment_ion_coverage_min=0.6, neutral_loss_filtering=True` |
| 5 | Metabolite identification via spectral library search and cross-dataset matching | Fast MASST + Metabolomics USI | massive spectral similarity search (cosine) across GNPS libraries | `cosine_score_threshold=0.6, min_matched_peaks=4, library_match_mode=global, usi_search_scope=public_metabolomics_libraries` |
