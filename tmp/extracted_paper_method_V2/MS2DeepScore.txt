sample_description: The sample used in the research consists of LC–MS/MS-derived MS/MS spectral data, specifically in .mgf (Mascot Generic Format) format. Each spectral entry must contain a unique feature identifier, a precursor mass-to-charge ratio (m/z), and spectral data represented as one or more tuples of mass-to-charge ratio and corresponding intensity values. The input data are assumed to have undergone prior LC–MS/MS preprocessing—including feature detection and MS/MS spectral exporting—using external tools such as MZMine3, to reduce dataset size and minimize feature redundancy. No specific biological or chemical origin of the samples is explicitly stated beyond the illustrative use of 'wheat data' in the Results section and dashboard overview (Figure 1).
software_configuration_description: MS2DeepScore is employed as the primary similarity metric for computing pairwise spectral similarities within specXplore. It is integrated via the open-source Python package 'ms2deepscore' (citation 10). Pretrained models are not custom-trained but are instead obtained from and used as provided by MS2Query (citation 14). The MS2DeepScore similarity matrix serves as the input distance matrix for t-SNE embedding—the central overview visualization—and no additional configuration parameters (e.g., model architecture, training epochs, or fine-tuning settings) are specified in the text; usage is default and model-based, relying on the prepackaged inference pipeline of ms2deepscore. The t-SNE embedding itself uses the MS2DeepScore matrix as its dissimilarity input, with users able to tune the perplexity parameter interactively in the range of 5 to 50.
