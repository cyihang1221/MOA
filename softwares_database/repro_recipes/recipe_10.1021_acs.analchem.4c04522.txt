paper_title: Integrating FT-ICR MS and Machine Learning to Forecast Acid Content Across Boiling Cuts.

overall_reproducibility_score: 42/100

workflow_steps: 8
  Step 1: FT-ICR MS data acquisition
    tool: FT-ICR MS
    input: crude oil samples (neat or solvent-diluted)
    output: raw mass spectra (.fid or vendor-specific format)
    confidence: low
  Step 2: Spectral processing and peak detection
    tool: DataAnalysis or Composer (Bruker)
    algorithm: peak picking with S/N threshold, calibration, apodization
    parameters: snr_threshold=4, calibration_points=5
    input: raw .fid files
    output: peak list (m/z, intensity, retention equivalent)
    confidence: medium
  Step 3: Molecular formula assignment
    tool: Bruker DataAnalysis or Formularity
    algorithm: elemental composition assignment using mass accuracy < 1 ppm and isotope pattern matching
    parameters: mass_tolerance_ppm=1, elements_allowed=['C', 'H', 'N', 'O', 'S', 'P'], max_degree_unsaturation=20
    input: peak list
    output: molecular formula table (m/z, CxHyNzOw, DBE, class)
    confidence: medium
  Step 4: Compound class annotation and heteroatom-based grouping
    tool: in-house scripts or DataAnalysis reports
    algorithm: class assignment by heteroatom count (e.g., O1, O2, N1O1, etc.) and double bond equivalent (DBE) filtering
    parameters: min_dbe=0, max_dbe=20, exclude_radicals=True
    input: molecular formula table
    output: compound class abundance table (sample × class)
    confidence: low
  Step 5: TAN measurement
    tool: ASTM D664 potentiometric titration (vASTM D664-22)
    parameters: titrant=KOH in isopropanol, endpoint_detection=potentiometric
    input: TBP distillation cuts
    output: TAN (mg KOH/g)
    confidence: high
  Step 6: Predictive modeling (PLS regression)
    tool: MATLAB or Python (scikit-learn)
    algorithm: Partial Least Squares (PLS) regression
    parameters: n_components=8, scaling=UV, cross_validation_folds=5
    input: compound class abundance table, TAN values
    output: PLS model (coefficients, RMSEC, Rc)
    confidence: medium
  Step 7: Ordered predictor selection (OPS)
    tool: custom implementation
    algorithm: sequential addition of compound classes based on PLS coefficient magnitude and cross-validated RMSE reduction
    parameters: max_predictors=20, selection_criterion=RMSECV
    input: PLS model + feature importance
    output: optimized feature subset and final predictive model
    confidence: low
  Step 8: Volcano plot generation
    tool: R (ggplot2) or Python (matplotlib/seaborn)
    algorithm: log2-fold-change vs −log10(p-value) from univariate correlation (Pearson/Spearman) between class abundance and TAN
    parameters: p_value_threshold=0.05, fold_change_threshold=1.5
    input: compound class abundance table, TAN values
    output: volcano plot (highlighted molecular classes)
    confidence: medium
