========== sample_description&software_configuration_description entry ==========
sample_description: MRC5 primary human fibroblasts were metabolically labeled by switching to DMEM medium containing 25 mM 13C6-glucose for either 5 or 60 minutes. After incubation, the medium was aspirated, cells were rapidly washed with ice-cold PBS, and intracellular metabolites were extracted using a cold solvent mixture of 50:30:20 methanol/acetonitrile/water. Samples were prepared in biological triplicates for subsequent LC-MS analysis.
software_configuration_description: AssayR uses a tab-separated values (.tsv) configuration file specifying for each metabolite of interest: (1) its nominal m/z value, (2) a retention time (RT) window (minimum and maximum RT), (3) the maximum number of isotopologues to analyze—separately configurable for 13C, 15N, and 2H labels, including combinations thereof (e.g., 13C/15N dual-labeled species), (4) the width of the peak detection filter in seconds (not peak width, but the temporal width parameter for the Mexican hat convolution filter), (5) an intensity threshold for peak detection, and (6) an 'interactive' flag enabling or disabling user-guided iterative peak picking per metabolite. Default values include broad initial RT windows and conservative filter widths; during interactive curation, parameters—including m/z tolerance (ppm), filter width ('seconds'), and intensity threshold—are dynamically updated and saved back to the config file (e.g., from 'Initial' to 'Final' config as shown in Figure 2). Isotopologue selection is numeric (e.g., '6' for all six 13C atoms incorporated) and supports combinatorial labeling (e.g., '13C2,15N1').
