paper_title: mixOmics: An R package for 'omics feature selection and multiple data integration
source_paper: Rohart F et al. (2017), PLoS Computational Biology, DOI: 10.1371/journal.pcbi.1005752, PMID: 29099853
overall_reproducibility_score: 88/100

workflow_steps: 8
  Step 1: Data preprocessing and filtering
    tool: mixOmics
    algorithm: near-zero variance removal, Median Absolute Deviation (MAD) filtering
    parameters: max_predictors_per_dataset=10000
    input: raw 'omics data matrices (e.g., gene expression, metabolite intensities, count data)
    output: filtered and normalized data matrix X (N × P), dummy indicator matrix Y (N × K)
    confidence: medium
  Step 2: Unsupervised dimension reduction and exploration
    tool: mixOmics
    algorithm: PCA (NIPALS for missing values), ICA, rCCA, rGCCA
    input: filtered and normalized data matrix X
    output: latent component scores (t1,…,tH), loadings (a1,…,aH), explained variance
    confidence: high
  Step 3: Supervised multivariate modeling
    tool: mixOmics
    algorithm: PLS-DA, sparse PLS-DA (sPLS-DA), GCC-DA, multi-group PLS-DA
    parameters: ncomp=K−1 recommended, keepX=user-defined grid of features to select per component
    input: filtered X and dummy indicator matrix Y
    output: discriminant latent components, class predictions, classification performance metrics
    confidence: high
  Step 4: Parameter tuning via cross-validation
    tool: mixOmics
    algorithm: repeated stratified cross-validation (10×5-fold), Leave-One-Group-Out (LOGO)
    parameters: measure=Balanced Error Rate (BER) or overall misclassification error, distance=['maximum', 'Centroid', 'Mahalanobis']
    input: training data (X, Y)
    output: optimal ncomp and keepX values, tuned model object
    confidence: high
  Step 5: Feature selection and molecular signature identification
    tool: mixOmics
    algorithm: ℓ1 regularisation (LASSO) via soft-thresholding (keepX parameter)
    parameters: keepX=grid-specified number of top features per component
    input: tuned sPLS-DA or sGCCA model
    output: selected feature subsets per component (e.g., genes, metabolites), relevance networks, clustered image maps
    confidence: high
  Step 6: Multi-'omics integration (N-integration)
    tool: mixOmics
    algorithm: DIABLO (Discriminant Integration Analysis with Bias Learning Optimization)
    parameters: ncomp=K−1, keepX=per-data-set grid, weight_mode=majority vote or weighted vote (correlation-based)
    input: multiple matched 'omics matrices (same N samples, different platforms)
    output: integrated sample scores, multi-omics signature, Circos correlation plot
    confidence: high
  Step 7: Multi-'omics integration (P-integration)
    tool: mixOmics
    algorithm: MINT (Multiple Independent ‘omics Data Integration)
    parameters: ncomp=2, cv=Leave-One-Group-Out, distance=maximum, measure=BER
    input: multiple independent studies (same P features, different N samples)
    output: consensus signature, global sample plot, per-study performance
    confidence: high
  Step 8: Classification prediction and distance-based inference
    tool: mixOmics
    algorithm: prediction using maximum / Centroid / Mahalanobis distance on latent scores or dummy variables
    parameters: distance=['maximum', 'Centroid', 'Mahalanobis']
    input: tuned model + new test set (X_test)
    output: predicted class labels, prediction confidence areas, per-class error rates
    confidence: high
