    confidence: high
  Step 2: Cumulative neutral loss (CNL) spectrum representation
    tool: Custom Julia implementation
    algorithm: Cumulative neutral losses from MS2 spectra
    parameters: min_mz=10.0, max_mz=500.0, bin_width=1.0
    input: MS2 spectra (centroided, m/z and intensity)
    output: binned cumulative neutral loss profile (vector)
    confidence: medium
  Step 3: Ionization efficiency (logIE) prediction modeling
    tool: Julia MLJ.jl framework
    algorithm: Random forest regression
    parameters: n_trees=100, max_depth=15, min_samples_split=2
    input: molecular fingerprint vector OR CNL vector
    output: predicted logIE value
    confidence: medium
  Step 4: Model evaluation
    tool: Custom Julia script
    algorithm: Hold-out test set validation
    parameters: test_fraction=0.2, metric=RMSE
    input: predicted vs. experimentally measured logIE
    output: RMSE, R², scatter plots
    confidence: high
