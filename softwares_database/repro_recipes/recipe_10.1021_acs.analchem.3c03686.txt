========== reproducibility_recipe entry ==========
paper_title: Systematic Evaluation of Chromatographic Peak Quality for Targeted Mass Spectrometry via Variational Autoencoder.
source_paper: Yang C et al. (2024), Analytical chemistry, DOI: 10.1021/acs.analchem.3c03686, PMID: 38336364
overall_reproducibility_score: 58/100

workflow_steps: 6
  Step 1: Data collection and preprocessing
    tool: Skyline
    algorithm: manual export
    parameters: export_format=chromatogram_and_peak_boundary_csv
    input: Skyline .sky files
    output: chromatogram CSV + peak boundary CSV
    confidence: high
  Step 2: Quality feature extraction
    tool: TargetedMSQC-derived metrics
    algorithm: 47-feature computation from 32 quality metrics
    parameters: aspects=['jaggedness', 'symmetry', 'similarity', 'modality', 'shift', 'full_width_at_half_maximum', 'area_ratio', 'intensity', 'retention_time'], levels=['transition', 'transition_pair', 'isotope', 'peak_group'], type_I_features=17, type_II_features=22, type_III_features=8
    input: chromatogram + peak boundary CSV
    output: quality feature vectors (type I, II, III)
    confidence: high
  Step 3: Latent space encoding via variational autoencoder
    tool: β-TCVAE
    algorithm: beta-tuned conditional variational autoencoder
    parameters: latent_dimensions=2, minibatch_size=10000, initial_learning_rate=0.001, final_learning_rate=1e-06, epochs=40, convergence_criterion=loss_stabilization
    input: quality feature vectors (type I, II, III)
    output: 2D latent embeddings per quality type
    confidence: medium
  Step 4: Reference point annotation and scoring function definition
    tool: custom Python implementation
    algorithm: Euclidean distance-based weighted scoring
    parameters: reference_points_count=5, reference_point_labels=['best', '70%_best', 'light_worst_heavy_best', 'light_best_heavy_best', 'worst'], weights=[2, 1, 1, -1, -2], distance_normalization=d_max = distance(best, worst), score_normalization=min_max_to_range(-10, 10)
    input: 2D latent embeddings
    output: TMSQE scores (type I, II, III)
    confidence: high
  Step 5: Quality categorization guideline derivation
    tool: empirical distribution analysis
    algorithm: multimodal thresholding
    parameters: categories=['poor', 'acceptable', 'good'], thresholds=determined from bimodal/multimodal score distributions (Fig 4)
    input: TMSQE scores (type I, II, III)
    output: quality classification labels
    confidence: medium
  Step 6: Cross-dataset evaluation and compatibility adaptation
    tool: automRm
    algorithm: virtual heavy-light pairing
    parameters: filtering_criteria=molecules with 13C-labeled standards only, pairing_method=artificial replication of heavy signal, feature_robustness_assumption=PeakGroupRatioCorr impact tolerated
    input: automRm output (HILIC/RP metabolite data)
    output: TMSQE-evaluated peak quality labels
    confidence: medium
