</div></section></section><section aria-label="Article content"><section class="body main-article-body"><section class="abstract" id="abstract1"><h2>Abstract</h2>
<section id="s1"><h3 class="pmc_sec_title">Motivation</h3>
<p>Testing for pathway enrichment is an important aspect in the analysis of untargeted metabolomics data. Due to the unique characteristics of untargeted metabolomics data, some key issues have not been fully addressed in existing pathway testing algorithms: (i) matching uncertainty between data features and metabolites; (ii) lacking of method to analyze positive mode and negative mode liquid chromatography–mass spectrometry (LC/MS) data simultaneously on the same set of subjects; (iii) the incompleteness of pathways in individual software packages.</p></section><section id="s2"><h3 class="pmc_sec_title">Results</h3>
<p>We developed an innovative R/Bioconductor package: <em>meta</em>bolic pathway testing with <em>po</em>sitive and <em>ne</em>gative mode data (metapone), which can perform two novel statistical tests that take matching uncertainty into consideration—(i) a weighted gene set enrichment analysis-type test and (ii) a permutation-based weighted hypergeometric test. The package is capable of combining positive- and negative-ion mode results in a single testing scheme. For comprehensiveness, the built-in pathways were manually curated from three sources: Kyoto Encyclopedia of Genes and Genomes, Mummichog and The Small Molecule Pathway Database.</p></section><section id="s3"><h3 class="pmc_sec_title">Availability and implementation</h3>
<p>The package is available at <a href="https://bioconductor.org/packages/devel/bioc/html/metapone.html" class="usa-link usa-link--external" data-ga-action="click_feat_suppl" target="_blank" rel="noopener noreferrer">https://bioconductor.org/packages/devel/bioc/html/metapone.html</a>.</p></section><section id="s5"><h3 class="pmc_sec_title">Supplementary information</h3>
<p>
<a href="#sup1" class="usa-link">Supplementary data</a> are available at <em>Bioinformatics</em> online.</p></section></section><section id="sec5"><h2 class="pmc_sec_title">1 Introduction</h2>
<p>Untargeted metabolomics, which measures of abundance of small molecules in an unbiased manner, is gaining wider applications in biomedical research (<a href="#btac364-B8" class="usa-link" aria-describedby="btac364-B8">Jacob <em>et al.</em>, 2019</a>). Pathway testing is a critical step in data interpretation for untargeted metabolomics data. Many works have been done on metabolic pathway testing, but there is no consensus on the best approach (<a href="#btac364-B9" class="usa-link" aria-describedby="btac364-B9">Karnovsky and Li, 2020</a>). The current leading methods, e.g. Mummichog and MetaboAnalyst (<a href="#btac364-B4" class="usa-link" aria-describedby="btac364-B4">Chong <em>et al.</em>, 2018</a>; <a href="#btac364-B12" class="usa-link" aria-describedby="btac364-B12">Li <em>et al.</em>, 2013</a>), use incomplete pathway information. More importantly, pathway testing is hampered by matching uncertainty between extracted features from LC/MS data and known metabolites, as possible correspondences are largely identified by comparison of feature <em>m</em>/<em>z</em> values and the theoretical <em>m</em>/<em>z</em> values of common adduct ions of known metabolites, and many metabolites share the same molecular composition. Furthermore, when multiple adduct ions are considered, the issue becomes more complicated. Although efforts were made to annotate LC/MS data features to known metabolites in a more reliable manner, currently the majority of features are matched with uncertainty, i.e. a feature could potentially be derived from multiple metabolites (<a href="#btac364-B2" class="usa-link" aria-describedby="btac364-B2">Chaleckis <em>et al.</em>, 2019</a>; <a href="#btac364-B11" class="usa-link" aria-describedby="btac364-B11">Kuhl <em>et al.</em>, 2012</a>; <a href="#btac364-B17" class="usa-link" aria-describedby="btac364-B17">Uppal <em>et al.</em>, 2017</a>). This uncertainty heavily impacts pathway testing, as in many cases, we cannot be sure a differentially abundant feature is truly derived from a certain pathway.</p>
<p>Some methods use extra information in pathway testing, such as methods for longitudinal metabolomics data (<a href="#btac364-B5" class="usa-link" aria-describedby="btac364-B5">Ebrahimpoor <em>et al.</em>, 2021</a>), matching features to metabolites by utilizing the similarity of MS2 in reaction-paired neighborhood (<a href="#btac364-B14" class="usa-link" aria-describedby="btac364-B14">Shen <em>et al.</em>, 2019</a>), and combining feature matching with predictive modeling (<a href="#btac364-B1" class="usa-link" aria-describedby="btac364-B1">Cai <em>et al.</em>, 2017</a>). However, for untargeted data collected using the most common case–control study design, such methods are not suitable. And since not all matched metabolites can be found in the known metabolic network, some information may be lost when using network-based methods. Therefore, a method that can be widely used with relatively complete pathway information is urgently needed.</p>
<p>In this work, we developed an R/Bioconductor package named ‘Metapone’. It facilitates pathway testing by making improvements in three areas:
</p>
<ol class="list" style="list-style-type:decimal">
<li><p>We developed two novel tests to address the matching uncertainty issue. The first follows the concept of gene set enrichment analysis (GSEA) (<a href="#btac364-B16" class="usa-link" aria-describedby="btac364-B16">Subramanian et al., 2005</a>), but uses weighted features or metabolites based on multiple-matching status. The second is a permutation-based weighted hypergeometric test which also accounts for matching uncertainty.</p></li>
<li><p>We compiled pathways from three established database sources by computationally removing (partial) overlaps—Kyoto Encyclopedia of Genes and Genomes (KEGG) (<a href="#btac364-B13" class="usa-link" aria-describedby="btac364-B13">Ogata et al., 1998</a>), Mummichog (<a href="#btac364-B12" class="usa-link" aria-describedby="btac364-B12">Li et al., 2013</a>) and The Small Molecule Pathway Database (SMPDB) (<a href="#btac364-B7" class="usa-link" aria-describedby="btac364-B7">Frolkis et al., 2010</a>).</p></li>
<li><p>Metapone can jointly analyze positive- and negative-ion mode data produced in the same study, which can help avoid double counting and to generate a more integrated and comprehensive view of metabolic perturbations.</p></li>
</ol></section><section id="sec6"><h2 class="pmc_sec_title">2 Materials and methods</h2>
<section id="sec7"><h3 class="pmc_sec_title">2.1 Combining pathways from different databases</h3>
<p>All metabolites were mapped using the human metabolome database (HMDB) IDs. We first collected all pathways from the three established sources. Then between any pair of pathways, if the number of overlapping metabolites is <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE1"><math id="IM1" display="inline" overflow="linebreak"><mo>≥</mo><mn>75</mn><mi mathvariant="normal">%</mi></math></span> of the size of both pathways, we removed the pathway with smaller number of metabolites. A total of 372 pathways were included in the Metapone package.</p></section><section id="sec8"><h3 class="pmc_sec_title">2.2 Testing procedures</h3>
<p>Metapone can use data from a single-ion mode, and it can also handle the case of jointly testing both positive- and negative-ion mode data. In the joint analysis scenario, data from the two ion modes are first individually mapped to HMDB metabolites based on the listed of allowed adduct ions, which the user can select. We then combine the feature-metabolite matching from both modes in the pathway testing. Metapone allows two approaches for pathway testing.</p>
<p>
<em>(1) Weighted GSEA test.</em>
</p>
<p>This is a modified GSEA-type test based on Fast Gene Set Enrichment Analysis (fgsea) approach (<a href="#btac364-B10" class="usa-link" aria-describedby="btac364-B10">Korotkevich <em>et al.</em>, 2021</a>), using weighted features/metabolites. The features are denoted as <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE2"><math id="IM2" display="inline" overflow="linebreak"><msub><mrow><mi>f</mi></mrow><mrow><mn>1</mn></mrow></msub><mo>,</mo><msub><mrow><mi>f</mi></mrow><mrow><mn>2</mn></mrow></msub><mo>,</mo><mo>…</mo><mo>,</mo><mi mathvariant="normal"> </mi><msub><mrow><mi>f</mi></mrow><mrow><mi>M</mi></mrow></msub></math></span>, the metabolites as <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE3"><math id="IM3" display="inline" overflow="linebreak"><msub><mrow><mi>m</mi></mrow><mrow><mn>1</mn></mrow></msub><mo>,</mo><msub><mrow><mi>m</mi></mrow><mrow><mn>2</mn></mrow></msub><mo>,</mo><mo>…</mo><mo>,</mo><mi mathvariant="normal"> </mi><msub><mrow><mi>m</mi></mrow><mrow><mi>K</mi></mrow></msub></math></span>, the potential matching between features and metabolites as <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE4"><math id="IM4" display="inline" overflow="linebreak"><mi>A</mi><mo>∈</mo><msup><mrow><mi mathvariant="double-struck">R</mi></mrow><mrow><mi>M</mi><mo>×</mo><mi>K</mi></mrow></msup></math></span>, where <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE5"><math id="IM5" display="inline" overflow="linebreak"><msub><mrow><mi>A</mi></mrow><mrow><mi>i</mi><mi>j</mi></mrow></msub><mo>=</mo><mn>1</mn></math></span> if there is potential matching between <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE6"><math id="IM6" display="inline" overflow="linebreak"><msub><mrow><mi>f</mi></mrow><mrow><mi>i</mi></mrow></msub></math></span> and <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE7"><math id="IM7" display="inline" overflow="linebreak"><msub><mrow><mi>m</mi></mrow><mrow><mi>j</mi></mrow></msub></math></span>, and 0 otherwise. For feature <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE8"><math id="IM8" display="inline" overflow="linebreak"><mi>i</mi></math></span>, we define the feature weight as:
</p>
<table class="disp-formula p" id="E1"><tr><td class="formula"><math id="M1" display="block" overflow="linebreak"><mrow><msub><mi>w</mi><mi>i</mi></msub><mo>=</mo><mn>1</mn><mo>/</mo><msup><mrow><mrow><mo stretchy="true">[</mo><mrow><mtext>min</mtext><mrow><mo stretchy="true">(</mo><mrow><munderover><mstyle mathsize="140%" displaystyle="true"><mo>∑</mo></mstyle><mrow><mi>j</mi><mo>=</mo><mn>1</mn></mrow><mi>K</mi></munderover><msub><mi>A</mi><mrow><mi>i</mi><mi>j</mi></mrow></msub><mo>,</mo><mi>b</mi></mrow><mo stretchy="true">)</mo></mrow></mrow><mo stretchy="true">]</mo></mrow></mrow><mi>d</mi></msup><mo>,</mo></mrow></math></td></tr></table>
<p>where <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE9"><math id="IM9" display="inline" overflow="linebreak"><mi>b</mi></math></span> is a cap of the number of matchings to a feature to limit the penalty, and <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE10"><math id="IM10" display="inline" overflow="linebreak"><mi>d</mi></math></span> is the power term which tunes the penalty on multiple matching. The recommended range for parameter <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE11"><math id="IM11" display="inline" overflow="linebreak"><mi>d</mi></math></span> is between 0 and 1, with a default value of 0.5. The higher the value of <em>d</em>, the higher the penalty on multiply matched features. Users can adjust the parameters according to the scope of matchings and specific task requirements.</p>
<p>We then take steps to limit the total contribution of a single feature/metabolite. If a feature is connected to too many metabolites such that <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE12"><math id="IM12" display="inline" overflow="linebreak"><msub><mrow><mi>w</mi></mrow><mrow><mi>i</mi></mrow></msub><mrow><msubsup><mo stretchy="false">∑</mo><mrow><mi>t</mi><mo>=</mo><mn>1</mn></mrow><mrow><mi>k</mi></mrow></msubsup><mrow><msub><mrow><mi>A</mi></mrow><mrow><mi>i</mi><mi>t</mi></mrow></msub></mrow></mrow><mo>&gt;</mo><mn>2</mn></math></span>, we limit its total contribution by replacing <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE13"><math id="IM13" display="inline" overflow="linebreak"><msub><mrow><mi>w</mi></mrow><mrow><mi>i</mi></mrow></msub></math></span> with <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE14"><math id="IM14" display="inline" overflow="linebreak"><mn>2</mn><mo>/</mo><mrow><msubsup><mo stretchy="false">∑</mo><mrow><mi>t</mi><mo>=</mo><mn>1</mn></mrow><mrow><mi>k</mi></mrow></msubsup><mrow><msub><mrow><mi>A</mi></mrow><mrow><mi>i</mi><mi>t</mi></mrow></msub></mrow></mrow></math></span>. And if the total weight of a metabolite’s matched features is larger than 1, we divide each of the weights by the square-root of the total weight. The procedure avoids the weights of single metabolites being too large and dominating the pathway test.</p>
<p>For GSEA calculation, the feature importance is defined as the weighted negative log <em>P</em>-value:
</p>
<table class="disp-formula p" id="E2"><tr><td class="formula"><math id="M2" display="block" overflow="linebreak"><mrow><mtext>imp</mtext><mrow><mo>(</mo><mrow><msub><mi>f</mi><mi>i</mi></msub></mrow><mo>)</mo></mrow><mo>=</mo><mo>−</mo><mtext>log</mtext><mrow><mo>(</mo><mrow><msub><mi>p</mi><mi>i</mi></msub></mrow><mo>)</mo></mrow><mo>×</mo><msub><mi>w</mi><mi>i</mi></msub><mo>.</mo></mrow></math></td></tr></table>
<p>For metabolites <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE15"><math id="IM15" display="inline" overflow="linebreak"><mi>j</mi></math></span>, we define its importance as the sum of the importance of its associated features:
</p>
<table class="disp-formula p" id="E3"><tr><td class="formula"><math id="M3" display="block" overflow="linebreak"><mrow><mtext>imp</mtext><mrow><mo>(</mo><mrow><msub><mi>m</mi><mi>j</mi></msub></mrow><mo>)</mo></mrow><mo>=</mo><munder><mstyle mathsize="140%" displaystyle="true"><mo>∑</mo></mstyle><mrow><mi>i</mi><mo>:</mo><mtext> </mtext><msub><mi>A</mi><mrow><mi>i</mi><mi>j</mi></mrow></msub><mo>=</mo><mn>1</mn></mrow></munder><mtext>imp</mtext><mrow><mo>(</mo><mrow><msub><mi>f</mi><mi>i</mi></msub></mrow><mo>)</mo></mrow><mo>.</mo></mrow></math></td></tr></table>
<p>In combination with pathway assignments, the importance scores of metabolites are used in <em>fgsea</em>. Alternatively, the testing can be conducted using <em>fgsea</em> with respect to features, with the relevant pathways for each feature being determined by the pathways of its matched metabolites.</p>
<p>
<em>(2) Permutation-based weighted hypergeometric test.</em>
</p>
<p>The procedure is similar to the regular hypergeometric test of gene sets in GOstats (<a href="#btac364-B6" class="usa-link" aria-describedby="btac364-B6">Falcon and Gentleman, 2007</a>). The difference is we factor the matching uncertainty into the test statistics by using <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE16"><math id="IM16" display="inline" overflow="linebreak"><msub><mrow><mi>w</mi></mrow><mrow><mi>i</mi></mrow></msub></math></span> as the fractional counts of feature <em>i</em>. For each pathway, we first find the total fractional counts of significant features assigned to pathway <em>k</em>:
</p>
<table class="disp-formula p" id="E4"><tr><td class="formula"><math id="M4" display="block" overflow="linebreak"><mrow><msub><mi>C</mi><mi>k</mi></msub><mo>=</mo><munder><mstyle mathsize="140%" displaystyle="true"><mo>∑</mo></mstyle><mrow><mi>i</mi><mo>:</mo><mtext> </mtext><msub><mi>f</mi><mi>i</mi></msub><mtext> </mtext><mo>∈</mo><msub><mrow><mtext> Φ</mtext></mrow><mi>k</mi></msub></mrow></munder><msub><mi>w</mi><mi>i</mi></msub><mo>×</mo><mi>I</mi><mrow><mo>(</mo><mrow><msub><mi>p</mi><mi>i</mi></msub><mtext> </mtext><mo>≤</mo><mtext> </mtext><mi>δ</mi></mrow><mo>)</mo></mrow><mo>,</mo></mrow></math></td></tr></table>
<p>where <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE17"><math id="IM17" display="inline" overflow="linebreak"><msub><mrow><mi mathvariant="normal">Φ</mi></mrow><mrow><mi>k</mi></mrow></msub></math></span> denotes the collection of features associated with pathway <em>k</em> through their matched metabolites, <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE18"><math id="IM18" display="inline" overflow="linebreak"><mo>δ</mo></math></span> denotes the <em>P</em>-value threshold, and <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE19"><math id="IM19" display="inline" overflow="linebreak"><mi>I</mi><mo>(</mo><mo>)</mo></math></span> is the identity function. To assign pathway significance, we use a permutation test. In the <em>n</em>th permutation, we permute the original feature <em>P</em>-values, and calculate the total fractional counts of significant features <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE20"><math id="IM20" display="inline" overflow="linebreak"><msubsup><mrow><mi>C</mi></mrow><mrow><mi>k</mi></mrow><mrow><mo>(</mo><mi>n</mi><mo>)</mo></mrow></msubsup></math></span>. After <em>N</em> permutations, we assign the pathway <em>P</em>-value by <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE21"><math id="IM21" display="inline" overflow="linebreak"><mrow><mrow><mrow><msubsup><mo stretchy="false">∑</mo><mrow><mi>n</mi><mo>=</mo><mn>1</mn></mrow><mrow><mi>N</mi></mrow></msubsup><mrow><mi>I</mi><mo>(</mo><msub><mrow><mi>C</mi></mrow><mrow><mi>k</mi></mrow></msub><mo>≤</mo><msubsup><mrow><mi>C</mi></mrow><mrow><mi>k</mi></mrow><mrow><mo>(</mo><mi>n</mi><mo>)</mo></mrow></msubsup><mo>)</mo></mrow></mrow></mrow><mo>/</mo><mrow><mi>N</mi></mrow></mrow></math></span>.</p>
<p>Following either testing procedure, the pathway-level <em>P</em>-values are then transformed to local false discovery rate and cumulative false discovery rate (<a href="#btac364-B15" class="usa-link" aria-describedby="btac364-B15">Strimmer, 2008</a>). The output contains a table of pathway testing results and a list of the mapped significant features in each pathway.</p></section></section><section id="sec9"><h2 class="pmc_sec_title">3 Example analysis using metapone</h2>
<p>As an illustration, we performed metapone analysis on data from the Metabolome Atlas of the Aging Mouse Brain (ST001888) dataset downloaded from the Metabolomics Workbench (<a href="https://www.metabolomicsworkbench.org/data/DRCCMetadata.php?Mode=Study&amp;StudyID=ST001888" class="usa-link usa-link--external" data-ga-action="click_feat_suppl" target="_blank" rel="noopener noreferrer">https://www.metabolomicsworkbench.org/data/DRCCMetadata.php?Mode=Study&amp;StudyID=ST001888</a>). The F-test results of metabolites between prime-age and aging mice were used. Using weighted hypergeometric test with 2000 permutations and parameters <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE22"><math id="IM22" display="inline" overflow="linebreak"><mi>b</mi></math></span>, <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE23"><math id="IM23" display="inline" overflow="linebreak"><mi>d</mi></math></span> set to 10 and 0.5, we obtained 9 pathways with <em>P</em>-value <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE24"><math id="IM24" display="inline" overflow="linebreak"><mo>≤</mo><mn>0.05</mn></math></span> and the weighted number of significant metabolites <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE25"><math id="IM25" display="inline" overflow="linebreak"><mo>≥</mo><mn>1.5</mn></math></span> (<a href="#btac364-F1" class="usa-link">Fig. 1a</a>). The majority of the selected pathways were associated important lipid species in the brain. The remaining pathways include retinol metabolism, which is known to be critical to the nervous system development, and pentose glucuronate interconversions, which was linked to Alzheimer’s disease in gene expression analysis (<a href="#btac364-B3" class="usa-link" aria-describedby="btac364-B3">Chen <em>et al.</em>, 2016</a>). We also conducted pathway testing using only positive- (<a href="#btac364-F1" class="usa-link">Fig. 1b</a>) or negative- (<a href="#btac364-F1" class="usa-link">Fig. 1c</a>) ion mode data, using the same criteria with <em>P</em>-value <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE26"><math id="IM26" display="inline" overflow="linebreak"><mo>≤</mo><mn>0.05</mn></math></span> and the weighted number of significant metabolites <span xmlns:mml="http://www.w3.org/1998/Math/MathML" id="IE27"><math id="IM27" display="inline" overflow="linebreak"><mo>≥</mo><mn>1.5</mn></math></span>. Less significant pathways were found by comparing both ion modes. Similar results using weighted GSEA test are shown in <a href="#sup1" class="usa-link">Supplementary Figure S1</a>. Therefore, the results indicate analyzing both ion modes data together yields higher power than analyzing individual ion mode data separately.</p>
