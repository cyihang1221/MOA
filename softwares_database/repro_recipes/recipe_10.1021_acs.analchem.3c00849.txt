workflow_steps: 4
  Step 1: Global connectivity molecular network (GCMN) construction
    tool: Custom implementation
    algorithm: Molecular fingerprint similarity
    parameters: fingerprint_type=MACCS, similarity_metric=Tanimoto
    input: Chemical structures from metabolome databases (e.g., HMDB, GNPS, LipidMaps)
    output: Global connectivity molecular network (GCMN) graph
    confidence: medium
  Step 2: Seed metabolite selection and experimental MS/MS spectral assignment
    tool: Custom implementation
    algorithm: Network annotation propagation using known metabolites as seeds
    parameters: seed_criteria=experimentally confirmed metabolites with reference MS/MS spectra
    input: Reference MS/MS spectra (e.g., GNPS library), seed metabolite identifiers
    output: Assigned 'pseudo' MS/MS spectra to neighbor metabolites in GCMN
    confidence: low
  Step 3: Pseudo-spectrum guided feature annotation
    tool: Custom implementation
    algorithm: Multi-dimensional matching (predicted RT, m/z, pseudo-MS/MS)
    parameters: rt_tolerance_sec=15, mass_tolerance_ppm=5, cosine_score_threshold=0.7
    input: Untargeted UPLC-HRMS data (feature table + MS/MS spectra), GCMN with pseudo-spectra
    output: Annotated metabolite features (level 2 identification)
    confidence: medium
  Step 4: Iterative annotation propagation
    tool: Custom implementation
    algorithm: Recursive seed expansion
    parameters: max_iterations=3, minimum_annotation_confidence=0.83
    input: Previously annotated metabolite features
    output: Expanded metabolite annotation list (increased coverage)
    confidence: low
