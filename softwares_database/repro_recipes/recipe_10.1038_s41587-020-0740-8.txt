========== reproducibility_recipe entry ==========
paper_title: Systematic classification of unknown metabolites using high-resolution fragmentation mass spectra.
source_paper: Dührkop K et al. (2021), Nature biotechnology, DOI: 10.1038/s41587-020-0740-8, PMID: 33230292
overall_reproducibility_score: 87/100

workflow_steps: 5
  Step 1: Input spectral preprocessing
    tool: CANOPUS
    algorithm: deep neural network (DNN) with heterogeneous training
    parameters: spectral_similarity_threshold=0.7, mass_tolerance_ppm=5
    input: high-resolution MS/MS spectra (e.g., from GNPS, MassBank)
    output: preprocessed spectral features (peak intensities, m/z, retention time not used)
    confidence: medium
  Step 2: Compound class prediction
    tool: CANOPUS
    algorithm: deep neural network trained on heterogeneous data (MS/MS + structural SMILES)
    parameters: num_classes=2497, ontology_source=ClassyFire ChemOnt, max_ontology_depth=11
    input: preprocessed MS/MS spectra
    output: compound class predictions with confidence scores (per ClassyFire ontology level)
    confidence: high
  Step 3: Multi-class annotation and selection
    tool: CANOPUS
    algorithm: structural pattern-based class prioritization
    parameters: priority_rule=larger structural pattern selected for single-class display
    input: multi-class prediction outputs
    output: single dominant class annotation per compound (for visualization)
    confidence: medium
  Step 4: Molecular networking
    tool: GNPS
    algorithm: cosine similarity clustering
    parameters: similarity_score_threshold=0.7, min_matched_peaks=6, fragment_mz_tolerance=0.02
    input: MS/MS spectra
    output: molecular network (nodes = spectra, edges = spectral similarity ≥ 0.7)
    confidence: high
  Step 5: Ontology-aware chemodiversity analysis
    tool: ClassyFire
    algorithm: ChemOnt ontology tree traversal
    parameters: ontology_levels_analyzed=['Kingdom', 'Superclass', 'Class', 'Subclass']
    input: CANOPUS class annotations
    output: hierarchical class distribution (e.g., % at each ChemOnt level)
    confidence: medium
