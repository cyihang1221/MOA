workflow_steps: 6
  Step 1: Data collection and characterization
    tool: Custom R scripts
    algorithm: L2-norm correlation metric
    parameters: correlation_metric_definition=L2-norm of off-diagonal, upper-triangular correlation matrix, log_information_metric=I = log10(n/p), data_set_count=60, data_types=['real', 'synthetic']
    input: Complete (no missing) data matrices
    output: Characterized data sets (ρ, n, p, I)
    confidence: high
  Step 2: Missingness induction
    tool: Custom R implementation
    algorithm: ['MCAR', 'MAR', 'NMAR']
    parameters: target_missing_fraction=γNA ∈ (0,1), MCAR_method=random uniform sampling over flattened matrix, MAR_method=column-wise missingness driven by tail behavior of randomly selected covariate using logistic link F(x) = (1 + exp(−3x))⁻¹, NMAR_method=variable-wise missingness driven by own empirical tail behavior, Bj_distribution=i.i.d. symmetric Bernoulli (0–1)
    input: Complete data matrices
    output: Partially missing data matrices (with ground truth)
    confidence: high
  Step 3: RF-based imputation
    tool: R (custom RF implementations: RFotf, RFunsv, RFprx, mForest)
    algorithm: ['On-the-fly imputation', 'Unsupervised RF splitting', 'Proximity imputation', 'missForest generalization (mForest)']
    parameters: nsplit=10, mtry=p (all features), ytry=p (for RFunsv), nodesize=1, ntree=500, mForest_alpha=[0.05, 0.25], iterations=[1, 5], iteration_behavior_note=Iteration improved accuracy except for NMAR in low/medium correlation
    input: Partially missing data matrices
    output: Imputed data matrices
    confidence: high
  Step 4: KNN imputation (benchmark)
    tool: impute.knn from R package 'impute'
    algorithm: k-nearest neighbors with Euclidean distance
    parameters: k=10, rowmax=1.0, colmax=1.0, distance_metric=Euclidean (confined to non-missing columns per row)
    input: Partially missing data matrices
    output: Imputed data matrices
    confidence: high
  Step 5: Imputation error evaluation
    tool: Custom R metrics
    algorithm: Standardized RMSE (continuous), misclassification error (categorical)
    parameters: standardized_rmse_denominator=variance of Xj over artificially missing entries, misclassification_error=fraction of mismatches among imputed categorical values, relative_imputation_error_baseline=strawman imputation (𝒮), relative_error_formula=ℰ(ℐ) / ℰ(𝒮) × 100
    input: Imputed matrices + ground truth + missingness indicators
    output: Relative imputation error (%) per variable type and dataset
    confidence: high
  Step 6: Statistical analysis and visualization
    tool: ANOVA
    algorithm: Analysis of variance
    parameters: effect_size_metric=η² (eta-squared) for log-information, replicates_per_setting=100, experimental_factors=['missingness mechanism', 'γNA', 'correlation', 'data complexity (I)']
    input: Relative imputation error results
    output: ANOVA tables, effect sizes, aggregated performance summaries
    confidence: medium
