    input: SMILES or molecular structures (COCONUT + LOTUS databases)

  Step 2: Spectral similarity computation (all-vs-all)
    tool: Custom implementation of Modified Hungarian Distance
    algorithm: Modified Hungarian Algorithm with functional-group-aware tolerance and dimensionless coordinate normalization
    parameters: sigma_H_ppm=0.01, sigma_C_ppm=0.2, f_H_ppm=0.5, f_C_ppm=2.5, edge_similarity_threshold=30, padding_strategies=['zero', 'truncation', 'nearest_neighbor']
    input: HSQC peak lists (unordered (δH, δC) pairs)
    output: pairwise spectral similarity matrix / edge list
    confidence: high
  Step 3: Structural similarity calculation
    tool: Custom hybrid metric (Tanimoto + MCS)
    algorithm: Hybrid similarity = 0.5 × (Tanimoto + Maximum Common Subgraph)
    parameters: tanimoto_fingerprint=standard RDKit Morgan fingerprint (radius=2), mcs_algorithm=VFLib or similar subgraph isomorphism solver, structural_similarity_threshold=0.6
    input: molecular structures (SMILES/InChI)
    output: pairwise structural similarity scores (Hybrid, Tanimoto, MCS)
    confidence: medium
  Step 4: HSQC molecular network construction
    tool: Custom graph construction pipeline
    algorithm: Thresholded all-vs-all similarity graph with structural edge filtering
    parameters: network_size=99719, edge_retention_threshold_mod_hungarian=30, structural_edge_filter=Hybrid > 0.6, edge_features=['Tanimoto', 'MCS', 'Hybrid']
    input: Modified Hungarian similarity matrix + structural similarity scores
    output: undirected weighted graph (GML or adjacency list)
    confidence: high
  Step 5: Annotation propagation & dereplication
    tool: Algorithmic molecular networking (graph topology–driven ranking correction)
    algorithm: Graph-based ranking refinement using topology metrics (e.g., centrality, clustering coefficient)
    parameters: ranking_correction_method=topology-aware re-ranking, false_positive_reduction_strategy=structural consistency filtering across network neighborhoods
    input: HSQC molecular network + annotated nodes (experimental spectra from HMDB/PubChem)
    output: propagated annotations, dereplicated compound clusters, improved candidate rankings
    confidence: low
