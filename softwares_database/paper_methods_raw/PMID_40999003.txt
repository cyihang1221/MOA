
Methodology
This section describes diagnostic techniques for estimating SoC,
SoH, and detecting cell-level degradation in a 15S2P LiFePO4
battery pack using real-time BMS data. The method combines
advanced Coulomb Counting, EKF, machine learning techniques,
and statistical diagnostics to create a cohesive hybrid framework.
