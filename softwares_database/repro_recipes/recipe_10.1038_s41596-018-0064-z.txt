========== reproducibility_recipe entry ==========
paper_title: A computational framework to integrate high-throughput '-omics' datasets for the identification of potential mechanistic links.
source_paper: Pedersen HK et al. (2018), Nature protocols, DOI: 10.1038/s41596-018-0064-z, PMID: 30382244
overall_reproducibility_score: 87/100

workflow_steps: 7
  Step 1: Data preprocessing and normalization
    tool: R
    algorithm: custom
    input: raw metabolomics (LC-MS) and metagenomics (shotgun sequencing) data
    output: normalized feature tables (metabolites, microbial genes, KOs, MGS)
    confidence: medium
  Step 2: Metabolite binning
    tool: R
    algorithm: hierarchical clustering + correlation-based grouping
    parameters: correlation_threshold=0.7, clustering_method=average linkage
    input: normalized metabolite abundance table
    output: binned metabolite modules
    confidence: medium
  Step 3: Microbial gene binning into MGS and functional modules
    tool: HUMAnN2 / MetaPhlAn2
    algorithm: MGS (metagenomic species) profiling + KEGG module mapping
    parameters: min_coverage=1.0, min_abundance=0.001
    input: shotgun metagenomic reads
    output: MGS abundance table and KEGG module activity scores
    confidence: low
  Step 4: Integration of prior biological knowledge
    tool: KEGG database (vKEGG release 91 (2018))
    algorithm: manual curation + module-level aggregation
    parameters: module_aggregation=sum, KO_filtering=present in ≥2 samples
    input: KO abundance table
    output: KEGG module activity matrix
    confidence: high
  Step 5: Three-pronged association analysis (phenotype–metabolome–microbiome)
    tool: R
    algorithm: multivariate linear regression with permutation testing
    parameters: n_permutations=1000, FDR_control=Benjamini-Hochberg, covariates=['age', 'sex', 'BMI']
    input: phenotype vector, binned metabolite modules, KEGG module activity matrix
    output: tripartite association scores (p-values, effect sizes)
    confidence: medium
  Step 6: Driver-species analysis via leave-one-MGS-out
    tool: R
    algorithm: iterative model refitting with MGS removal
    parameters: MGS_removal_threshold=abundance > 0.1% in ≥10% samples
    input: MGS abundance table, phenotype vector, metabolite module matrix
    output: driver-species contribution scores
    confidence: medium
  Step 7: Pathway-level mechanistic hypothesis generation
    tool: R
    algorithm: enrichment of co-associated metabolite–module pairs
    parameters: min_pair_frequency=3, p_value_threshold=0.05
    input: tripartite association results
    output: mechanistic link hypotheses (e.g., 'Bifidobacterium adolescentis → BCAA biosynthesis → serum valine')
    confidence: low
