overall_reproducibility_score: 52/100

workflow_steps: 3
  Step 1: Metabolic reaction network (MRN) curation
    tool: Graph Neural Network (GNN) model
    algorithm: GNN-based reaction relationship prediction
    parameters: pre_screening_steps=2, reaction_pair_sources=['KEGG', 'MetaCyc', 'HMDB'], metabolite_generation_tool=BioTransformer
    input: Metabolite knowledge databases (KEGG, MetaCyc, HMDB), known reaction pairs
    output: Curated metabolic reaction network (MRN) with 765,755 metabolites and 2,437,884 predicted reaction pairs
    confidence: medium
  Step 2: Experimental data pre-mapping onto MRN
    tool: MetDNA3 (v3)
    algorithm: Sequential MS1 m/z matching → reaction relationship mapping → MS2 similarity constraints
    parameters: ms1_matching_tolerance_ppm=None, ms2_similarity_threshold=None, reaction_mapping_rule_set=biochemically plausible transformations
    input: LC-MS raw data (.mzML or vendor format), curated MRN
    output: Two-layer interactive network topology (data-driven feature nodes + knowledge-driven metabolite nodes)
    confidence: low
  Step 3: Recursive metabolite annotation propagation
    tool: MetDNA3 (v3)
    algorithm: Cross-network interaction-driven recursive annotation
    parameters: propagation_depth=None, annotation_confidence_threshold=None, computational_efficiency_gain=10-fold
    input: Two-layer interactive network topology
    output: Annotated metabolite list: >1600 seed metabolites (with standards), >12,000 putatively annotated metabolites
    confidence: medium

reproducibility_gaps:
  - Raw LC-MS data not deposited in any public repository (e.g., MetaboLights, GNPS)
  - No access to the GNN training code, model weights, or reaction pair training dataset
  - Critical parameters missing: MS1 tolerance (ppm), MS2 similarity threshold, propagation depth, confidence cutoffs
  - BioTransformer usage details (version, settings, output filtering) not specified
  - No description of LC-MS acquisition parameters (column, gradient, instrument method) needed for reproducible feature mapping
  - MetDNA3 web interface does not provide full programmatic API or offline CLI mode for batch/reproducible runs
reproducibility_strengths:
  - MetDNA3 is freely available as a web service with documented two-layer networking workflow
  - Comprehensive MRN construction methodology described (multi-database integration, GNN prediction, BioTransformer augmentation)
  - Validation metrics reported (Tanimoto coefficient alignment, degree distribution, clustering coefficient)
  - Explicit benchmarking against prior versions (MetDNA2) and external databases (PubChem)
