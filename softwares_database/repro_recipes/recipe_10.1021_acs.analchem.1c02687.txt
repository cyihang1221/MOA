  Step 2: Automated parameter optimization
    tool: SLAW
    algorithm: grid search + reproducibility-based objective function (feature overlap across technical replicates)
    parameters: parameter_space_resolution=coarse-to-fine, reproducibility_metric=Jaccard index of features in replicates, optimization_iterations=adaptive
    input: feature tables from candidate parameter sets
    output: optimized parameter set for peak picking and alignment
    confidence: high
  Step 3: Retention time alignment
    tool: SLAW
    algorithm: efficient sample alignment using dynamic time warping (DTW) on quality control (QC) samples
    parameters: alignment_reference=pooled QC, dtw_window=30, max_shift=60
    input: unaligned feature table + QC runs
    output: RT-aligned feature table
    confidence: medium
  Step 4: Gap filling by data recursion
    tool: SLAW
    algorithm: iterative re-detection using aligned RT and refined m/z windows from existing features
    parameters: recursion_depth=2, intensity_threshold_ratio=0.1, mz_tolerance_ppm=5
    input: RT-aligned feature table
    output: gap-filled feature table
    confidence: medium
  Step 5: Consolidated MS² and isotopic pattern extraction
    tool: SLAW
    algorithm: cross-sample MS² spectral merging + isotopic pattern inference using mass defect filtering and retention time consistency
    parameters: ms2_merge_tolerance_mz=0.005, ms2_merge_tolerance_rt=5, isotopic_charge_states=[1, 2], mass_defect_window_da=0.005
    input: gap-filled feature table + raw .mzML files with MS² scans
    output: consolidated MS² spectra library + isotopic pattern table
    confidence: medium
