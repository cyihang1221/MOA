    parameters: default_parameters=True
    input: FASTQ files

    confidence: high
  Step 3: TOMOseq alignment to reference genome
    tool: STAR (v2.7.7a)
    algorithm: splice-aware alignment
    parameters: default_parameters=True, genome=mouse GRCm38 Ensembl 102
    input: trimmed FASTQ
    output: BAM files
    confidence: high
  Step 4: TOMOseq quantification and filtering
    tool: custom_pipeline
    algorithm: UMI-corrected transcript counting

    output: gene-by-section count matrix
    confidence: low
  Step 5: TOMOseq normalization and integration
    tool: Scanpy (v1.9.3)
    algorithm: z-score normalization per sample, median normalization per section
    parameters: n_pcs=16, k_neighbors=65, distance_metric=euclidean, clustering_method=Leiden
    input: gene-by-section count matrix
    output: integrated z-score matrix, PCA embedding, Leiden clusters
    confidence: high
  Step 6: TOMOseq differential expression analysis
    tool: Scanpy (v1.9.3)
    algorithm: two-sided t-test with Benjamini–Hochberg correction
    parameters: p_value_threshold=0.05, z_score_difference_threshold=0.4
    input: z-score transformed gene expression matrix
    output: differentially expressed genes (DEGs) list
    confidence: high
  Step 7: MALDI-MSI data acquisition (TOF/TOF)
    tool: rapifleX MALDI-TOF/TOF
    algorithm: imaging mass spectrometry
    parameters: ion_mode=negative, mass_range=[80, 1000], pixel_size=20x20 μm², laser_shots_per_pixel=None
    input: 8 μm cryosections on ITO slides
    output: raw .d directory (Bruker format)
    confidence: high
  Step 8: MALDI-MSI data acquisition (FTICR)
    tool: solariX 2xR-FTICR
    algorithm: imaging mass spectrometry
    parameters: ion_mode=negative, mass_range=[550, 1000], pixel_size=75x75 μm², laser_shots_per_pixel=25
    input: 8 μm cryosections on ITO slides
    output: raw .d directory (Bruker format)
    confidence: high
  Step 9: MALDI-MSI preprocessing
    tool: custom pipeline
    algorithm: baseline correction, total ion current normalization
    parameters: min_pixel_intensity=2000, min_features_per_pixel=140, exclusion_criteria=['freezing damage patterns', 'matrix peaks']
    input: raw .d files
    output: preprocessed imzML or equivalent feature table
    confidence: low
  Step 10: MALDI-MSI peak filtering and normalization
    tool: custom pipeline
    algorithm: intensity normalization to mean total intensity, log10 transformation, z-score scaling
    parameters: normalization_method=total intensity mean, transformation=['log10', 'z-score']
    input: feature table (m/z vs pixel)
    output: normalized, scaled feature table
    confidence: medium
  Step 11: MALDI-MSI metabolite annotation
    tool: HMDB + LIPID MAPS + Wang et al. 2017 reference
    algorithm: m/z matching with mass tolerance not specified
    parameters: databases=['HMDB', 'LIPID MAPS'], validation_method=['cross-platform MSI validation (TOF vs FTICR)', 'biological plausibility']
    input: m/z features with intensity images
    output: putatively annotated metabolite/lipid table
    confidence: low
  Step 12: Spatial integration of TOMOseq and MALDI-MSI
    tool: custom in silico binning
    algorithm: proximal-distal axis binning into 50 equal-length regions, pixel-count normalization
    parameters: n_bins=50, binning_axis=proximal-distal, normalization=pixels_per_bin
    input: MALDI-MSI feature table + spatial coordinates
    output: pseudo-TOMOseq metabolite-by-section table
    confidence: medium

  - Cross-platform MSI validation (TOF vs FTICR) performed for annotation confidence
