========== reproducibility_recipe entry ==========
paper_title: Data processing, multi-omic pathway mapping, and metabolite activity analysis using XCMS Online.
source_paper: Forsberg EM et al. (2018), Nature protocols, DOI: 10.1038/nprot.2017.151, PMID: 29494574
overall_reproducibility_score: 78/100

workflow_steps: 10
  Step 1: Data upload
    tool: XCMS Online (vv3.0 (as of 2018))
    input: raw LC-MS data files (.mzML, .mzXML, .cdf, .wiff, .raw)
    output: uploaded dataset
    confidence: high
  Step 2: Feature detection
    tool: XCMS Online (vv3.0)
    algorithm: centWave
    parameters: peak_width_sec=[10, 60], mz_tolerance_ppm=25, sn_thresh=10, prefilter=[3, 10000], noise=500
    input: raw LC-MS data files
    output: feature table (m/z, RT, intensity)
    confidence: high
  Step 3: Retention time correction
    tool: XCMS Online (vv3.0)
    algorithm: obiwarp
    parameters: profiling=true, span=0.5, smooth=true
    input: feature table
    output: retention time-aligned feature table
    confidence: high
  Step 4: Peak filling and missing value imputation
    tool: XCMS Online (vv3.0)
    algorithm: fillpeaks
    parameters: max_peakwidth_sec=30, min_peakwidth_sec=5, mz_tolerance_ppm=25, sn_thresh=10
    input: retention time-aligned feature table
    output: filled/complete feature matrix
    confidence: high
  Step 5: Statistical analysis (univariate)
    tool: XCMS Online (vv3.0)
    algorithm: t-test, ANOVA, fold-change
    parameters: p_value_cutoff=0.05, fold_change_threshold=2.0, multiple_testing_correction=FDR (Benjamini-Hochberg)
    input: filled feature matrix with sample class annotations
    output: list of statistically significant features
    confidence: high
  Step 6: Metabolite annotation (MS1-based)
    tool: XCMS Online (vv3.0)
    algorithm: mzCloud, HMDB, METLIN, MassBank matching
    parameters: mass_tolerance_ppm=5, retention_time_window_sec=30, database_priority_order=['mzCloud', 'HMDB', 'METLIN', 'MassBank']
    input: significant features (m/z, RT)
    output: putatively annotated metabolites
    confidence: medium
  Step 7: Predictive metabolic pathway analysis
    tool: XCMS Online (vv3.0)
    algorithm: MetaboAnalyst-style overrepresentation analysis + impact analysis
    parameters: pathway_database=KEGG, organism=Homo sapiens, method=hypergeometric test + pathway topology analysis, p_value_cutoff=0.05, impact_threshold=0.1
    input: annotated significant metabolites (KEGG IDs)
    output: dysregulated pathways with p-values and impact scores
    confidence: high
  Step 8: Multi-omics integration (transcriptomics overlay)
    tool: XCMS Online (vv3.0)
    algorithm: gene-metabolite mapping via KEGG/Reactome
    parameters: omics_type=transcriptomics, mapping_database=KEGG, directionality=up/down-regulated genes overlaid on pathway maps
    input: significant transcriptomics data (Supplementary Data 1)
    output: integrated pathway maps with gene and metabolite regulation
    confidence: medium
  Step 9: Multi-omics integration (proteomics overlay)
    tool: XCMS Online (vv3.0)
    algorithm: protein-metabolite mapping via KEGG/Reactome
    parameters: omics_type=proteomics, mapping_database=KEGG, directionality=up/down-regulated proteins overlaid on pathway maps
    input: significant proteomics data (Supplementary Data 2)
    output: integrated multi-omic pathway maps
    confidence: medium
  Step 10: Pathway cloud visualization
    tool: XCMS Online (vv3.0)
    algorithm: custom pathway enrichment cloud
    parameters: score_metric=combined p-value and impact score, font_size_scaling=log10(1/p), color_by=impact_score
    input: pathway analysis results
    output: interactive pathway cloud plot
    confidence: high
