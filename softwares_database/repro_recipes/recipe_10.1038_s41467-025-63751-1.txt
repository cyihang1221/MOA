workflow_steps: 7
  Step 1: Descriptive statistics computation
    tool: R/Python base libraries
    algorithm: mean, median, mode, SD, IQR, skewness, kurtosis, Pearson/Spearman correlation
    parameters: correlation_method=Spearman for skewed/non-normal data, Pearson for normal, outlier_definition_tukey=Q1 - 1.5*IQR, Q3 + 1.5*IQR, outlier_definition_adjusted_boxplot=medcouple-based fences: Q3 + 1.5*exp(3*MC)*IQR (upper), Q1 - 1.5*exp(-4*MC)*IQR (lower) for MC ≥ 0
    input: quantified lipid/metabolite abundance matrix (e.g., peak area/intensity table)
    output: summary statistics table (location, dispersion, shape, correlation matrix)
    confidence: high
  Step 2: Box plot construction (Tukey and adjusted)
    tool: robustbase (R), litteR (R), seaborn/matplotlib (Python)
    algorithm: Tukey boxplot; medcouple-adjusted boxplot
    parameters: whisker_method=Tukey (1.5×IQR) or medcouple-adjusted, jitter=enabled for dot overlay, transparency=alpha < 1 to handle overplotting, paired_lines=enabled for within-subject designs
    input: abundance matrix with group labels
    output: annotated box plots (with dots, violin overlays, paired lines)
    confidence: high
  Step 3: Fold change calculation
    tool: R/Python base libraries
    algorithm: log2(ratio of group means or medians)
    parameters: log_base=2, central_tendency=mean for symmetric, median for skewed distributions
    input: group-wise summary statistics (means/medians per lipid/metabolite)
    output: fold change vector (log2FC)
    confidence: high
  Step 4: Two-group statistical testing
    tool: R (stats), Python (scipy)
    algorithm: t-test (unpaired/paired/Welch), Mann–Whitney U test (Wilcoxon rank-sum)
    parameters: test_selection_criteria=normality (Shapiro-Wilk) and homoscedasticity (F-test or Levene’s) assessed first, t_test_type=two-sided by default; Welch’s correction if variances unequal, mann_whitney_handling_ties=average rank assignment, alpha=0.05
    input: abundance matrix with two-group labels
    output: p-value vector, test statistic (t/U/Z), effect size (Cohen’s d, rank-biserial)
    confidence: high
  Step 5: Multi-group statistical testing
    tool: R (stats), Python (scipy)
    algorithm: one-way ANOVA (parametric), Kruskal–Wallis test (non-parametric)
    parameters: anova_assumptions=normality, homoscedasticity, independence, post_hoc=Tukey HSD or Dunn’s test (if ANOVA/KW significant), alpha=0.05
    input: abundance matrix with ≥3-group labels
    output: p-value vector, F-statistic or H-statistic, post-hoc pairwise results
    confidence: medium
  Step 6: Missing value classification and imputation
    tool: R (impute, missForest, VIM), Python (scikit-learn, fancyimpute, sklearn.impute)
    algorithm: kNN imputation, random forest imputation, half-minimum (hm), quantile regression imputation for left-censored (QRILC)
    parameters: imputation_strategy_by_missingness={'MCAR/MAR': ['kNN', 'random forest'], 'MNAR': ['half-minimum', 'QRILC']}, filter_threshold=remove features with >35% missing values, knn_k=default or optimized (not specified)
    input: raw abundance matrix with NA/NaN entries
    output: imputed abundance matrix (no missing values)
    confidence: medium
  Step 7: Data normalization and preprocessing
    tool: R (norm, metid), Python (scikit-learn, pandas)
    algorithm: batch correction, internal standard-based concentration recalibration, sample amount normalization
    parameters: normalization_target=analytical variation (batch effects, signal intensity drift), preferred_pre-acquisition_normalization=yes (e.g., spike-in standards, total sum, PQN)
    input: imputed abundance matrix
    output: normalized abundance matrix (biological variation emphasized)
    confidence: low
