    output: feature table (peak intensity matrix)
    confidence: medium
  Step 2: Retention time alignment and correction
    tool: XCMS
    algorithm: obiwarp
    parameters: profiling=True, method=obiwarp
    input: feature list from centWave
    output: aligned feature table
    confidence: medium
  Step 3: Metabolite annotation
    tool: CAMERA
    algorithm: adduct detection, isotope grouping, blank subtraction
    parameters: ppm=5, mzwid=0.025, minfrac=0.5, maxiso=3
    input: aligned feature table
    output: annotated feature table with putative metabolite IDs
    confidence: medium
  Step 4: Quality control and filtering
    tool: R (custom scripts)
    algorithm: missing value imputation (KNN), coefficient of variation filtering, inter-sample correlation filtering
    parameters: cv_threshold=0.3, cor_threshold=0.8, k=10
    input: annotated feature table
    output: QC-filtered metabolite abundance matrix
    confidence: low
  Step 5: mdGWAS statistical modeling
    tool: mdGWAS R package
    algorithm: Differential correlation network association testing using Fisher’s z-transformation and permutation-based FDR control
    parameters: n_permutations=1000, fdr_threshold=0.05, min_cor_change=0.2, cor_method=spearman
    input: QC-filtered metabolite abundance matrix + genotype matrix (plink format)
    output: SNP-metabolite-pair associations with differential coordination p-values and FDR
    confidence: high
  Step 6: Pathway-level coordination analysis
    tool: MetaboAnalyst
    algorithm: pathway enrichment via overrepresentation analysis (ORA) on differentially coordinated metabolite pairs
    parameters: database=HMDB, method=hypergeometric, p_value_cutoff=0.05, fdr_method=BH
    input: list of metabolite pairs with significant mdGWAS hits
    output: enriched metabolic pathways with coordination disruption scores
    confidence: medium
