workflow_steps: 4
  Step 1: MS2 spectral processing and library matching
    tool: SMfinder
    algorithm: MS2 false discovery rate (FDR) based on single spectral permutation
    input: MS2 spectra (e.g., .mzML, .mgf)
    output: annotated small molecule identifications with FDR control
    confidence: medium
  Step 2: Instrument-independent metabolite identification
    tool: SMfinder
    algorithm: Library search using public MS2 spectral libraries (e.g., GNPS, MassBank, LipidBlast)
    parameters: library_matching_tolerance=instrument-independent, fdr_threshold=0.01
    input: processed MS2 spectra and reference spectral libraries
    output: confidently annotated metabolites/lipids with FDR-controlled matches
    confidence: low
  Step 3: Quantification and integration with untargeted workflows
    tool: SMfinder
    algorithm: Peak area integration from MS1 features linked to MS2 identifications
    input: MS1 feature table + matched MS2 identifications
    output: quantified, annotated metabolite/lipid table
    confidence: low
  Step 4: Support for targeted and flux analysis
    tool: SMfinder
    algorithm: Retention time alignment and isotope pattern-based quantification (for flux)
    input: targeted acquisition data or isotopically labeled datasets
    output: targeted quantification results or isotopic enrichment values
    confidence: low
