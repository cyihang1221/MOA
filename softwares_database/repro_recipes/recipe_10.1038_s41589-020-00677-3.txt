========== reproducibility_recipe entry ==========
paper_title: Chemically informed analyses of metabolomics mass spectrometry data with Qemistree.
source_paper: Tripathi A et al. (2021), Nature chemical biology, DOI: 10.1038/s41589-020-00677-3, PMID: 33199911
overall_reproducibility_score: 87/100

workflow_steps: 7
  Step 1: Feature detection and abundance table generation
    tool: MZmine
    algorithm: peak picking
    input: raw .mzXML files
    output: feature abundance table + MGF file with MS1/MS2
    confidence: medium
  Step 2: Molecular fingerprint prediction and in silico structural annotation
    tool: SIRIUS + CSI:FingerID
    algorithm: CSI:FingerID molecular fingerprint prediction from MS2 spectra
    input: MGF file with MS1/MS2 ion information
    output: predicted SMILES + molecular fingerprints (e.g., CSI:FingerID fingerprints)
    confidence: high
  Step 3: Phenetic tree construction from molecular fingerprints
    tool: Qemistree (QIIME2 plugin)
    algorithm: pairwise Tanimoto similarity + UPGMA clustering
    parameters: distance_metric=tanimoto, clustering_method=upgma
    input: molecular fingerprints (per MS feature)
    output: phenetic tree (Newick format)
    confidence: high
  Step 4: Chemical taxonomy annotation via ClassyFire
    tool: ClassyFire API
    algorithm: chemical ontology classification
    parameters: taxonomic_levels=['kingdom', 'superclass', 'class', 'subclass', 'direct_parent']
    input: SMILES strings (from SIRIUS/CSI:FingerID or spectral library matches)
    output: chemical taxonomy annotations per feature
    confidence: high
  Step 5: Tree-based diversity analysis and sample comparison
    tool: QIIME2
    algorithm: Weighted UniFrac distance calculation
    parameters: weighted_unifrac=True, pseudocount=1
    input: feature abundance table + phenetic tree
    output: sample-by-sample distance matrix (Weighted UniFrac)
    confidence: high
  Step 6: Statistical comparison of sample groupings
    tool: QIIME2 + custom statistical scripts
    algorithm: PERMANOVA (Adonis)
    parameters: permutations=999
    input: distance matrix + sample metadata
    output: statistical significance (pseudo-F, p-value) for groupings
    confidence: medium
  Step 7: Tree visualization and annotation
    tool: iTOL
    algorithm: interactive tree rendering with metadata overlays
    parameters: tree_layout=rectangular, annotation_type=['pie_chart', 'ring_chart', 'color_strip']
    input: Newick tree + feature abundances + ClassyFire taxonomy + metadata
    output: annotated interactive tree visualization
    confidence: high
