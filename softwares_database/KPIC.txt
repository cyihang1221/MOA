All are untargeted high-resolution LC-MS metabolomics data suitable for pure ion chromatogram extraction. Specific biological sample preparation details (extraction solvents, chromatography columns) are not reported in the abstract.
software_configuration_description: KPIC2 (Kernel-based Peak Identification, version 2) is an open-source R package for untargeted LC-MS metabolomics built around pure ion chromatograms (PICs). PIC extraction: the raw LC-MS data is converted into a three-column matrix (retention time, m/z, intensity); the highest-intensity ion is chosen iteratively as a landmark, a region of interest (ROI) is delimited with a flexible m/z tolerance (ppm), and optimal one-dimensional k-means clustering (Ckmeans.1d.dp) is applied to the squared m/z differences between ions and the landmark to isolate the same ion from noise; the selected ions form a PIC refined by exponential smoothing. Peak detection: multiscale peak detection (MSPD) in wavelet space — continuous wavelet transform (CWT) with the Mexican hat wavelet; peak positions are located from ridges, valleys, and zero-crossings of the wavelet coefficients; peak width is estimated from an enhanced SNR derivative; peaks are filtered by signal-to-noise ratio and intensity. PIC quality is additionally scored by Gaussian similarity (R^2 of Gaussian fitting), sharpness, and SNR. Beyond detection, KPIC2 aligns PICs across samples, groups PICs into isotope/adduct clusters, and fills missing peaks. Key detection parameters: level (intensity threshold for seed ions), mztol (m/z tolerance, default 0.1 Da), gap (allowed missing scans, default 3), width (peak width, default 5 s), min_snr (signal-to-noise threshold, default 4). Implementation: R package depending on Ckmeans.1d.dp, Rcpp, RcppArmadillo, mzR, dbscan, GA, data.table, IRanges; input mzXML/CDF/mzML via mzR (LoadData); output peak table with m/z, retention time, intensity, area, and SNR.
source_paper: Ji et al. (2017), Analytical chemistry, DOI: 10.1021/acs.analchem.7b01547, PMID: 28621925
