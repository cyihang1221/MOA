  Step 6: Metabolite annotation and quantification
    tool: ClusterFinder (IROA TruQuant Workflow) (v4.2.21)
    algorithm: isotopic pattern matching (5%/95% 13C), monoisotopic mass + carbon count → molecular formula
    parameters: isotope_balance=95%:5% U-13C, carbon_range=[3, 50], identity_algorithm=comparison to IROA-LTRS, reporting_standard=IROA-defined tiers (e.g., Level 1–4)
    input: mzXML files (experimental samples) + Dual MSTUS Metabolite Lists
    output: quantitative table (raw, suppression-corrected, normalized intensities), annotation table (compound name, RT, m/z_12C, m/z_13C, reporting standard)
    confidence: high
  Step 7: Ion suppression correction
    tool: IROA TruQuant Workflow (proprietary algorithm)
    algorithm: Dual MSTUS normalization using IROA-IS and IROA-LTRS
    parameters: correction_basis=ratio of 12C/13C peak intensities for each metabolite, suppression_factor=calculated per-metabolite from IROA-IS response deviation, normalization_strategy=Dual MSTUS (Metabolite-Specific Total Unlabeled Standard)
    input: quantitative peak table + IROA-IS/LTRS response data
    output: suppression-corrected and normalized feature table
    confidence: medium
  Step 8: Quality control and batch assessment

    algorithm: CV-based QC (IROA-IS metabolites)

    input: suppression-corrected feature table + QC injections
    output: batch quality report, flagged samples
    confidence: high
