========== reproducibility_recipe entry ==========
paper_title: AI-driven framework to map the brain metabolome in three dimensions.
source_paper: Ma X et al. (2025), Nature metabolism, DOI: 10.1038/s42255-025-01242-9, PMID: 40102678
overall_reproducibility_score: 42/100

workflow_steps: 8
  Step 1: Image registration of serial 2D MALDI-MSI sections
    tool: MetaVision3D
    algorithm: computer vision–based image registration
    input: 2D MALDI mass spectrometry imaging heatmaps (per m/z)
    output: aligned stack of serial 2D sections
    confidence: low
  Step 2: Intensity normalization across serial sections
    tool: MetaNorm3D
    algorithm: slide-level normalization
    input: aligned 2D section heatmaps
    output: normalized 2D section heatmaps
    confidence: low
  Step 3: Gap imputation for tissue imperfections
    tool: MetaImpute3D
    algorithm: imputation of missing spatial pixels
    input: normalized 2D section heatmaps
    output: gap-filled 2D section heatmaps
    confidence: low
  Step 4: Interpolation to generate high-density phantom sections
    tool: MetaInterp3D
    algorithm: interpolation using enhanced correlation coefficient (ECC), SSIM, and MSE optimization
    parameters: target_section_count=316, phantom_sections_added=158
    input: gap-filled 2D section heatmaps (79 real sections)
    output: dense 3D voxel grid (316 interpolated sections)
    confidence: medium
  Step 5: 3D spatial metabolome reconstruction and visualization
    tool: ImageJ
    algorithm: 3D projection and fill rendering
    parameters: intensity_threshold=top 1% highest intensity pixels, rendering_mode=['projection', '3D fill']
    input: dense 3D voxel grid
    output: 3D rendered metabolite distribution maps
    confidence: high
  Step 6: Region-of-interest (ROI) extraction using anatomical reference atlases
    tool: Allen Brain Atlas / Allen Reference Atlas
    algorithm: spatial pixel masking based on Nissl-stained reference annotations
    parameters: atlases_used=['Allen Mouse Brain Atlas', 'Allen Reference Atlas'], regions_of_interest=['isocortex', 'hindbrain', 'cerebellar molecular layer', 'hippocampal region', 'ventricular system', 'cerebral nuclei']
    input: 3D rendered metabolite maps + Nissl-stained reference
    output: metabolite/lipid intensity values per anatomical ROI
    confidence: high
  Step 7: Pathway and ontology enrichment analysis
    tool: MetaboAnalyst
    algorithm: hypergeometric test with Bonferroni correction
    parameters: statistical_test=hypergeometric test, multiple_testing_correction=Bonferroni
    input: ROI-extracted metabolomics data
    output: enriched metabolic pathways (-log10 p-value)
    confidence: high
  Step 8: Lipid ontology enrichment analysis
    tool: LION (Lipid Ontology)
    algorithm: one-sided Kolmogorov-Smirnov test with Bonferroni correction
    parameters: statistical_test=one-sided Kolmogorov-Smirnov test, multiple_testing_correction=Bonferroni
    input: ROI-extracted lipidomics data
    output: enriched lipid categories (-log10 p-value)
    confidence: high
