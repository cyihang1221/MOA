(5) Feature detection & spectral matching: MZmine 4.3 performed feature detection with intensity threshold ≥1E6, mass accuracy ≤5 ppm, and post-processing (smoothing, alignment, isotope/duplicate filtering, gap filling, ion identity networking, blank filtration). Spectral matching used precursor m/z tolerance = 3 ppm, fragment m/z tolerance = 5 ppm, unweighted cosine similarity (Eq. 1), minimum score = 0.1, and minimum matched fragments = 2 (including precursor); results manually curated to exclude false positives. (6) Experimental library integration: 1,543,129 reference spectra from MS-DIAL (367,674), MSnLib (85,382), MoNA (148,546), Massbank EU (117,283), GNPS (816,675), HighResNPS (3,280), Folberth et al. (4,159), and Wang et al. (130) were compiled for comparative annotation.

sample_description: The study used five Caenorhabditis elegans strains: wild-type Bristol (N2); two xenobiotic-metabolizing enzyme knockout strains—VC40 (cyp-13A7(gk31) II, CYP enzyme mutant) and VC1668 (fmo-2(ok2147) IV, flavin-containing monooxygenase mutant); and two transgenic neurodegeneration models—UA57 (baIs4 [dat-1p::GFP + dat-1p::CAT-2], PD-related, expressing tyrosine hydroxylase ortholog in dopamine neurons) and BR5270 (byIs161 [rab-3p::F3(delta)K280 + myo-2p::mCherry], AD-related, pan-neuronal overexpression of human Tau pro-aggregation fragment). Worms were cultured at 20 °C on NGM agar plates seeded with UV-treated Escherichia coli OP50. Synchronization was achieved via hypochlorite bleaching of gravid (post-L4) adults to isolate eggs, followed by hatching and growth to L4 stage over 48 h. L4-stage worms were sorted using a COPAS Flow Pilot FP-250 system (Union Biometrica) based on an established gating strategy, collecting 300 worms per tube; corresponding M9 blanks (supernatant after centrifugation of worm suspension) were prepared in parallel. All sorted worms and M9 blanks were snap-frozen and stored at −80 °C prior to metabolite extraction.
complete_workflow_description: Data processing involved two complementary software tools: patRoon (v2.3.1) and MS-DIAL (v5.1.230912). Raw LC–MS/MS files (in vendor format) were first converted to open mzML format using MSConvertGUI (ProteoWizard v3.0.22108-f83e548) with peak-picking filter, vendor algorithm, and all MS levels enabled. In patRoon: feature detection and alignment used the 'xcms3' algorithm; optimal XCMS parameters were selected via the IPO algorithm run on pooled QC samples; componentization (grouping isotopes/adducts) used CAMERA; annotation employed MetFrag against two databases—PubChemLite (v1.19.0) and the custom 'WormJam expanded' collection—with MoNAScore-based confidence level filtering. In MS-DIAL: parameters included ionization type = soft ionization, separation type = chromatography, MS method type = conventional LC/MS or data-dependent, collision type = CID/HCD, data type = centroid, target omics = lipidomics (for RPLC NEG) or metabolomics (for HILIC POS), MS1 accuracy tolerance = 0.02 Da, MS2 accuracy tolerance = 0.025 Da, minimum peak height = 1000 amplitude, mass slice width = 0.1 Da. Annotation used public MSP libraries (MSMS_Public_EXP_NEG_VS17, MSMS_Public_ExpBioInsilico_NEG_VS17 for negative mode; MSMS_Public_EXP_POS_VS17 for positive mode) and custom in silico–generated WormJam MSP libraries (as described in CFM-ID configuration). Adducts considered were [M-H]−, [M-H2O-H]−, [M+Na-2H]−, [M+HCOO-H]−, [M+CH3COO-H]−, [M+CH3COONa-H]− (negative) and [M+H]+, [M+NH4]+, [M+Na]+, [M+CH3OH+H]+, [M+K]+, [M+ACN+H]+, [M+H-H2O]+ (positive). Alignment used pooled QC file with retention time tolerance = 0.1 min, MS1 tolerance = 0.02 Da, and retention time/MS1 factor = 0.5. Manual curation based on visual inspection of peak shape was performed for significant compounds before exporting intensity tables. All R-scripts for downstream statistical and pathway analyses (using R v4.3.1, RStudio v2023.06.1, tidyverse v2.0.0) are publicly available.

========== paper_workflow entry 3 ==========
related_tool: CFM-ID
sample_description: The study used experimental MS/MS data from three spectral libraries: (1) NIST'17, a commercial library containing MS/MS spectra from authentic compound standards, converted to .msp format using lib2nist and parsed with RDKit for molecular structure information (SMILES, MOL, InChiKey); (2) the public MS-DIAL spectral library (available in .msp format), which aggregates annotated spectra from MassBank and GNPS and provides standardized metadata including collision energy, retention time (RT), and collision cross-section (CCS); and (3) MSnLib v1.0, a recently published open-source library containing over 1 million multi-stage fragmentation spectra, including 177,390 MS/MS spectra for 15,967 unique compounds. All libraries were pre-processed uniformly: normalized collision energy (NCE) was converted to electron volts (eV) using the Proteomicsnews formula; spectra with missing or ambiguous collision energies were excluded; compounds with inconsistencies among SMILES, MOL, and InChiKey representations were filtered out; only [M+H]+ and [M−H]− ionization modes were retained (plus [M]+ and [M]− for MSnLib); molecular weight was capped at 1000 Da and collision energy at 100 eV; fragment–peak matching was performed at 50 ppm tolerance for NIST and MS-DIAL (10 ppm for MSnLib) against the theoretically generated fragment ion space F(G); ambiguous matches (multiple fragments mapping to same m/z within tolerance) were assigned equal probability; spectra were required to have ≥2 matched peaks, ≥50% peak intensity coverage, ≤90% precursor intensity, and either ≥50% of total peaks matched or ≥5 matched peaks or ≥80% intensity coverage; the NIST'17 and MS-DIAL libraries were combined into a single training set of 74,401 spectra from 10,692 compounds, while MSnLib was used separately to train an open-source FIORA variant; additionally, benchmarking used CASMI 2016 and CASMI 2022 challenge datasets—CASMI 2016 included stepped collision energy spectra (predicted at all three energies and merged), while CASMI 2022 challenge spectra were extracted from mzML files using OpenMS Python wrapper with 10 ppm precursor tolerance and 5-second RT window, followed by consensus spectrum generation per collision energy level; all test compounds were rigorously excluded from respective training sets for FIORA and ICEBERG, whereas CFM-ID’s training on METLIN 17 means no such guarantee exists.
complete_workflow_description: FIORA’s workflow consists of four core procedural stages: (1) Graph construction and preprocessing: Molecular structures are parsed from SMILES strings into undirected molecular graphs G where atoms are nodes and bonds are edges; atom features (element type, number of bound hydrogens, ring membership) and bond features (bond type, ring membership) are encoded as integers and embedded into 300-dimensional vectors via learnable embedding layers; (2) Graph neural network processing: A 6-layer Relational Graph Convolutional Network (RGCN) is applied by default (though GCN, RGCN, GAT, and Graph Transformer layers are supported), with Exponential Linear Unit (ELU) activation after each layer; node representations are updated via message-passing: h_i = ϕ(x_i, ⊕_{j∈N_i} ψ(x_i, x_j)), where ⊕ is summation aggregation and ϕ/ψ are learnable functions; (3) Prediction head computation: For fragment ion abundance θ_f, edge features are constructed by concatenating embeddings of the two incident atoms, the edge embedding, and covariates (molecular weight, precursor ion mode ([M+H]+/[M−H]−), collision energy, instrument type), then passed through a two-layer fully connected network outputting a 10-dimensional logit vector (5 ion modes × 2 fragment sides per edge break); precursor stability σ is computed from the global mean-pooled graph embedding concatenated with the same covariates, processed by two fully connected layers yielding a scalar logit; all logits (σ and θ_f for all f ∈ F(G)) are jointly normalized via softmax to produce fragment and precursor probabilities p(f); (4) Spectrum reconstruction and post-processing: Predicted subgraphs (fragments) are traced back using the edge map; exact m/z values are reconstructed from fragment mass and hydrogen loss count (0–3 H); peak intensities are obtained by summing probabilities of all fragment ions falling within the m/z tolerance window (50 ppm for NIST/MS-DIAL, 10 ppm for MSnLib); RT and CCS values are predicted separately using the same mean-pooled graph embedding fed into dedicated dense layers (frozen during fragment training) with standard MSE loss; training uses weighted mean squared error loss between predicted fragment probabilities and observed probabilities (derived from square-root-transformed peak intensities matched to F(G)), weighted by 1/(number of spectra per compound) to mitigate compound-level bias; optimization employs ADAM with learning rate scheduling on validation loss plateau over 200 epochs; ICEBERG was trained identically to FIORA (same splits, same workflow) using the GitHub repository (commit from Oct 21, 2023); all software dependencies rely on PyTorch Geometric for GNN implementation.

========== paper_workflow entry 4 ==========
related_tool: CFM-ID
sample_description: The study used the NIST20 MS/MS spectral library containing 27,613 compounds and 1,026,712 experimental spectra, filtered to exclude compounds present in NIST17 or the CFM-ID 4.0 training set, resulting in 15,328 [M + H]+ and 15,494 [M – H]− benchmarking compounds; additionally, the Vaniya/Fiehn Natural Product Library (VFNPL) of Q-Exactive HF orbital ion trap accurate mass MS/MS spectra was downloaded from Massbank of North America; all spectra were restricted to [M + H]+ and [M – H]− adducts, and only spectra generated under specific fragmentation conditions (Orbitrap HCD/CID and Q-TOF) were retained — specifically, 157,407 [M + H]+ Orbitrap HCD, 71,026 [M – H]− Orbitrap HCD, 12,295 [M + H]+ Orbitrap CID, 6,333 [M – H]− Orbitrap CID, 1,111 [M + H]+ Q-TOF, and 35 [M – H]− Q-TOF spectra; for structural analysis, a subset of 8,035 [M + H]+/HCD-Orbitrap compounds with explicitly reported experimental collision energies between 35–45 eV was used; chemical structures were represented as InChI codes (hashed as InChIKeys), classified using the ClassyFire tool (batch version at cfb.fiehnlab.ucdavis.edu), and encoded into CACTVS molecular fingerprints via the PubChem web tool; the CFM-ID 4.0.4 training set (4,040 molecules disclosed by authors) and the 8,298 molecules from the 35–45 eV NIST20 subset were jointly fingerprinted for UMAP/PCA/t-SNE analysis.
complete_workflow_description: The workflow involved: (1) filtering the NIST20 library by removing compounds overlapping with NIST17 or CFM-ID 4.0 training data; (2) generating in silico MS/MS spectra using CFM-ID 4.04 and MSRB 1.1.3 (Docker images); (3) computing unweighted dot product similarities between predicted and experimental spectra with 10 ppm mass tolerance and exclusion of ±2 Da around precursor; (4) normalizing all spectra to relative abundance before similarity calculation; (5) classifying compound structures using ClassyFire via batch web service; (6) obtaining CACTVS fingerprints using PubChem REST API/web tool; (7) performing dimensionality reduction (UMAP, PCA, t-SNE) on combined training and test fingerprints; (8) partitioning spectra into six instrument/adduct groups per Table 1; (9) analyzing collision energy effects by binning experimental energies into 1 eV intervals (1–45 eV for Q-TOF; 1–70 eV for Orbitrap, limited to first 50 bins due to data sparsity) and correlating with simulated 10/20/40 eV CFM-ID predictions; (10) restricting high-energy analysis to Thermo Finnigan Elite Orbitrap spectra with explicit eV metadata (35–45 eV) to mitigate %NCE instrument variability; (11) computing best-match dot scores across the three CFM-ID energies per spectrum and retaining the maximum; (12) conducting all statistical analyses and visualizations using custom Python scripts.

========== paper_workflow entry 5 ==========
related_tool: CFM-ID
sample_description: All drug standards were provided by the Central Toxicological Laboratory of the Russian Ministry of Health. The study utilized experimentally acquired MS/MS spectra of >5000 molecules, including >1000 compounds after hydrogen/deuterium (H/D) exchange and >100 compounds after oxygen-16/oxygen-18 (16O/18O) exchange. H/D exchange was performed in the ESI source using a modified desolvation capillary heated to 300 °C with D2O vapor infusion; 16O/18O exchange was conducted in-solution by dissolving target compounds in H218O and heating at 95 °C for 15 h in sealed glass vials. Compounds included psychoactive designer drugs (e.g., methylenedioxypyrovalerone, MDPV), bisacodyl, cinnarizine, climbazole, tolperisone, thioridazine, benzydamine, anastrozole, buflomedil, and mephedrone isomers. Spectra were acquired in both positive-ion (pos-ESI) and negative-ion (neg-ESI) modes, with >200 compounds having neg-ESI data. Solutions of target compounds were prepared in methanol–water (1:1), infused at 1 μL·min⁻¹, with spray voltage of 3 kV. LC–MS/MS was also used for some compounds (details in Supporting Information).
complete_workflow_description: The PyFragMS software tool was developed as a web application using Anvil (https://anvil.works/) for the front-end and Python for the back-end. Molecular operations were implemented using RDKit (https://www.rdkit.org/) and the 'molmass' package. Fragmentation tree visualization employed GraphViz. MS/MS spectra preprocessing was performed using XCalibur 4.1 (Thermo Fisher Scientific) to extract and average MS/MS spectra across multiple collision energies (10–90 NCE) with isolation window of 0.4 Da. Molecular formula assignment for fragment ions was carried out using Sirius 4 software. The PyFragMS database integrates three data sources: (1) the largest public MS/MS spectral dataset (MzCloud-derived), (2) previously published H/D exchange MS/MS spectra, and (3) newly acquired experimental H/D and 16O/18O exchange MS/MS spectra. For fragmentation tree computation, PyFragMS accounts for multiple protonation sites (protomers), allows elemental composition deviation of ±1 H to accommodate hydrogen transfer during fragmentation, and supports user-defined filtering based on precursor molecular formula and number of H/D or 16O/18O exchanges. Identification workflows use cosine and Jaccard similarity measures computed on assigned molecular formulas (not raw m/z values) to improve annotation accuracy. Users can either query the embedded database or upload custom MS/MS data. The algorithm outputs a fragmentation tree with node IDs and a table mapping experimental MS/MS ions to theoretical fragments, indicating matches or mismatches in elemental composition. Step-by-step usage instructions, interface screenshots, and a video tutorial are available at https://pyfragms.anvil.app/ and in the Supporting Information.

========== paper_workflow entry 6 ==========
related_tool: CFM-ID
sample_description: A total of 1269 unique chemical substances were spiked across ten synthetic mixtures (labeled 499 through 508), with each mixture containing 95 to 365 substances. These mixtures constitute the EPA's ENTACT (Environmental and Toxicological Assessment of Chemicals in Mixtures) reference set. Only substances previously classified as 'pass' — i.e., those linked to experimental features with strong diagnostic evidence (e.g., corroborating MS1 and MS2 data supporting 'probable structure' identification per Schymanski et al. confidence level 2) — were included in the current in silico library matching analysis. A total of 845 'pass' substances spanned all ten mixtures, and for each, MS2 spectra were acquired at three collision energy (CE) levels (10, 20, and 40 V) in both positive ([M+H]⁺) and negative ([M−H]⁻) ionization modes using LC/MS. MS2 spectra corresponding to these 'pass' substances served as the experimental query set; each spectrum was associated with a known ground-truth compound identified by its DSSTox MS-Ready DTXCID. Sample preparation and LC/MS acquisition used an Agilent 1290 Infinity II LC coupled to an Agilent 6530B Q-TOF mass spectrometer with Dual AJS ionization, ZORBAX Eclipse Plus C8 column (2.1 × 50 mm, 1.8 μm), mobile phases of 0.4 mM ammonium formate in water and methanol, and mass calibration via continuous infusion of purine/hexakis(1H,1H,3H-tetrafluoropropoxy)phosphazene/TFA. MS1 and MS2 scans covered m/z 100–1000; Auto MS2 acquisition settings included up to 3 precursors/cycle, minimum threshold 3000 counts, scan rate 4 spectra/second, and dynamic exclusion/inclusion lists. Each sample was analyzed three times to generate one full MS2 dataset per CE level.
complete_workflow_description: The in silico library matching workflow was implemented using a custom Python script (source code available at https://github.com/NTA-Code/cfmid). First, experimental MS2 spectra were exported from Agilent .d files into MGF format. The Python script then performed formatting standardization and de-duplication: for each unique precursor m/z, only the MS2 spectrum with the highest sum intensity of fragment ions was retained. Next, for each experimental spectrum, candidate compounds were retrieved from the CFM-ID database based on 10-ppm mass match (and optionally formula match). Three scoring approaches were evaluated: (1) '1:1 matching' — only the CFM-ID spectrum at the same CE level as the experimental spectrum was scored; (2) '1:3 summation' — scores from all three CFM-ID CE levels (10, 20, 40 V) were summed for a given experimental spectrum; (3) '9-way summation' — scores from all nine combinations of experimental CE (10/20/40 V) × in silico CE (10/20/40 V) were summed. All scoring used the dot-product algorithm with 0.02 Da fragment tolerance. For each experimental spectrum, resulting scores were used to rank candidate compounds, compute percentile ranks (relative position among all candidates), and quotient values (candidate score divided by maximum candidate score for that spectrum). Receiver operating characteristic (ROC) analysis was performed globally across all 845 'pass' compounds to determine optimal cutoff thresholds (percentile and quotient) achieving ≥0.90 true positive rate (TPR); these global thresholds were then applied mixture-wise to compute mixture-specific TPRs and false positive rates (FPRs) as performance metrics. Analyses were conducted both with and without formula filtering to assess robustness under realistic (mass-only) versus idealized (formula-known) conditions.

========== paper_workflow entry 7 ==========
related_tool: CFM-ID
sample_description: The sample consisted of tandem mass spectral input data from the CASMI 2016 contest, comprising 312 training and 208 validation MS/MS spectra in *.MGF format. These spectra were acquired on a Q Exactive Plus Hybrid Quadrupole-Orbitrap mass spectrometer (Thermo Fisher) with <5 ppm mass accuracy and MS/MS resolution of 35,000 using electrospray ionization (ESI). Spectra were collected in stepped collision energies of 20, 35, and 50 eV. Only [M+H]+ (positive mode) and [M−H]− (negative mode) ion species were available. Spectral metadata included ChemSpider ID, compound name, monoisotopic mass, molecular formula, SMILES, InChI, and InChIKey. Candidate structures were retrieved from ChemSpider using a ±5 ppm mass search window, yielding 432,511 candidates for the training set and 258,808 for the validation set; candidate lists varied per spectrum from 1 (e.g., pentabromophenol) to up to 8,000 structures due to uneven mass distribution. Some initial candidate structures provided by CASMI organizers were erroneous (mismatched formula, SMILES, or InChIKey), and corrected ground-truth results were supplied post-deadline for evaluation.
complete_workflow_description: The research employed a comparative evaluation framework for four in silico fragmentation tools—CFM-ID, MS-FINDER, MetFragCL, and MAGMa+—applied to CASMI 2016 Category 2 (in silico fragmentation only). A custom Java application was developed to standardize input/output handling across tools, resolve structure conversion issues (e.g., salt forms, isotopic elements, radicals), and process result files; associated scripts and source code are publicly available at https://sourceforge.net/projects/insilico-fragmentation/. For CFM-ID: input consisted of experimental MGF spectra and CASMI-provided candidate SMILES/InChI lists; predictions used METLIN-trained models, ±5 ppm mass tolerance, and dot product scoring across three energy levels. For MS-FINDER (v1.70): input required specially formatted MS1/MS2 files; internal databases (ExistStructureDB_vs8.esd and ExistFormulaDB_vs8.efd) were emptied to isolate pure in silico fragmentation performance, and a new database was constructed from CASMI candidate structures; settings included ±5 ppm mass accuracy and batch processing. For MetFragCL (v2.2-CL): a parameter file (detailed in Additional file 1: Table S2) governed fragmentation; candidate files were prepared via the Java application; fragment matching accounted for proton addition (positive mode) or removal (negative mode, −1.007 Da) to align theoretical fragments with observed charged peaks. For MAGMa+ (Python wrapper of MAGMa): an SQLite database was generated from CASMI-provided InChIs (via a modified process_hmdb.py script); spectral-tree files were created from CASMI peak lists and metadata using a custom Python script; annotation used the published substructure generation algorithm. Parameter optimization was first conducted on the 312-training-set spectra, followed by development of a voting/consensus model that integrated ranked outputs from multiple tools—optionally augmented with database lookups (ChemSpider, MS/MS libraries)—to produce improved rankings. All evaluations adhered to CASMI Category 2 guidelines: no secondary database ranking or external metadata was used in the baseline in silico assessment.
