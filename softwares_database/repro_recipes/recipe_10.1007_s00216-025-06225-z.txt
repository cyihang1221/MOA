paper_title: Exploring non-target screening variability in unsupervised multivariate time trend analysis of LC-HRMS data.
source_paper: Armin R et al. (2026), Analytical and bioanalytical chemistry, DOI: 10.1007/s00216-025-06225-z, PMID: 41284005
overall_reproducibility_score: 87/100

workflow_steps: 8
  Step 1: Feature extraction
    tool: MarkerView v. 1.3.1, MZmine3 v. 3.2.8, PatRoon v.2.1.0 with OpenMS, Sirius, XCMS3
    parameters: not_reported
    input: LC-HRMS raw data (.wiff) from SCIEX OS v. 1.7.0
    output: feature peak matrix (m/z, RT, intensity)
    confidence: medium
  Step 2: Near-zero variance filtering
    tool: caret R package
    algorithm: nearZeroVar
    parameters: freqCut=95/5, uniqueCut=8
    input: feature intensity matrix
    output: filtered feature matrix retaining features with ≥4 consecutive non-zero values across 52 time points
    confidence: high
  Step 3: Data normalization
    tool: MATLAB R2022a
    parameters: IS-based normalization, log transformation, row-wise total abundance normalization
    input: filtered feature matrix
    output: normalized, log-transformed, autoscaled matrix
    confidence: high
  Step 4: Procrustes alignment
    tool: MEDA toolbox (GitHub: josecamachop/MEDA-Toolbox)
    algorithm: Procrustes analysis
    parameters: not_reported
    input: software-derived feature matrices vs. SCIEX OS reference [M+H]+ target matrix
    output: Procrustes dissimilarity metric (d)
    confidence: medium
  Step 5: PCA
    tool: MEDA toolbox
    parameters: autoscaling applied, 10 PCs computed
    input: normalized feature matrix
    output: PCA scores, loadings, MEDA maps
    confidence: high
  Step 6: SPCA with Elastic Net regularization
    tool: SpaSM MATLAB toolbox (http://www2.imm.dtu.dk/projects/spasm/)
    algorithm: Zou's SPCA
    parameters: L1 sparsity=70–90%, L2 penalty=0.1–100, empirically tuned per dataset and compound
    input: autoscaled feature matrix
    output: sparse loadings, score plots, explained variance per PC
    confidence: high
  Step 7: Stratified bootstrapped SPCA (SBS-SPCA)
    tool: custom MATLAB script
    algorithm: stratified bootstrap (500 replicates) + SPCA
    parameters: stratification over 5-consecutive-time-point groups, L1/L2 grid search, selection frequency threshold=p<0.05
    input: autoscaled feature matrix
    output: robust marker list with bootstrap selection frequency and empirical p-values
    confidence: high
  Step 8: Feature ranking
    tool: MATLAB R2022a
    parameters: ranking by absolute SPCA loading value
    input: sparse loadings
    output: top-N ranked features per PC (e.g., top 10 for exploratory interpretation)
    confidence: high
