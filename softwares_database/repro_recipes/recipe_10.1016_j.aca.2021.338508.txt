    input: LC-IM-MS raw data (.d or vendor format)
    output: raw IM-DIA datasets (IM-AI and IM-QRAI)
    confidence: medium
  Step 2: Peak picking and feature detection
    tool: MS-DIAL
    algorithm: centroid-based peak detection
    parameters: min_peak_height=None, rt_tolerance_sec=None, mz_tolerance_ppm=None, min_time_span_sec=None
    input: raw IM-DIA datasets
    output: feature table (m/z, RT, DT, intensity)
    confidence: low
  Step 3: Feature alignment and isotopologue pair reconciliation
    tool: MS-DIAL
    algorithm: retention time and drift time alignment; natural vs U¹³C isotopologue matching
    parameters: rt_alignment_window_sec=None, dt_alignment_window_percent=0.3, isotopologue_mass_shift_da=1.00335, carbon_count_validation=True
    input: feature table
    output: aligned feature table with natC/U¹³C pairs
    confidence: medium
  Step 4: Fragment spectrum deconvolution from DIA data
    tool: MS-Finder
    algorithm: in-silico MS/MS prediction + spectral deconvolution
    parameters: precursor_ion_selection_method=quadrupole-resolved, fragmentation_energy_profile=None, library_search_mode=DIA-deconvoluted
    input: aligned feature table + raw DIA spectra
    output: deconvoluted MS/MS spectra per feature
    confidence: low
  Step 5: Metabolite identification and confidence-level annotation
    tool: MS-Finder + MS-DIAL + Skyline
    algorithm: multi-tiered identification (Level 1–3.2): standard matching, accurate mass, in-silico MS/MS, DT-CCS<sub>N2</sub> validation, carbon count confirmation
    parameters: level_1_criteria=reference standard match (RT, DT, MS/MS), level_3_2_criteria=accurate mass spectrum + confirmed carbon number via U¹³C labeling, dt_ccs_n2_tolerance_percent=0.3, carbon_count_validation_method=U¹³C isotopologue spacing
    input: deconvoluted MS/MS spectra + aligned features + U¹³C spike metadata
    output: annotated metabolite list (87 metabolites, Levels 1–3.2)
    confidence: high
  Step 6: Targeted re-extraction and quantitative validation
    tool: Skyline
    algorithm: targeted extraction of natC/U¹³C transitions with IM/RT/DT constraints
    parameters: extraction_window_rt_sec=None, extraction_window_dt_percent=0.3, extraction_window_mz_ppm=None, transition_type=precursor → fragment (DIA)
    input: raw IM-DIA datasets + annotated metabolite list
    output: quantitative peak areas (natC/U¹³C ratios)
    confidence: medium
