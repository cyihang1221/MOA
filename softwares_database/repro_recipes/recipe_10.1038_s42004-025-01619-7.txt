reproducibility_gaps:
  - Agilent IM-MS Browser and Mass Profiler are commercial tools requiring license and not accessible without Agilent hardware
  - No raw data accession IDs provided — only 'uploaded to PubChem' without specific dataset identifiers or deposition links
  - Instrumental settings detailed only in 'Supporting Information File' (not provided in text), limiting full parameter reproducibility
  - No code or scripts shared for trendline fitting, manual verification logic, or class assignment
  - Chemical class assignment relies on 'expert judgement' without standardized ontology or reproducible rules
reproducibility_strengths:
  - Highly specific experimental parameters reported (e.g., 17 V/cm, 3.95 torr N₂, 78.24 cm drift tube)
  - Explicit QC criteria: ≤1% intra-lab CCS error, ≤10 ppm mass error, isotopic pattern validation
  - Public deposition of CCS values in PubChem enables external access and reuse
  - Use of standardized calibrants (Agilent Tune Mix) and published single-field method enhances cross-lab reproducibility
