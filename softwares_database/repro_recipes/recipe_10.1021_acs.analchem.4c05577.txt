  Step 3: Data conversion and preprocessing
    tool: vendor software or open-source tools
    parameters: conversion_target=mzML or vendor-native format, peak_picking_strategy=automatic, intensity_threshold_range=varied across teams (SI-01 Figure S10), isotopic_filtering=True, blank_filtering_strategy=['qualitative (n-blank detection)', 'quantitative (sample/blank area ratio)']
    input: raw .raw files
    output: feature table (m/z, RT, intensity)
    confidence: medium
  Step 4: Feature filtering and quality control
    tool: custom scripts / Excel / manual curation
    parameters: rt_window_min=0.8, rt_window_max=9.0, rstd_triplicate_cutoff_percent=30, msms_required=True, isotope_count_minimum=2, blank_removal=True, peak_picking_consensus=organizing team's peak-picking result used as reference
    input: feature table
    output: curated feature table (768 features)
    confidence: high
  Step 5: Ion species assignment
    tool: published fragment/complex list + manual curation
    algorithm: mass difference matching
    parameters: mass_tolerance_ppm=5, ion_notation_standard=[M+X±neutral]+, reference_list=SI-04 putative fragments/complexes
    input: feature table + MS/MS spectra
    output: ion species-annotated feature table
    confidence: high
  Step 6: Chemical class assignment
    tool: NP Classifier API (vnot specified)
    algorithm: machine learning-based chemical classification
    parameters: input_format=SMILES, source_conversion=InChI → SMILES via GNPS API, taxonomy_source=['LOTUS', 'KNApSAcK', 'HMDB', 'literature']
    input: InChI or InChIKey
    output: chemical class (e.g., steroidal glycoside)
    confidence: high
  Step 7: Structural annotation and consensus building
    tool: SIRIUS 5.6.3 (v5.6.3)
    algorithm: fragmentation pattern prediction + molecular formula inference
    parameters: msms_library_matching=False, taxonomic_context_filtering=True, reference_standards_used=18, confidence_scoring={'level_1A': 'confirmed by standard', 'level_2': 'participant-reported high confidence (e.g., internal DB)', 'level_3': 'refined via fragmentation prediction', 'level_5': 'in-source feature'}
    input: MS/MS spectra + m/z + RT
    output: Consensus Annotation Table (142 analytes, 13 confirmed)
    confidence: high
  Step 8: Annotation agreement quantification
    tool: Excel + custom logic
    algorithm: Annotation Agreement Score
    parameters: element_1=feature reported (RT ±0.05 min, m/z ±0.003), element_2=ion species description, element_3=chemical class (NP Classifier), element_4=2D structure identity (InChI), score_formula=Occurrence(A_j,i) / AssignmentMatch(j)
    input: Merged Annotation Table (768 rows)
    output: Annotation Agreement Scores per feature per element
    confidence: high
  Step 9: Interlaboratory performance scoring
    tool: Excel + custom logic
    algorithm: binary agreement scoring
    parameters: scoring_elements=['feature', 'ion species', 'chemical class', 'identity'], match_criteria=exact match to consensus annotation, analyte_level_reduction=True
    input: team-specific annotations vs Consensus Annotation Table
    output: per-team agreement scores (feature- and analyte-level)
    confidence: high
