  Step 2: Supervised machine learning classification
    tool: Random Forest
    algorithm: Random Forest
    parameters: robustness_against_overfitting=True, high_prediction_accuracy=True, handles_large_number_of_variables=True
    input: MCR-ALS-derived spatial pattern features + manually labeled training data (inner/outer medulla, cortex)
    output: tissue-type classification map (histological distribution prediction)
    confidence: medium
  Step 3: Unsupervised clustering (CLARA)
    tool: CLARA
    algorithm: Clustering Large Applications
    parameters: optimized_number_of_clusters=6
    input: dimensionality-reduced MSI data (t-SNE implied, though not explicitly applied in step description)
    output: six-cluster spatial segmentation map
    confidence: medium
  Step 4: Unsupervised clustering (DBSCAN)
    tool: DBSCAN
    algorithm: Density-based Spatial Clustering of Applications with Noise
    parameters: number_of_clusters=7
    input: dimensionality-reduced MSI data (t-SNE implied)
    output: seven-cluster spatial segmentation map
    confidence: medium
