    output: normalized and scaled feature table
    confidence: medium
  Step 7: Univariate statistical analysis
    tool: MetaboAnalyst
    algorithm: t-test / ANOVA with FDR correction

    input: normalized feature table
    output: list of significantly differential features
    confidence: high
  Step 8: Multivariate statistical analysis
    tool: MetaboAnalyst
    algorithm: PLS-DA and OPLS-DA
    parameters: n_components=2, n_permutations=200, validation_method=permutation test
    input: normalized feature table
    output: model metrics, VIP scores, score plots
    confidence: high
  Step 9: Metabolite annotation
    tool: XCMS Online / HMDB / METLIN / MassBank
    algorithm: MS1-based matching + retention time index filtering
    parameters: mass_tolerance_ppm=10, rt_tolerance_sec=15
    input: differential features (m/z, RT)
    output: putatively annotated metabolites
    confidence: medium
  Step 10: Compound similarity network (CSN) construction
    tool: Custom R/Python pipeline
    algorithm: Tanimoto similarity on Morgan fingerprints (ECFP4)
    parameters: similarity_threshold=0.6, fingerprint_radius=2, n_bits=2048
    input: annotated metabolites (SMILES or InChI)
    output: compound similarity network (graph)
    confidence: low
  Step 11: Metabolic pathway reconstruction
    tool: KEGG Mapper / RetroRules
    algorithm: reaction template matching + shortest path search
    parameters: max_path_length=3, template_score_threshold=0.7
    input: CSN subnetworks + KEGG compound IDs
    output: disease-relevant metabolic subpathways
    confidence: medium
