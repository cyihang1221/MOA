paper_title: Peak learning of mass spectrometry imaging data using artificial neural networks.

overall_reproducibility_score: 78/100

workflow_steps: 6
  Step 1: Data import and format conversion
    tool: SCiLS Lab (v2019c)
    input: raw vendor files (e.g., .tdf, .imzML)
    output: imzML files
    confidence: high
  Step 2: Format standardization for deep learning
    tool: Custom HDF5 conversion
    algorithm: HDF5 serialization
    input: imzML files
    output: HDF5 files
    confidence: medium
  Step 3: Unsupervised spectral representation learning
    tool: Variational Autoencoder (VAE)
    algorithm: Fully connected VAE with reparameterization trick
    parameters: latent_dim_k=None, input_dim_d=None, encoder_architecture=fully_connected, decoder_loss=cross_entropy, kl_weight=1.0, beta_range=[1, 2.5], weight_threshold_formula=mean(w) + beta * std(w)
    input: HDF5 spectra (N × d matrix)
    output: latent encoded features (N × k matrix)
    confidence: low
  Step 4: Informative m/z peak identification
    tool: Weight-based threshold analysis
    algorithm: Layer-wise weight magnitude thresholding
    parameters: beta=1 to 2.5, threshold_formula=T = mean(w_dj^(1)) + beta * std(w_dj^(1))
    input: VAE weight matrices W^(1), W^(2)
    output: list of informative m/z bins → mapped to local maxima on average spectrum
    confidence: medium
  Step 5: Spatial pattern clustering
    tool: Gaussian Mixture Model (GMM)
    algorithm: Expectation-Maximization
    parameters: n_components_k=user-tunable or BIC-optimized, covariance_type=full, init_params=kmeans
    input: latent encoded features (N × k matrix)
    output: spatial cluster assignments (N × 1 vector)
    confidence: medium
  Step 6: m/z–cluster correlation
    tool: Pearson correlation
    algorithm: Pearson linear correlation
    parameters: correlation_target=reduced peak list intensities vs cluster probability scores
    input: cluster assignment probabilities + MSI intensity matrix (N × p)
    output: ranked list of colocalized m/z peaks per cluster
    confidence: high
