sample_description: The study used the rice diversity panel 1 (RDP1), consisting of 421 purified homozygous rice varieties representing five subgroups: indica (IND), aus (AUS), tropical japonica (TRJ), temperate japonica (TEJ), and aromatic (ARO). For GPWAS, an additional 15 individuals were filtered out due to severe missing phenotypic data, resulting in 391 individuals with 27 available phenotypic traits. Phenotypic data—including six target panicle architecture traits (TSNP, GNP, EGNP, PBN, PL, PN) and 21 additional agronomic traits—were downloaded from the USDA Dale Bumpers National Rice Research Center website. Missing phenotypic values were imputed using the median value per trait. Genotype data underwent quality control in PLINK (minor allele frequency ≥0.05 and sample integrity ≥0.6), yielding 411,066 high-quality SNPs, which were subsequently imputed using Beagle 5.0. Gene annotation was based on the RAP-DB 2020-06-03 version (37,860 genes); SNPs were assigned to genes, intergenic SNPs were removed, and longest transcripts were selected in case of gene overlap.
software_configuration_description: BLINK (Bayesian-information and Linkage-disequilibrium Iteratively Nested Keyway) was employed as one of four multivariate GWAS methods (alongside GLM, MLM, and FarmCPU) for association analysis of six panicle architecture traits (TSNP, GNP, EGNP, PBN, PL, PN) in the 406 RDP1 accessions using 411,066 high-quality SNPs. BLINK was implemented via the Genomic Association and Prediction Integrated Tool (GAPIT). The first three principal components (PCs) derived from PCA were included as covariates to correct for population structure. The genome-wide significance threshold was set at p = 1.22E-07, calculated using the Bonferroni correction (0.05/n, where n = number of markers). Manhattan and QQ plots for BLINK results were generated using the R package 'qqman'. LD blocks surrounding significant peaks were defined using the Solid Spine (SS) method, and LD heatmaps were constructed using 'LDBlockShow' in the R package.
