<section id="sec1"><h3 class="pmc_sec_title">Background</h3>
<p>Non-targeted metabolomics based on mass spectrometry enables high-throughput profiling of the metabolites in a biological sample. The large amount of data generated from mass spectrometry requires intensive computational processing for annotation of mass spectra and identification of metabolites. Computational analysis tools that are fully integrated with multiple functions and are easily operated by users who lack extensive knowledge in programing are needed in this research field.</p></section><section id="sec2"><h3 class="pmc_sec_title">Results</h3>
<p>We herein developed an R package, metaX, that is capable of end-to-end metabolomics data analysis through a set of interchangeable modules. Specifically, metaX provides several functions, such as peak picking and annotation, data quality assessment, missing value imputation, data normalization, univariate and multivariate statistics, power analysis and sample size estimation, receiver operating characteristic analysis, biomarker selection, pathway annotation, correlation network analysis, and metabolite identification. In addition, metaX offers a web-based interface (<a href="http://metax.genomics.cn/" class="usa-link usa-link--external" data-ga-action="click_feat_suppl" target="_blank" rel="noopener noreferrer">http://metax.genomics.cn</a>) for data quality assessment and normalization method evaluation, and it generates an HTML-based report with a visualized interface. The metaX utilities were demonstrated with a published metabolomics dataset on a large scale. The software is available for operation as either a web-based graphical user interface (GUI) or in the form of command line functions. The package and the example reports are available at <a href="http://metax.genomics.cn/" class="usa-link usa-link--external" data-ga-action="click_feat_suppl" target="_blank" rel="noopener noreferrer">http://metax.genomics.cn/</a>.</p></section><section id="sec3"><h3 class="pmc_sec_title">Conclusions</h3>
<p>The pipeline of metaX is platform-independent and is easy to use for analysis of metabolomics data generated from mass spectrometry.</p></section><section id="sec4"><h3 class="pmc_sec_title">Electronic supplementary material</h3>
<p>The online version of this article (doi:10.1186/s12859-017-1579-y) contains supplementary material, which is available to authorized users.</p></section><section id="kwd-group1" lang="en" class="kwd-group"><p><strong>Keywords:</strong> Metabolomics, Pipeline, Workflow, Quality control, Normalization</p></section></section><section id="Sec1"><h2 class="pmc_sec_title">Background</h2>
<p>Biochemicals (metabolites) with low molecular masses are the ultimate products of biological metabolism, while a metabolome represents the total composite in a given biological system and reflects the interactions among an organism’s genome, gene expression status and the relevant micro-environment [<a href="#CR1" class="usa-link" aria-describedby="CR1">1</a>]. The most prevalent technology used in analysis of metabolomics is non-targeted mass spectrometry (MS) coupled with either liquid chromatography (LC-MS) or gas chromatography (GC-MS) [<a href="#CR2" class="usa-link" aria-describedby="CR2">2</a>, <a href="#CR3" class="usa-link" aria-describedby="CR3">3</a>]. Generally, these techniques generate a set data of mass spectra with chromatography that includes retention time, peak intensity and chemical masses. Data analysis involves stepwise procedures including peak picking, quality control, data cleaning, preprocessing, univariate and multivariate statistical analysis and data visualization. A number of software packages are available for MS-based metabolomics data analysis as listed in Table <a href="#Tab1" class="usa-link">1</a>, including propriety commercial, open-source, and online workflows. The MS manufacturers generally provide propriety software, like SIEVE (Thermo Scientific), MassHunter (Agilent Technologies) and Progenesis QI (Waters), which are often limited in scope and function. Open-source software, such as XCMS [<a href="#CR4" class="usa-link" aria-describedby="CR4">4</a>], CAMERA [<a href="#CR5" class="usa-link" aria-describedby="CR5">5</a>], MAIT [<a href="#CR6" class="usa-link" aria-describedby="CR6">6</a>], MetaboAnalyst [<a href="#CR7" class="usa-link" aria-describedby="CR7">7</a>] and Workflow4Metabolomics [<a href="#CR8" class="usa-link" aria-describedby="CR8">8</a>], usually cover limited processing steps. There is no such comprehensive pipeline that is used across the metabolomics community [<a href="#CR9" class="usa-link" aria-describedby="CR9">9</a>, <a href="#CR10" class="usa-link" aria-describedby="CR10">10</a>]. Referring to the capabilities of the tools mainly used (as shown in Table <a href="#Tab1" class="usa-link">1</a>), an automatic and comprehensive open source pipeline is urgent in bioinformatics analysis of metabolomics. Basically, the pipeline aims for users to easily perform end-to-end metabolomics data analysis with a flexible combination of different methods to efficiently integrate new modules and to build customized pipelines in multiple ways.
</p>

<div class="p text-right font-secondary"><a href="table/Tab1/" class="usa-link" target="_blank" rel="noopener noreferrer">Open in a new tab</a></div></section><p>We herein developed a comprehensive workflow for analysis of metabolomics data, termed metaX. At the present time, R [<a href="#CR11" class="usa-link" aria-describedby="CR11">11</a>] is a popular statistical programming environment and provides a convenient environment for statistical analysis of metabolomic and other -omics data [<a href="#CR12" class="usa-link" aria-describedby="CR12">12</a>, <a href="#CR13" class="usa-link" aria-describedby="CR13">13</a>]. We thus designed metaX as an R package that automates analysis of untargeted metabolomics data acquired from LC/MS or GC/MS and offers a user-friendly web-based interface for data quality assessment and normalization evaluation. This workflow, which is open source and rich in functions, encourages experienced programmers to improve the relevant functions or to build their own pipeline within the R framework. Overall, metaX aims to be a tool array that utilizes an end-to-end statistical analysis of metabolomics data.</p></section><section id="Sec2"><h2 class="pmc_sec_title">Implementation</h2>
<p>A stepwise overview of data processing using metaX is illustrated in Fig. <a href="#Fig1" class="usa-link">1</a>.

<figcaption><p>Overview of metaX. This figure summarizes the main modules, functions and features of metaX. The input data and the functions are included in the figure</p></figcaption></figure><section id="Sec3"><h3 class="pmc_sec_title">Peak picking and inputs</h3>
<p>In general, metaX can take mzXML files as input or a peak table file as input. If taking mzXML files as input, metaX will use the R package XCMS [<a href="#CR4" class="usa-link" aria-describedby="CR4">4</a>] to detect peaks, then use the CAMERA [<a href="#CR5" class="usa-link" aria-describedby="CR5">5</a>] package to perform peak annotation. If a peaks table file is an input, metaX transforms the table data from a peak detection software, such as Progenesis QI (exported comma separated value (csv) format file), into an R object compatible with the subsequent workflow.</p></section><section id="Sec4"><h3 class="pmc_sec_title">Pre-processing of raw peak data metabolite</h3>
<p>The raw peak intensity data was pre-processed in metaX. Firstly, if a metabolite feature is detected in &lt; 50% of quality control (QC) samples or detected in &lt; 20% of experimental samples, it is removed from data analysis [<a href="#CR14" class="usa-link" aria-describedby="CR14">14</a>]. Secondly, a missing value after the first filtering is retained and imputed. In metaX, four methods are implemented to perform missing value imputation: k-nearest neighbor (KNN), Bayesian principal component analysis replacement (BPCA), svdImpute and random forest imputation (missForest) [<a href="#CR15" class="usa-link" aria-describedby="CR15">15</a>].</p></section><section id="Sec5"><h3 class="pmc_sec_title">Data scaling and transformation</h3>
<p>Five different scaling approaches are offered in metaX: Pareto scaling, vast scaling, range scaling, autoscaling and level scaling [<a href="#CR16" class="usa-link" aria-describedby="CR16">16</a>]. The formulas of these scaling approaches are described in detail elsewhere [<a href="#CR16" class="usa-link" aria-describedby="CR16">16</a>]. In addition, three transformation approaches are offered in metaX: log, generalized logarithm (glog) and cube root transformation.</p></section><section id="Sec6"><h3 class="pmc_sec_title">Removal of outliers</h3>
<p>metaX provides the ability to automatically remove the outlier samples in the pre-processed data based on expansion of the Hotelling’s T2 distribution ellipse [<a href="#CR17" class="usa-link" aria-describedby="CR17">17</a>]. A sample within the first and second component principal component analysis (PCA) score plot beyond the expanded ellipse is removed, and then the PCA model is recalculated. In default mode, three rounds of outlier removal are performed.</p></section><section id="Sec7"><h3 class="pmc_sec_title">Normalization</h3>
<p>A metabolomics dataset usually contains unwanted variations introduced by signal drift/attenuation and multiplicative noise across the dynamic range. These effects can detrimentally impact the significant signal discovery and MS features that are required for rigorous quality assurance [<a href="#CR14" class="usa-link" aria-describedby="CR14">14</a>, <a href="#CR18" class="usa-link" aria-describedby="CR18">18</a>]. In metaX, two types of normalization methods are provided: 1) Sample-based normalization is used to correct different concentrations of samples, such as normalization to total sum, probabilistic quotient normalization (PQN), variance stabilizing normalization (VSN) and quantile-based methods. 2) Peak-based normalization is implemented to correct data within batch experiment analytical variation and batch-to-batch variation in large-scale studies [<a href="#CR19" class="usa-link" aria-describedby="CR19">19</a>]. In this normalization, if a study contains QC samples, the QC-robust spline batch correction (QC-RSC) can be used to alleviate the effects of peak area attenuation [<a href="#CR19" class="usa-link" aria-describedby="CR19">19</a>]. During normalization, the degree of smoothening is controlled by a parameter that sets the proportion of points for smoothening at each point, while in metaX, this parameter is automatically assigned by using leave-one-out cross validation. On the basis of QC samples, a metabolite feature with a coefficient of variation (CV) over the predetermined value is excluded after normalization. The CV threshold could be set by users; generally, CV values ≤ 30% are recommended. Support vector regression (SVR) [<a href="#CR20" class="usa-link" aria-describedby="CR20">20</a>] and ComBat [<a href="#CR21" class="usa-link" aria-describedby="CR21">21</a>] normalization methods are also implemented in metaX. A user-friendly web-based interface (<a href="http://metax.genomics.cn/" class="usa-link usa-link--external" data-ga-action="click_feat_suppl" target="_blank" rel="noopener noreferrer">http://metax.genomics.cn</a>) was offered for rapid evaluation of the data normalization methods for a specified dataset.</p></section><section id="Sec8"><h3 class="pmc_sec_title">Assessment of data quality</h3>
<p>Pre- and post-normalization, the data quality is visually assessed in several aspects, 1) the peak number distribution, 2) the number of missing value distribution, 3) the boxplot of peak intensity, 4) the total peak intensity distribution, 5) the correlation heatmap of QC samples if available, 6) the metabolite m/z (or mass) distribution, 7) the plot of m/z versus retention time, and 8) the PCA score or loading plot of all samples. There are two ways to perform data quality assessment in metaX, the command line mode and the user-friendly web-based interface at <a href="http://metax.genomics.cn/" class="usa-link usa-link--external" data-ga-action="click_feat_suppl" target="_blank" rel="noopener noreferrer">http://metax.genomics.cn/</a>.</p></section><section id="Sec9"><h3 class="pmc_sec_title">Univariate and multivariate statistical analysis</h3>
<p>metaX offers both univariate and multivariate statistical analysis. For univariate statistical analysis, the parametric statistical test (Students t-test), non-parametric statistical test (Mann-Whitney U test), and classical univariate receiver operating characteristic (ROC) curve analysis are implemented. For multivariate statistical analysis, metaX offers functionalities for cluster analysis, multivariate modelling, including PCA, partial least squares-discriminant analysis (PLS-DA) and orthogonal partial least squares-discriminant analysis (OPLS-DA), with numerical and graphical results and diagnostics (optimal number of components estimated by cross-validation, R<sup>2</sup>, Q<sup>2</sup>, variable importance in projection (VIP), statistical significance of the model by permutation testing) [<a href="#CR22" class="usa-link" aria-describedby="CR22">22</a>]. In terms of the univariate test analysis, metaX also offers the false discovery rate (FDR)-corrected <em>p</em>-value by using the Benjamini-Hochberg FDR algorithm [<a href="#CR23" class="usa-link" aria-describedby="CR23">23</a>]. The PLS-DA was implemented based on the functions from the pls package [<a href="#CR24" class="usa-link" aria-describedby="CR24">24</a>], and the OPLS-DA was performed using the functions from the ropls package [<a href="#CR25" class="usa-link" aria-describedby="CR25">25</a>].</p></section><section id="Sec10"><h3 class="pmc_sec_title">Power and sample size analysis</h3>
<p>metaX offers an easy-to-use function to perform the power and sample size analysis. This function is based on the Bioconductor package SSPA [<a href="#CR26" class="usa-link" aria-describedby="CR26">26</a>] and outputs a figure to show the distribution curve of sample size versus the estimated power.</p></section><section id="Sec11"><h3 class="pmc_sec_title">Metabolite correlation network analysis</h3>
<p>metaX offers two types of network analysis. One is the correlation network analysis without regard for experimental groups information, and the other is differential correlation network analysis, which aims to identify metabolite correlation differences in a physiological state. The former was implemented using the cor function from the stats package to calculate the correlation coefficient, and the latter was implemented using the function comp.2.cc.fdr from the DiffCorr package [<a href="#CR27" class="usa-link" aria-describedby="CR27">27</a>] to calculate the significantly differential correlations. The igraph package [<a href="#CR28" class="usa-link" aria-describedby="CR28">28</a>] was used for network analysis and visualization. In addition, the network can be exported as a file in formats such as gml and pajek, which can be imported into Cytoscape [<a href="#CR29" class="usa-link" aria-describedby="CR29">29</a>] and Gephi [<a href="#CR30" class="usa-link" aria-describedby="CR30">30</a>] for network analysis and visualization. Both of the correlation network analyses aim to describe the correlation patterns among metabolites across samples, in which nodes represent metabolites and edges represent the correlation between different metabolites. The network analysis offers a complementary method to univariate and multivariate statistical analysis methods.</p></section><section id="Sec12"><h3 class="pmc_sec_title">Metabolite identification</h3>
<p>Currently, metaX provides a function for metabolite identification based on the Human Metabolome Database (HMDB) [<a href="#CR31" class="usa-link" aria-describedby="CR31">31</a>], KEGG [<a href="#CR32" class="usa-link" aria-describedby="CR32">32</a>, <a href="#CR33" class="usa-link" aria-describedby="CR33">33</a>], MassBank [<a href="#CR34" class="usa-link" aria-describedby="CR34">34</a>], PubChem [<a href="#CR35" class="usa-link" aria-describedby="CR35">35</a>], LIPID MAPS [<a href="#CR36" class="usa-link" aria-describedby="CR36">36</a>], MetaCyc [<a href="#CR37" class="usa-link" aria-describedby="CR37">37</a>] and PlantCyc (<a href="http://www.plantcyc.org/" class="usa-link usa-link--external" data-ga-action="click_feat_suppl" target="_blank" rel="noopener noreferrer">www.plantcyc.org</a>). Moreover, metaX can easily be extended to support the other databases. The metabolites having molecular weights within a specified tolerance to the query m/z or molecular weight value are retrieved from the databases as putative identifications. The information of adducts and isotopes is utilized to assist in metabolite identification if it is present. The default tolerance is 10 ppm.</p></section><section id="Sec13"><h3 class="pmc_sec_title">Functional analysis</h3>
<p>At present, metaX provides a function for metabolite pathway analysis based on IMPaLA [<a href="#CR38" class="usa-link" aria-describedby="CR38">38</a>].</p></section><section id="Sec14"><h3 class="pmc_sec_title">Biomarker analysis</h3>
<p>metaX uses functions from the R package “caret” to perform the biomarker selection, model creation and performance evaluation [<a href="#CR39" class="usa-link" aria-describedby="CR39">39</a>]. Currently, two methods, random forest [<a href="#CR40" class="usa-link" aria-describedby="CR40">40</a>] and support vector machine (SVM), are implemented to automatically select the metabolites which show the best performance. After the best set features are selected, a randomForest model can be created and the ROC curve can be plotted.</p></section><section id="Sec15"><h3 class="pmc_sec_title">HTML-based report generation</h3>
<p>metaX outputs an HTML-based report by using the Nozzle package [<a href="#CR41" class="usa-link" aria-describedby="CR41">41</a>], which contains quality assessment plots and other analysis results.</p></section></section><section id="Sec16"><h2 class="pmc_sec_title">Results and discussion</h2>
<p>To illustrate the applications of metaX, a published non-targeted LC-MS metabolomics dataset from a coronary heart disease (CHD) study was used [<a href="#CR42" class="usa-link" aria-describedby="CR42">42</a>, <a href="#CR43" class="usa-link" aria-describedby="CR43">43</a>]. The dataset consisted of two batches of 138 plasma samples (59 CHD patients, 43 healthy controls and 36 QC samples) acquired in positive ion mode on an LTQ Orbitrap Velos instrument (Thermo Fisher Scientific, MA, USA). LC-MS raw data files were converted to mzXML format using ProteoWizard (version 3.0.5941) [<a href="#CR44" class="usa-link" aria-describedby="CR44">44</a>] and then were processed by XCMS [<a href="#CR4" class="usa-link" aria-describedby="CR4">4</a>] and CAMERA [<a href="#CR5" class="usa-link" aria-describedby="CR5">5</a>] for peak picking and peak annotation, respectively. In total, 1438 features were retained for downstream analysis. The mzXML files can be downloaded from the Dryad Digital Repository [<a href="#CR43" class="usa-link" aria-describedby="CR43">43</a>]. It merits to note that the study focus is mainly on the software application and its capabilities, not on the biological interpretation of the generated results.</p>
<section id="Sec17"><h3 class="pmc_sec_title">Quality assessment of metabolomics data using metaX</h3>
<p>In metabolomics studies, data quality checks are crucial prerequisites to achieve reliable results. metaX offers a quick and easy data quality check of metabolomics data. This can be done using the R function in metaX or a user-friendly web interface at the website <a href="http://metax.genomics.cn/" class="usa-link usa-link--external" data-ga-action="click_feat_suppl" target="_blank" rel="noopener noreferrer">http://metax.genomics.cn/</a> as shown in Fig. <a href="#Fig2" class="usa-link">2</a>. The mainly QC charts generated by metaX for the CHD dataset are illustrated in Figs. <a href="#Fig3" class="usa-link">3</a> and <a href="#Fig4" class="usa-link">4</a>. The number of features detected per sample over the analysis time (injection order) is illustrated in Fig. <a href="#Fig4" class="usa-link">4c</a>, revealing that the peaks acquired from any group, disease, healthy and QC, are randomly distributed. The intensities of all features per samples before and after normalization over the analysis time (injection order) are illustrated in Fig. <a href="#Fig3" class="usa-link">3a and b</a>, respectively. The missing value distribution is shown in Fig. <a href="#Fig3" class="usa-link">3e</a>, which gives an overview of the percent of missing values of all features in both the QC and experiment samples. According to Chawade’s view, the total missing value plot and the total intensity plot derived from raw data and treated with/without normalization could be used to identify sample outliers [<a href="#CR45" class="usa-link" aria-describedby="CR45">45</a>]. Our analysis supported this. The correlation plots of QC samples before and after normalization by SVR are illustrated in Fig. <a href="#Fig3" class="usa-link">3c and d</a> and indicate that the lowest correlation efficiency is enhanced from approximately 0.7 to 0.9. The CV distribution of all features before and after normalization for each group is displayed in Fig. <a href="#Fig3" class="usa-link">3f</a>, implying that after normalization, the signal quality is obviously improved. The sum intensity of all features per sample before and after normalization over the analysis time (injection order) is illustrated in Fig. <a href="#Fig4" class="usa-link">4a and b</a>, suggesting that normalization could narrow the signal variation. The score plots of PCA for the raw feature intensity data and the normalized data are shown in Fig. <a href="#Fig4" class="usa-link">4d and e</a>, respectively, which give an overview of the dataset and showing trends, groupings and outliers before data normalization and after data normalization. The score plot of PCA (Fig. <a href="#Fig4" class="usa-link">4d</a>) for the non-normalized data provided a simple and easily interpretable visual check of the presence of batch effects. In Fig. <a href="#Fig4" class="usa-link">4d</a>, the two data batches appear as two separated groups upon PCA analysis without normalization, whereas in Fig. <a href="#Fig4" class="usa-link">4e</a>, after normalization the batch effect was reduced and all of the QC samples were clustered tightly, which provides an initial evaluation of the data quality. Overall, these QC charts demonstrate the necessity of normalization for metabolomics data, while metaX enables overview of the data quality with different charts.

<p>A systematic bias in high-throughput metabolomics data is often introduced by various steps of sample processing and data generation. Data normalization can reduce systematic biases. A question related to this issue is how to select a proper normalization method. metaX provides a user-friendly web-based Shiny application (<a href="http://metax.genomics.cn/" class="usa-link usa-link--external" data-ga-action="click_feat_suppl" target="_blank" rel="noopener noreferrer">http://metax.genomics.cn</a>) for this purpose. To select the optimal normalization approach for the CHD dataset, seven methods are evaluated using metaX. Figure <a href="#Fig5" class="usa-link">5</a> shows the score plots of PCA using different normalization methods. They indicate that after normalization using QC-RSC, ComBat or SVR, all of the QC samples are clustered more tightly, and the batch effect is effectively reduced compared with other methods. Table <a href="#Tab2" class="usa-link">2</a> presents the quantitative comparison metrics acquired by the different methods. From the results it is clear that all normalization methods performed better than non-normalization used in most of the metrics. Specifically, SVR detects the largest number of features (1293) with CV ≤ 30% in QC samples, followed by QC-RSC (1191). For the average CV of features in QC samples, SVR achieved the best performance, followed by QC-RSC. This is similar to the findings in a previous study [<a href="#CR20" class="usa-link" aria-describedby="CR20">20</a>]. However, QC-RSC could detect the largest number of differentially expressed features (178), followed by SVR (170). Taken together, for this data set, SVR could be an optimal normalization method, thus it was chosen as the default normalization method for the downstream analysis.

</div></div></section></section><section id="Sec19"><h3 class="pmc_sec_title">Univariate and multivariate statistical analysis</h3>
<p>Data for the QC samples are removed from the dataset prior to univariate and multivariate analysis in metaX. For univariate analysis, Mann-Whitney U test and Students t-test are performed to compare disease and health groups, followed by false discovery correction using the Benjamini-Hochberg method using metaX. The results, along with the fold change of the disease group versus health group, are presented in Additional file <a href="#MOESM1" class="usa-link">1</a>: Table S1. In total, 171 features (13.22% of total features) are detected under the criteria of the corrected <em>p</em>-value (Mann-Whitney U test) ≤ 0.05, fold change ≥ 1.5 or ≤ 0.667 and VIP &gt; =1, and 170 features (13.15% of total features) are detected under the criterion of the corrected <em>p</em>-value (Students t-test) ≤ 0.05, fold change ≥ 1.5 or ≤ 0.667 and VIP &gt; = 1. The result is comparable with that of the previous study [<a href="#CR42" class="usa-link" aria-describedby="CR42">42</a>].</p>
<p>For multivariate analysis, PCA, PLS-DA and OPLS-DA are performed by metaX. In PCA analysis, the normalized peak intensity matrix is glog transformed, followed by Pareto scaling and centering, and then two components are selected. The PCA score and loading plots are shown in Fig. <a href="#Fig6" class="usa-link">6a and b</a>, respectively. The score plot indicates that there is an apparent difference between the disease and health groups. For PLS-DA and OPLS-DA, the normalized peak intensity matrix is also glog transformed, followed by Pareto scaling and centering. Two components are selected for PLS-DA and two components (one orthogonal and one predictive) for OPLS-DA. The score and loading plots for PLS-DA and OPLS-DA are shown in Fig. <a href="#Fig7" class="usa-link">7a and c</a>, respectively. The R<sup>2</sup>Y and Q<sup>2</sup>Y values of the PLS-DA model, which are 0.908 and 0.854, respectively, indicate that the model has good goodness of fit and predictive ability. The R<sup>2</sup>Y and Q<sup>2</sup>Y values of the OPLS-DA model, which are 0.905 and 0.847, respectively, indicate that the model also has good goodness of fit and predictive ability. Overall, the two multivariate data analysis methods, PLS-DA and OPLS-DA, give similar results. To test the validity of the models of PLS-DA and OPLS-DA, a permutation test (<em>n</em> = 200) is performed. As shown in Fig. <a href="#Fig7" class="usa-link">7b and d</a>, the test indicated that the two models are valid, and the good predictive ability of the model is not because of over-fitting with a <em>p</em>-value less than 0.05. Taken together, the results of PCA and PLS-DA (or OPLS-DA) show a distinct separation between the disease and health groups.

<p>To create the classification model between the disease and health groups, the functions implemented in metaX are used to conduct the biomarker selection, model creation and performance evaluation. A recursive feature elimination algorithm with the random forest model is used to select the best feature set. During the treatment, 5-fold cross-validation is used to optimize the model and reduce over-fitting. As shown in Table <a href="#Tab3" class="usa-link">3</a>, 8 features were selected. To further evaluate the performance of the 8 selected features, the 102 samples were randomly split into two sample sets. One sample set (Disease: 29, Health 29) was for model building and the other (Disease: 14, Health 30) was for testing. Based on the two data sets, the 8 features were used to build a random forest model, and a receiver operating characteristic (ROC) curve of this model was plotted and is shown in Fig. <a href="#Fig8" class="usa-link">8</a>. The result indicated that the model based on the 8 features had a good result with an area under the ROC (AUROC) curve of 0.999. The 8 features were then identified based on the HMDB (version 3.6) database through metaX. Seven out of the 8 features were identified with a mass accuracy of &lt; 10 ppm (parts per million). The putative identified metabolites were then submitted to the IMPaLA website (version 9) through metaX to perform the pathway analysis, and the results are presented in Additional file <a href="#MOESM2" class="usa-link">2</a>: Table S2.

<p>Network-based correlation analysis is a complementary method to the traditional univariate and multivariate statistics that is taken in metabolomics analysis to identify metabolite changes in response to variable status of physiology. All of the features with the normalized intensity described above were used to perform the differential correction network analysis. This analysis can be used to detect the interconnection of metabolite pairs whose relationships are significantly altered due to the disease process. In this study, only the metabolite pairs that had significant differential correlations (<em>q</em>-value &lt; = 0.01) between the disease and health populations were used to build the network. As shown in Fig. <a href="#Fig9" class="usa-link">9</a>, of the network with 266 nodes and 444 edges, a giant component (198/266, 74.44%) was found and the community detection analysis using the fast greedy modularity optimization algorithm against this component resulted in seven communities, in which each one has equal to or greater than 10 nodes detected. In addition, metaX can estimate three centrality metrics (degree, closeness and betweenness) for each node, and they reflect the importance of the node in the entire network (Additional file <a href="#MOESM3" class="usa-link">3</a>: Table S3). Differentially correlation network analysis is expected to provide useful insights into the underlying biological processes of the clinical development of CHD.
</p>

<p>metaX presents a complete data processing software that is easy to operate and capable of dealing with large-scale metabolomics datasets. A metaX user can customize the pipeline according to the research requirements. Compared to software for metabolomics datasets that requires high-manual interaction, metaX requires much less manual interaction and can be used in a command line or web-based user-friendly interface. Based upon the fast process and the optimized workflow, therefore, metaX would greatly improve the interpretation of metabolomics data.</p></section><section id="sec27"><h2 class="pmc_sec_title">Additional files</h2>
