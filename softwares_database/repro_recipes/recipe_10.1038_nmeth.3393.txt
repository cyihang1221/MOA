  Step 1: Raw data preprocessing and spectral centroiding
    tool: MS-DIAL (v1.0 (2015))
    algorithm: centroiding
    parameters: centroiding_method=simple centroiding, mz_slice_width=0.1, mz_step_size=0.05
    input: profile-mode LC-MS/MS DIA raw files (.raw, .d, .mzML)
    output: centroided MS1 and MS/MS spectra
    confidence: high
  Step 2: Peak detection (spotting) on MS1 data
    tool: MS-DIAL (v1.0 (2015))
    algorithm: linearly weighted smoothing + differential calculus-based peak detection
    parameters: smoothing_method=linearly weighted smoothing average, amplitude_filter_percentile=5, first_derivative_filter_percentile=5, second_derivative_filter_percentile=5, minimum_amplitude_threshold=0.0001, derivative_approximation_points=5, mz_tolerance_for_merging=not explicitly quantified; 'close m/z value in adjacent bins'
    input: centroided MS1 data (base peak chromatograms)
    output: detected peak spots (RT-m/z-intensity table)
    confidence: high
  Step 3: MS/MS deconvolution (MS2Dec)
    tool: MS-DIAL (v1.0 (2015))
    algorithm: least squares model peak fitting with Gaussian derivative filter
    parameters: rt_extraction_window=±1.5 × peak width, ideal_slope_threshold=0.95, baseline_correction_segments=user-defined, baseline_correction_band_width=user-defined, model_peak_basis=['M1(n)', 'M2(n)', 'M3(n)'], ad_hoc_model_peak_selection=median sharpness among ideal slope = 1 candidates
    input: MS/MS chromatograms extracted per spot
    output: deconvolved, quantified MS/MS peak intensities per spot
    confidence: medium
  Step 4: Metabolite identification
    tool: MS-DIAL (v1.0 (2015))
    algorithm: multi-criteria scoring (RT, accurate mass, isotope ratio, MS/MS spectrum)
    parameters: mass_tolerance_ppm=None, rt_tolerance_seconds=None, isotope_similarity_formula_required=True, msms_similarity_weighting={'dot_product': 1, 'reverse_dot_product': 1, 'matched_fragments_ratio': 1}, weight_function=w = 1 / (1 + A / sum(A) - 0.5), total_score_denominator=3.5, total_score_isotope_weight=0.5, identification_threshold=user-defined
    input: deconvolved spots + reference library (NIST MSP format)
    output: annotated feature table with compound IDs and confidence scores
    confidence: low
  Step 5: Peak alignment across samples
    tool: MS-DIAL (v1.0 (2015))
    algorithm: Joint Aligner–inspired algorithm
    parameters: reference_file_selection=user-defined, rt_alignment_tolerance=None, mz_alignment_tolerance=None, missing_value_interpolation=enabled
    input: per-sample peak tables (RT, m/z, intensity)
    output: aligned feature table (consensus peaks across samples)
    confidence: low
