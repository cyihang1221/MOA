reproducibility_gaps:
  - AutoHX is commercial-grade software embedded in Mass Spec Studio — full source code not publicly available despite GitHub link pointing to limited wrapper/API repo
  - No detailed description of AutoHX's core algorithms (e.g., fragment alignment, scrambling correction model, combinatorial confidence scoring) — only conceptual overview provided
  - Instrument method files (.meth) and chromatographic gradient profiles (e.g., exact %B vs time) not deposited or fully specified
  - No public access to processed deuteration tables or intermediate feature tables (e.g., fragment-level deuteration matrices)
reproducibility_strengths:
  - Raw DIA/DDA data publicly available in PRIDE (PXD042187)
  - AutoHX version and DOI provided; GitHub repository linked with MIT license
  - All sample prep protocols, instrument parameters, and biological replicates explicitly described
  - Three distinct biological systems (Phosphorylase B, Polθ, DNA-PKcs) validate workflow robustness
