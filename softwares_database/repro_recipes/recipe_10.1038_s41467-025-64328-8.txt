  Step 1: Sample preparation and lipid extraction

    output: raw .raw files
    confidence: high
  Step 3: Lipid identification and peak detection
    tool: LipidSearch (v4.2)
    algorithm: full-scan + ddMS²-based identification
    parameters: identification_confidence_levels=['A', 'B', 'C'], snr_threshold=3, peak_quality_threshold=0.6, total_lipids_identified=2200, final_lipids_retained=343
    input: raw .raw files
    output: annotated lipid feature table (343 lipids)
    confidence: high
  Step 4: QC-based normalization
    tool: SERRF
    algorithm: QC-RLSC (retention time and signal correction)
    parameters: normalization_method=QC-based batch correction, log_transformation=log2
    input: LipidSearch feature table
    output: normalized, log2-transformed lipid abundance matrix
    confidence: medium
  Step 5: Covariate adjustment
    tool: R (stats package)
    algorithm: linear regression
    parameters: covariates_included=['age', 'sex', 'APOE-risk'], covariates_assessed_but_excluded=['pmi', 'race', 'education', 'BMI']
    input: normalized log2 lipid matrix
    output: covariate-adjusted lipid matrix
    confidence: high
  Step 6: Differential abundance analysis
    tool: R (stats package)
    algorithm: ['ANOVA', 'Tukey LSD', "Student's t-test"]
    parameters: comparisons=['Control vs AAD vs SAD', 'Control vs SAD', 'AAD vs SAD'], significance_threshold=0.05, post_hoc_tests=["Fisher's LSD", 'Tukey'], adjustment_method=none (main text); Benjamini-Hochberg FDR for enrichment tests
    input: covariate-adjusted lipid matrix
    output: differentially abundant lipids (p-values, fold-changes)
    confidence: high
  Step 7: Lipid set enrichment analysis
    tool: Lipidr
    algorithm: permutation-based enrichment scoring (GSEA-like)
    parameters: ranking_metric=log2 fold-change, background_set=all annotated lipids, query_set=hub lipids (MM > 0.60), fdr_threshold=0.05, test=one-sided Fisher exact test, enrichment_metrics=['chain length', 'unsaturation', 'lipid class']
    input: differentially abundant lipids + annotation
    output: enriched lipid sets and classes
    confidence: high
  Step 8: Weighted lipid co-expression network analysis (WGCNA)
    tool: WGCNA
    algorithm: signed co-expression network
    parameters: sample_n=314, power=7, scale_free_r2=0.979, network_type=signed, topologic_overlap_measure=component-wise average TO, clustering_distance=1 - TO (dissTom), tree_cut_method=dynamic hybrid, cut_height=0.99, deep_split=4, min_module_size=3, modules_detected=13, dimensionality_reduction=t-SNE (Rtsne), trait_correlation_method=Pearson, traits_analyzed=['Diagnosis', 'GlobalCogFunc', 'Reagan', 'Braak', 'CERAD', 'global pathology', 'amyloid', 'neurofibrillary tangle']
    input: normalized log2 lipid matrix
    output: lipid modules, module eigenlipids (MEs), module-trait correlations
    confidence: high
  Step 9: Multi-omics integration (lipid + protein modules)
    tool: mixOmics (DIABLO)
    algorithm: sparse PLS-based integrative analysis
    parameters: ncomp=3, validation=Mfold, folds=10, nrepeat=1, test_keepX=[5, 6, 7, 8, 9, 10, 12, 14, 16, 18, 20, 25, 30], performance_metric=mahalanobis.dist, balanced_error_rate_optimization=True, correlation_threshold=0.7, omics_inputs=['lipid modules', '30 proteomic modules', '5 clinical traits'], sample_n=266
    input: lipid module eigenvalues + protein module eigenvalues + clinical traits
    output: integrated multi-omics biomarker panel, cross-omic correlation network
    confidence: high
  Step 10: Omics-wide association (lipid-protein pairwise)
    tool: xMWAS
    algorithm: partial least squares regression
    parameters: association_method=PLS regression, correlation_threshold=0.5, p_value_threshold=0.05, statistical_test=Student's t-test, sample_n=313, input_types=['normalized lipid abundances', 'normalized protein abundances']
    input: normalized lipid + protein matrices
    output: lipid-protein association network
    confidence: medium
  Step 11: Protein functional enrichment
    tool: org.Hs.eg.db + AnnotationDbi
    algorithm: GO over-representation analysis
    parameters: identifier_conversion=UniProt → ENTREZ ID, enrichment_test=over-representation analysis, ontology=Gene Ontology (GO), multiple_testing_correction=Benjamini-Hochberg
    input: differentially expressed proteins (ENTREZ IDs)
    output: enriched GO terms
    confidence: high
