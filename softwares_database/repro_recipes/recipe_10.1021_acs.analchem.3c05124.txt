paper_title: ChloroDBPFinder: Machine Learning-Guided Recognition of Chlorinated Disinfection Byproducts from Nontargeted LC-HRMS Analysis.
source_paper: Zhao T et al., (2024), Analytical chemistry, DOI: 10.1021/acs.analchem.3c05124, PMID: 38294426
overall_reproducibility_score: 92/100

workflow_steps: 12
  Step 1: Raw data conversion to mzML
    tool: MSConvert version 3.0.22035
    parameters: not_reported
    input: Sciex wiff2 files
    output: mzML files
    confidence: high
  Step 2: Isotopic pattern simulation
    tool: enviPat R package
    algorithm: isopattern()
    parameters: error~U(0, 5) ppm, fluctuation~N(0, δ²), δ=11.8% for M+1, δ=15.8% for M+2,+3,+4
    input: theoretical monoisotopic mass and elemental composition
    output: simulated experimental MS spectra
    confidence: high
  Step 3: Molecular formula assignment
    tool: MassTools R package
    algorithm: calcMF()
    parameters: not_reported
    input: accurate m/z with simulated error
    output: candidate molecular formulas
    confidence: medium
  Step 4: Binary Cl-presence classification
    tool: randomForest R package version 4.3.0
    algorithm: random forest
    parameters: n.tree=500, mtry=sqrt(n.features), six engineered features from M, M+1, M+2 peaks
    input: simulated isotope patterns (M, M+1, M+2 intensities and masses)
    output: Cl-containing vs non-Cl prediction
    confidence: high
  Step 5: Multiclass Cl-count classification
    tool: randomForest R package version 4.3.0
    algorithm: random forest
    parameters: n.tree=500, mtry=sqrt(n.features), eleven engineered features from M, M+1, M+2, M+3, M+4 peaks
    input: simulated isotope patterns (M–M+4 intensities and masses)
    output: predicted number of Cl atoms (1, 2, or ≥3)
    confidence: high
  Step 6: Feature extraction and isotope averaging
    tool: XCMS R package (embedded in ChloroDBPFinder)
    algorithm: chromatographic peak averaging
    parameters: not_reported
    input: mzML files
    output: averaged MS1 spectra per feature
    confidence: medium
  Step 7: False positive filtering
    tool: ChloroDBPFinder internal algorithms
    algorithm: salt adduct, natural isotope, and in-source fragment removal
    parameters: not_reported
    input: Cl-containing features from ML classification
    output: high-quality Cl-DBP features
    confidence: medium
  Step 8: Spectral library search
    tool: ChloroDBPFinder internal function
    algorithm: dot product similarity
    parameters: MS/MS match number ≥4, dot product score ≥0.7
    input: experimental MS/MS spectra
    output: tentative compound annotations against NIST20
    confidence: high
  Step 9: Molecular networking (spectral similarity)
    tool: GNPS-based MS/MS similarity
    algorithm: cosine similarity
    parameters: cosine=0.7, minimum matched peaks=6, minimum cosine score=0.7
    input: MS/MS spectra of reference and unknown compounds
    output: spectral similarity network
    confidence: medium
  Step 10: Integrated molecular networking
    tool: ChloroDBPFinder internal implementation
    algorithm: combined spectral similarity + reaction connectivity
    parameters: not_reported
    input: reference compounds + unknown Cl-DBP features
    output: integrated network with dual-criteria edges
    confidence: medium
  Step 11: Reaction networking
    tool: ChloroDBPFinder internal implementation
    algorithm: mass shift–based transformation inference
    parameters: not_reported
    input: m/z pairs with plausible biotransformation mass shifts (e.g., +67.9224 Da for Cl₂/H₂ substitution)
    output: reaction network links
    confidence: medium
  Step 12: Quantitative confidence assessment
    tool: custom R script (implied)
    algorithm: linear correlation across injection volumes
    parameters: seven injection volumes: 2, 4, 6, 10, 13, 16, 20 μL
    input: feature intensities across triplicate injections at varying volumes
    output: correlation coefficient per feature (mean=0.98)
    confidence: high
