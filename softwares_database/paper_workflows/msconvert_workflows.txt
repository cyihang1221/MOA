related_tool: msconvert
sample_description: The samples used were grab samples taken from a wastewater treatment plant effluent in Warburg (Stadtwerke Warburg GmbH, Warburg, Germany), selected for non-target screening and centroiding algorithm development and validation. These effluent samples contain a high load of organic substances, inducing strong matrix-associated effects in high-resolution mass spectrometry (HRMS) such as signal overlay—making them ideal for rigorously testing the robustness of the centroiding algorithm. Sampling and sample preparation followed detailed protocols published by Hohrenk et al. (2020). The algorithm was developed and validated using both MS1 and MS2 spectra acquired in ESI-positive and ESI-negative modes; however, all examples presented in the paper specifically refer to MS1 spectra in ESI-positive mode. Notably, the chromatographic domain (i.e., retention time dimension) was deliberately neglected during algorithm development, as consecutive mass spectra were assumed to be statistically independent—ensuring the algorithm’s universal applicability to both chromatographically separated and direct-infusion HRMS data.
complete_workflow_description: The centroiding process is implemented as a platform-independent algorithm available in Python (v3.9), R (v4.0.4), and Julia (v1.6.3), with third-party packages automatically installed via a ready-to-use application (listed in Supplementary Table S3). The workflow comprises: (1) Input of profile-mode *.mzXML spectra; (2) Peak isolation by detecting zero-intensity regions (for resolved peaks) and valley points (for splitting overlapping profiles, with valley points assigned to both adjacent peaks); (3) Log-transformation of each isolated Gaussian-shaped peak profile to linearize the Gaussian model Î(x) = Î₀·exp[−(x−x̂₀)²/(2σ̂²)] into a second-order polynomial ln(Î(x)) = β̂₀ + β̂₁x + β̂₂x²; (4) Weighted linear regression using sparse matrix algebra, where weights wᵢ = Iᵢ / ΣIᵢ² (intensity-squared weighting optimized for Orbitrap-MS); (5) Estimation of Gaussian parameters (centroid x̂₀, width σ̂, height Î₀, area Â) via closed-form solutions (Eqs. 3–6); (6) Calculation of regression standard errors via the variance–covariance matrix s̆²(β) = MSE·(XᵀWX)⁻¹, with MSE computed from weighted residuals (Eq. 13); (7) Derivation of the Data Quality Score (DQS) = 1 − erf(ΔÂ/Â), where ΔÂ is propagated from uncertainties in Î₀ and σ̂ using error propagation (Eq. 11); (8) Filtering out poor fits based on two criteria: β̂₂ < 0 (ensuring real-valued σ̂) and minimum 4 data points per peak (to ensure ≥1 degree of freedom); (9) Export of final centroided results (m/z–intensity pairs with DQS) to *.csv. The algorithm avoids deconvolution for overlapping peaks to prevent computationally prohibitive non-linear regression, instead relying on valley-based splitting. A Bi-Gaussian extension for TOF-MS is described in the supplementary material but was not part of the primary implementation shown in the main text.

========== paper_workflow entry 2 ==========
related_tool: msconvert
sample_description: The research utilized seven open datasets (Dataset1 to Dataset7) encompassing both proteomics and metabolomics data, acquired under Data Dependent Acquisition (DDA) and Data Independent Acquisition (DIA)/SWATH modes. These datasets were generated on multiple mass spectrometers: TripleTOF 5600, TripleTOF 6600, Q-Exactive (Thermo QE), Agilent 6550 QTOF, and SCIEX TOF 5500. Specific datasets include: DDA-Dataset1 and DIA-Dataset1 (TripleTOF 5600, PXD021390); DDA-Dataset2 and DIA-Dataset2 (Q-Exactive, PXD018139); DDA-Dataset3 (Q-Exactive, IPX0001509000); DDA-Dataset4 (metabolomics, Q-Exactive, MTBLS2119); DDA-Dataset5 (metabolomics, TripleTOF 6600, XCMS1197236); DIA-Dataset6 (TripleTOF 5600/6600, PXD002952); and DIA-Dataset7 (Agilent 6550, PXD004712). All raw data and converted files (mzML, mgf, mz5, Aird) were uploaded to ProteomeXchange (PXD025142). The total data volume reached several terabytes, and testing was performed on a desktop computer with Intel i7-7700K CPU (4.4 GHz), 16 GB RAM, and 5900 RPM HDD.
complete_workflow_description: The conversion workflow was implemented using AirdPro (C#) and AirdSDK (Java), both open-source tools available at https://github.com/CSi-Studio/AirdPro/releases/ and https://github.com/CSi-Studio/Aird-SDK. AirdPro first reads vendor files via the ProteoWizard SDK (v3.0.20196-20896b6b1). Then, it applies mode-specific spectrum reordering and compression: (1) For m/z arrays, the ZDPD compressor is used — a hybrid algorithm combining FastPfor (for delta-encoding of sorted integers with SIMD acceleration) followed by Zlib (level 6, DotNetZip library) — with user-configurable m/z decimal precision (e.g., 0.0001 corresponding to ~4 decimal places or ~0.1 ppm accuracy); (2) For intensity arrays, Zlib is the default compressor (with 1 decimal place precision), and optionally the Log10 Compressor (inspired by MS-Numpress) can be applied for lossy compression with up to 0.25% precision loss; (3) Zero-intensity points are ignored by default ('Is Zero Intensity Ignore: Yes') unless explicitly disabled; (4) Indexing strategies are dynamically selected based on acquisition mode: RT-MS index (for general use, like mzXML/mzML), MS1-MS2 Group index (for DDA, grouping MS1 spectra and their associated MS2 spectra contiguously), and Precursor m/z range-MS2 Group index (for DIA/SWATH, clustering MS2 spectra by SWATH window); (5) Metadata is stored in JSON format (validated against the public AirdMetaData.json schema) instead of XML to reduce file size (~65% smaller for SCIEX TOF, ~1.7× smaller for Thermo QE) and improve parsing speed; (6) No external database technologies (e.g., HDF5, SQLite) are used — all indexing and querying capabilities are embedded directly in the Aird binary structure.

========== paper_workflow entry 3 ==========
related_tool: msconvert
sample_description: The research evaluated the software's cross-platform performance using numerous simple and complex sample types from four instrument platforms: AB SCIEX Triple TOF 5600 (UPS1 human, E. coli, Rat Liver), Agilent 6530/6550 QqTOF (Bovine 6, Human Serum), Thermo Scientific Q-Exactive (Bovine 6, Human Jurkat), and Waters Synapt G2/G2-S QqTOF (Bovine 6, Yeast, E. coli, Human K562). Sample complexity increases top-to-bottom per vendor in Table 1. Bovine 6 is a simple mixture of six bovine proteins; UPS1 is a human protein standard; Human Serum, Jurkat, K562 are human biological fluids/cell lines; E. coli and Rat Liver represent prokaryotic and mammalian tissue lysates; Yeast is a eukaryotic model organism. All raw datasets are publicly available via MassIVE (http://massive.ucsd.edu/ProteoSAFe). Sample preparation and acquisition details are provided in the Supporting Information, with explicit note that many datasets were acquired solely for software evaluation—not under optimal instrument conditions (e.g., Waters Synapt was not run with ion-mobility DIA). Inter-platform comparisons were not intended; instead, ProteoWizard’s performance was benchmarked against each platform’s native or commercial software (e.g., AB SCIEX MS Data Converter, Mascot Distiller) on the same data.
complete_workflow_description: The signal processing pipeline consisted of four sequential steps: (1) Peak-picking of MS/MS spectra using CantWaiT, a continuous wavelet transform (CWT)-based algorithm employing the Ricker ('Mexican Hat') wavelet; CantWaiT adaptively selects 10 wavelet scales based on local m/z spacing (computed via 10-point sliding window), performs CWT only at m/z points and midpoints, avoids ridge line identification, identifies local maxima separated by ≥0.1 m/z, applies SNR thresholding (noise estimated as 95th percentile of correlation at smallest scale within 300 m/z bins), and outputs m/z and intensity of maximum intensity point per peak. (2) Precursor charge determination using Turbocharger, which first runs CantWaiT on survey scans surrounding each MS/MS spectrum (two preceding for Thermo/Waters; one preceding + one following for AB SCIEX/Agilent), then builds isotopic chains with interpeak spacing = m_neutron/q ± 0.06 m/z (m_neutron = 1.00335 Da), scores chains using three metrics—(i) m/z spacing fidelity (sum of squared errors vs. simulated null distribution, converted to p-value), (ii) relative intensity distribution (Kullback–Leibler divergence vs. Poisson isotopic model, p-value from 10,000 simulations), and (iii) intensity rank-sum (p-value from combinatorial rank distribution)—then sums ranks across metrics and applies post-hoc correction (selects longer chain if top-8 contains same peaks plus leading peak and passes p < 0.30 relative intensity criterion). (3) Deisotoping using the Poisson model + KL divergence approach, chaining peaks with interpeak spacing within 100 ppm of m_neutron/q, checking charge states 1–3 by default, removing nonmonoisotopic peaks if both SSE and KL scores fall below length-dependent cutoffs (listed in Table S1). (4) Database searching and protein assembly: processed peak lists were searched using MyriMatch and MS-GF+ against proteome-level FASTA databases (with reverse decoys) using two missed cleavages, semi-tryptic option, min 5/max 75 aa, static modifications (carboxymethylation for Bovine 6; carbamidomethylation otherwise), dynamic modifications (Met oxidation, Gln ammonia loss, N-term Gln/Asn deamidation for Bovine 6), and instrument-specific mass tolerances (50/100 ppm for most; 10/20 ppm for Thermo Q-Exactive); monoisotopic peak misassignment correction was disabled. Results were assembled into parsimonious protein groups using IDPicker 3.0 with 2% peptide FDR and ≥2 distinct peptides per protein group.

sample_description: Biological samples consisted of five Caenorhabditis elegans strains: the wild-type Bristol (N2) strain, two knockout strains deficient in xenobiotic-metabolizing enzymes (cytochrome P450 and flavin-containing monooxygenase/FMO), and two transgenic strains modeling neurodegenerative pathways—specifically, Parkinson’s disease (PD)-related tyrosine hydroxylase overexpression in dopaminergic neurons and Alzheimer’s disease (AD)-related pro-aggregation tau fragments. complete_workflow_description: The end-to-end workflow begins with C. elegans strain cultivation and harvesting under controlled conditions, followed by parallel metabolite extraction using either monophasic (for HILIC-POS analysis) or biphasic (for RPLC-NEG analysis) methods. Extracts are analyzed via LC-MS/MS on high-resolution tandem mass spectrometers. Raw data files are converted to mzML using MSConvertGUI (ProteoWizard v3.0.22108-f83e548) with peak-picking enabled and all MS levels retained. Data processing is performed in parallel using two open-source pipelines: (1) patRoon (v2.3.1), integrating IPO for experimental design handling, XCMS for feature detection and alignment, CAMERA for annotation of adducts and isotopes, and MetFrag for in silico fragmentation-based annotation against a custom 'WormJam expanded' database—comprising the original WormJam consensus model, C. elegans–specific metabolites from PubChem, and literature-curated compounds—supplemented with PubChemLite as a prioritized candidate list; and (2) MS-DIAL (v5.1.230912), using its built-in spectral library (MSP, >15,000 compounds) and in silico predicted spectra generated via CFM-ID for the WormJam expanded metabolites. Gap filling was intentionally omitted in both tools to preserve QC-driven feature filtering. Statistical analysis and visualization were conducted in R (v4.3.1) using tidyverse (v2.0.0). Strain-specific metabolic differences were identified through multivariate and univariate statistical testing, supported by pooled QC samples per strain to ensure data quality and biological reproducibility.

related_tool: msconvert
sample_description: Thirteen fractions (7 ethyl acetate and 6 methanol) derived from eight crude extracts of Annona crassiflora — including stem wood, leaves, root bark, root wood, and stem bark — were prepared via Diol cartridge partitioning. Only EtOAc and MeOH fractions with ≥5 mg yield were selected for larvicidal bioassay (against Aedes aegypti larvae at 125 µg/mL) and subsequent HPLC-DAD-MS/MS analysis; six EtOAc fractions were active (mortality >10%), while none of the MeOH fractions showed activity.
complete_workflow_description: The end-to-end workflow begins with crude extraction of Annona crassiflora plant parts (stem wood, leaves, root bark, root wood, stem bark) using hexane and ethanol, followed by Diol cartridge-based partitioning into hexane, ethyl acetate (EtOAc), and methanol (MeOH) phases. Only EtOAc and MeOH fractions yielding ≥5 mg were dried and subjected to larvicidal bioassay against Aedes aegypti; active fractions were defined as those causing >10% mortality at 125 µg/mL. Active and inactive fractions underwent HPLC-DAD-MS/MS analysis in positive ion mode. Raw MS data were converted to .mzXML using MSConvert, then processed in MzMine for peak detection (using MS1 data only), baseline correction, isotopic peak removal, chromatogram alignment, and export as a CSV feature table (columns: m/z, sample name, group label [active/inactive], peak area). This table was uploaded to MetaboAnalyst for multivariate statistical analysis—including unsupervised methods (HCA, PCA) and supervised sPLS—to identify discriminant features between active and inactive groups. Parallel LC-MS/MS data were analyzed via GNPS for molecular networking and annotation. Finally, bio-guided isolation was performed on prioritized fractions to isolate and confirm the larvicidal activity of candidate compounds.
source_paper: P et al. (2020), Scientific reports, DOI: 10.1038/s41598-020-58046-y, PMID: 31974423
