related_tool: MZMine
sample_description: The samples used in this study were a subset of eight surface water samples (sites A–H) from a micropollutant monitoring study in Germany. The full list of 680 analyzed compounds, including their IDs, mode of analysis (LC-ESIpos/neg or GC-EI), and associated internal standards, is provided in Supporting Information S2, Tables S2-1 and S2-2.
complete_workflow_description: The Automated Target Screening (ATS) workflow is implemented as an R package (R v4.1.3) available on GitHub. It consists of six main steps executed via five core functions: (A) EIC generation and peak identification/integration; (B) global shift calculation; (C) peak list annotation and intensity-dependent shift calculation; (D) internal standard (IS)-specific shift analysis; (E) sample-level target screening; and (F) quantification. Input data includes centroided .mzML or Thermo .raw files, processed using rawrr (v1.2.0) and RaMS (v1.3.0). EICs are generated per m/z of interest, smoothed only for shape-dependent functions (not for quantification), and integrated via the trapezoidal rule. Peak shapes are encoded as Symbolic Aggregate Approximation (SAX) sequences (using seewave v2.2.0) with user-selectable alphabet size. Baseline is determined using the 25th intensity quantile by default, but elevated quantiles (up to 80th) are applied when EICs exhibit high noise—triggered by thresholds: (A) <25% zigzag pattern (alternating high/baseline intensities), (B) root mean squared error of background <10%, and (C) max intensity / 25th quantile >3. In-sample LOD and LOQ are defined as baseline + 3×noise and baseline + 10×noise, respectively. Peak identification uses a local maxima algorithm with customizable parameters: intensity_factor_decrease (>40%), intensity_factor_increase (>40%), density_factor (5× data density), and data density defined as points per 0.1 min. Peak splitting at likely cutoffs (edges of adjacent maxima) is enforced. Global shift (Function B) is calculated from all internal standards across samples, assuming the mean shift represents system-wide retention time drift; the largest observed shift defines the initial screening window (≥0.5 min for LC, ≥0.1 min for GC). Function C generates consensus peaks per reference standard, incorporates confirming ions for validation, and detects intensity-dependent shifts via linear regression of intensity vs. theoretical concentration—requiring inclusion of IS-only samples to identify unspecific interferences. Function D computes per-sample IS shifts to infer analyte-specific drifts, with fallback to uncorrected expected retention time if a valid peak is found precisely at that time. Function E performs target screening using adjusted windows incorporating global, intensity-dependent, and IS-dependent shifts; confirming ions are checked separately with ±20% intensity ratio tolerance; peaks failing shape similarity (via MINDIST on SAX sequences), minimal data points (≤7), or confirming ion detection are tagged 'CHECK'. Function F handles quantification: solvent blanks are used to estimate and subtract background (mean blank response); matrix-matched standards enable matrix correction; reference standards are outlier-checked via interquartile range (IQR); calibration uses six linear regression variants (through origin or unconstrained, with/without weighting by x or 1/x) optimized autonomously for R² ≥0.95 and median quantification error <30%, with high-leverage points iteratively removed using Cook’s distance until improvement ceases (minimum 4 points retained); final model selection prioritizes lowest quantification error, then widest concentration coverage, then highest R². Outputs include sample responses, response ratios, quantified concentrations, consensus peak lists, apex retention times, and qualitative heatmaps (TRUE/FALSE/masked).

complete_workflow_description: The workflow consisted of four integrated computational stages implemented in Julia v1.5.3 (64-bit) on Ubuntu 20.04.2 LTS (Intel Core i7, 16 GB RAM): (1) Data conversion: raw files were converted to mzXML format using ProteoWizard v3; (2) Centroiding: a self-adjusting, iterative centroiding algorithm (implemented via custom Julia code and MS_Import.jl) performed signal selection (using nominal resolution to estimate initial mass window, then extending to 2× that width and truncating at half-height or user-defined minimum intensity threshold), smoothing (3-point moving-average filter), Gaussian fitting (3-parameter Gaussian: y = a·exp(−((x−b)/c)²); assessed via adjusted R² threshold ≥ user-specified value, default range tested 0–1), centroid calculation (average of Gaussian-predicted m/z and measured apex m/z, accepted only if |Δm/z| < 0.5 × measured full width at half maximum), and signal removal (setting intensities within detected peak region to half the minimum intensity threshold before proceeding to next strongest signal); parameters optimized on 50 random peaks across two chromatograms and fixed across all datasets regardless of matrix or vendor; (3) Modeling: Random Forest Regression (RFR) implemented via DecisionTree.jl v0.10.10 used three predictors—relative intensity (%), m/z (Da), and retention factor (%)—to predict mass peak width at half-height (mDa); hyperparameter optimization via grid search over number of trees (50–350, step 50) and minimum leaf population (1–30, step 5), evaluated on validation set using RMSE and correlation coefficient; final optimized model used 250 trees and minimum leaf size 10; validated via 500-sample out-of-bag bootstrapping and 5-fold cross-validation; (4) Profile prediction: for each centroid, a mass window of twice the predicted peak width (spanning 8 data points, based on median experimental profile point count) was used with fitted Gaussian parameters (a = measured intensity, b = measured m/z, c = predicted width) to reconstruct full mass spectral profiles from centroided data.

complete_workflow_description: The centWave algorithm (implemented in R/Bioconductor within the XCMS framework, version 1.12.1) was applied for feature detection. Its core workflow consists of three main stages: (1) Regions of Interest (ROI) detection in the m/z domain: using mass deviation threshold μ (set to 30 ppm for Bruker MicrOTOF-Q, reflecting ~6–10× advertised 3–5 ppm accuracy), minimum centroid count p_min (derived from chromatographic peak width range and average inter-scan distance), and optional prefilter (e.g., (k=2, I=100) requiring ≥2 consecutive intensities ≥100); ROIs are built by scanning centroided spectra sequentially and grouping m/z values within μ ppm of existing ROI means or initiating new ROIs; low-intensity or short ROIs (<p_min centroids) are discarded. (2) Chromatographic peak detection per ROI via Continuous Wavelet Transform (CWT): using the 'Mexican Hat' wavelet (second derivative of Gaussian), scale range (s_min, s_max) derived from user-specified chromatographic peak width range (w_min, w_max, e.g., (5,10) seconds for UPLC) and inter-scan time; local maxima and ridges in the CWT coefficient matrix are identified to locate peaks across scales; peak boundaries (rt_min, rt_max) are determined by descent on the optimal-scale coefficients. (3) Feature characterization and filtering: baseline (BL) and noise level (NL) estimated via 10% trimmed mean and standard deviation of ROI intensities; signal-to-noise ratio SNR = (I_max − BL)/NL computed and features discarded if SNR < SNR_Thr (e.g., 10); m/z centroid calculated as weighted mean within peak boundaries; optional Gaussian fitting via R's Nonlinear Least Squares (NLS). Additional software evaluated included matchedFilter (XCMS v1.12.1, C/R) with parameters fwhm (model peak width), snthresh (SNR threshold), and step (bin size); all data files were in mzData format and acquired in centroid mode.
