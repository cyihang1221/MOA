sample_description: The research used multiple public mass spectral libraries for training and benchmarking: the GNPS library, the MassBank EU library, the MassBank of North America (MoNA) library, and MS2 spectra from MSnLib (created by Brungs et al.). After cleaning with the matchms library pipeline, the combined dataset comprised 36,638 unique molecules (519,580 spectra) in positive ionization mode and 18,480 unique molecules (145,594 spectra) in negative ionization mode; uniqueness was defined by the first 14 characters of the InChIKey (ignoring stereochemistry). For case studies, three experimental datasets were employed: (1) human urine fractions from the National Phenome Centre, acquired via reversed-phase UHPLC coupled to a Waters Xevo G2-S TOF mass spectrometer using electrospray ionization; (2) human blood plasma (NIST SRM1950), analyzed using UHPLC-RP-LC on a BEH C8 column coupled to a Waters Xevo G3 QTof; and (3) Rumex sanguineus plant tissue (25 mg homogenized and extracted with water/methanol/MTBE), analyzed on an Agilent 1290 UHPLC coupled to a Thermo Q-Exactive Focus Orbitrap in both positive and negative ionization modes with data-dependent acquisition (24 samples: 4 biological replicates × 2 technical duplicates across roots, stems, and leaves). All raw data were converted to .mzML format using ProteoWizard msconvert, peak-picked and converted to .mgf using MSDIAL (with parameters: min peak height = 1000 amplitude, mass slice width = 0.05 Da, MS2Dec sigma = 0.5, MS2 abundance cutoff = 200 amplitude, RT tolerance = 0.05 min, MS1 tolerance = 0.01 Da), and further processed with matchms (urine: retained only MS2 spectra with >4 fragments; Rumex and plasma: no minimum peak count applied).
software_configuration_description: MS2DeepScore 2.0 was implemented in PyTorch (replacing the Tensorflow-based v1.0), supporting dual-ionization mode training. Input spectra were binned into 9900 fixed bins of 0.1 Da width spanning m/z 10–1000 Da (all bins included regardless of occupancy); intensity values were square-root transformed. Metadata inputs included precursor m/z (numerically scaled to ~1 magnitude) and ionization mode (one-hot encoded); additional experiments tested instrument type and adduct type as metadata. The final model architecture consisted of a single fully connected layer with 10,000 nodes and an embedding size of 500; the final layer activation was Tanh (replacing ReLU), and dropout and batch normalization were removed. Data augmentation settings were: augment removal max = 0.2 (previously 0.3), augment intensity = 0.2 (previously 0.4), and augment noise intensity = 0.02 (previously 0.01). Molecular similarity was trained to predict Tanimoto scores computed from RDKit daylight-like binary fingerprints (4096 bits, not 2048 as in v1.0). The Embedding Evaluator — a separate InceptionTime-based CNN — was trained to predict mean squared error (MSE) of spectrum embeddings using MSE calculated over 999 random pairwise predictions per training spectrum. For molecular networking, edges were generated using MS2DeepScore scores with a minimum cut-off of 0.85, 'top-n' = 20, and mutual linking (requiring reciprocal top-20 inclusion); the top 10 mutual links per node were retained. For UMAP visualization, 500-dimensional embeddings were reduced to 2D using UMAP with n_neighbors = 50. The model is available as a pip-installable Python package (v2.5.3), integrated into MZmine 4.3.0 via TorchScript conversion supported by Deep Java Library (DJL), with automatic model download from Zenodo (10.5281/zenodo.12628368).

sample_description: The research utilized multiple biological samples across four case studies: (1) NIST 1950 Frozen Human Plasma standard reference material (SRM) for lipidomic profiling via reversed-phase chromatography (RPC); (2) a plasma Long-Term Reference (LTR) sample (10 L bulk plasma from Seralab, homogenized and aliquoted at –80 °C) analyzed using hydrophilic interaction liquid chromatography (HILIC) for polar metabolites; (3) a pooled urine LTR sample (78 urine voids from healthy volunteers, combined into 20 L, homogenized, aliquoted, and stored at –80 °C) analyzed by RPC for small-molecule metabolites; and (4) extracts from three anammox bacterial strains — Kuenenia stuttgartiensis MBR1 (cultivated in a 12-L membrane bioreactor), Brocadia fulgida (6-L bioreactor), and Scalindua (5.5-L sequencing batch reactor) — grown under defined chemostat-like conditions with specific nitrogen sources (NaNO₂ and (NH₄)₂SO₄), trace elements, salts, and controlled temperature/stirring. All case study samples underwent standardized protein precipitation (e.g., with isopropanol or acetonitrile), centrifugation, supernatant collection, and LC-MS injection under strictly controlled pre-analytical conditions (e.g., 4 °C thawing, full-loop injection mode, 5× overfill).
software_configuration_description: MS2Deepscore was trained exclusively on fully annotated spectra from the GNPS library (downloaded on 1 November 2022), using identical settings as in the original MS2Deepscore publication (reference 32). Training employed all spectra with valid SMILES, InChIKey, and InChI. The model computes spectral similarity by first generating multidimensional mass spectral embeddings and then calculating cosine similarity between embeddings. For benchmarking and inference, MS2Deepscore was applied to compute pairwise spectral similarity scores between a query spectrum and all library spectra; the top 2000 highest-scoring library spectra were retained for downstream ranking. During analogue search benchmarking, library spectra were filtered to include only those with precursor m/z difference ≤ 100 Da relative to the query; for exact-match benchmarking, only library spectra within a 0.25 Da precursor m/z tolerance were considered. Pre-calculated MS2Deepscore embeddings for all library spectra were stored to avoid redundant computation, and these precomputed scores were reused both for initial top-2000 selection and for computing Feature 4 (average MS2Deepscore over 10 chemically similar library molecules).

sample_description: The study used annotated MS/MS spectra from the Global Natural Products Social Molecular Networking (GNPS) platform, retrieved on 25/01/2021, totaling 210,407 spectra. After metadata cleaning using matchms v0.8.2—including compound name standardization, adduct extraction, metadata field harmonization, and InChI/SMILES/InChIKey conversions—184,698 spectra were annotated with InChIKey and/or SMILES/InChI. The final analytical subset comprised 109,734 positive-ion-mode spectra meeting strict criteria: presence of a valid 14-character InChIKey, at least one structural annotation (SMILES or InChI), and ≥5 peaks in the m/z range 10.0–1000.0 Da. Spectra were further preprocessed by intensity thresholding (<0.1% of max peak intensity removed), limiting to top 1000 highest-intensity peaks, square-root intensity transformation, and binning into 10,000 equal-width bins spanning m/z 10–1000; 9948 bins were retained after removing empty bins across the training set. Structural similarity labels were derived from Tanimoto scores computed on 2048-bit RDKit Daylight fingerprints generated from the most common InChI per unique 14-character InChIKey (n = 15,062). The dataset was split into training (n = 14,062 InChIKeys), validation (n = 500), and test (n = 500) sets, corresponding to 109,734 total spectra — with 3,597 validation spectra and 3,601 test spectra — and all possible spectrum pairs within each set were considered for evaluation (e.g., 6,485,401 unique pairs in the test set).
software_configuration_description: MS2DeepScore is implemented as a Siamese neural network with a base network that maps binned spectral vectors (9948-dimensional, m/z 10–1000, square-root transformed intensities) into 200-dimensional spectral embeddings. The base network consists of three dense layers: two hidden layers with 500 nodes each, followed by an output embedding layer of 200 nodes. Regularization includes L1 and L2 weight penalties (both λ = 10⁻⁶) applied only to the first dense layer, dropout (rate = 0.2) applied to all subsequent dense layers (i.e., second and third layers), and batch normalization after each dense layer except the final embedding layer. At inference, uncertainty quantification uses Monte-Carlo Dropout ensembles: N = 10 forward passes with dropout enabled in all but the first layer, yielding a distribution of cosine-similarity predictions from which median and interquartile range (IQR) are computed. The model was trained using the Adam optimizer (learning rate = 0.001, batch size = 32) to minimize mean squared error (MSE) loss, with early stopping triggered after 5 epochs without validation loss improvement. Training was performed on NVIDIA GTX 1080 Ti GPUs (SURFsara Lisa cluster). The software is distributed as an open-source Python library (v0.2.0), compatible with Python 3.7/3.8, integrated into matchms, and available on GitHub (https://github.com/matchms/ms2deepscore).
