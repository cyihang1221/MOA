reproducibility_gaps:
  - Raw MALDI-MSI imaging data not deposited in public repository (e.g., MetaboLights, MassIVE)
  - No code repository or scripts provided for Seurat/Monocle3 pipelines, MATLAB preprocessing, or IsoCorrectoR usage
  - SCiLS Lab 2016b is commercial software requiring license; no open alternative workflow provided
  - Exact gradient or acquisition parameters for RapifleX/FTICR not fully specified (e.g., laser focus, detector gain, accumulation settings)
  - No details on statistical thresholds for cluster identification or trajectory significance testing
  - CaseViewer and MATLAB are commercial tools with version-specific workflows not fully documented
reproducibility_strengths:
  - Detailed experimental protocols for tissue handling, labeling, and matrix application
  - Explicit mass accuracy thresholds (±5 ppm for FTICR, ±20 ppm for TOF) and SNR criteria (≥3)
  - Use of established open-source tools (Seurat 3.0, Monocle3, IsoCorrectoR, mMass, HMDB)
  - Clear description of co-registration strategy between IF and MSI at matched resolution
