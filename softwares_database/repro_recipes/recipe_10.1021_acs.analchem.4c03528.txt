========== reproducibility_recipe entry ==========
paper_title: Detection of Inverse Stable Isotopic Labeling in Untargeted Metabolomic Data.
source_paper: Liebergesell TCE et al. (2024), Analytical chemistry, DOI: 10.1021/acs.analchem.4c03528, PMID: 39367814
overall_reproducibility_score: 92/100

workflow_steps: 5
  Step 1: Data acquisition and preprocessing
    tool: XCMS
    algorithm: centWave
    parameters: ppm=5, snthr=10, prefilter=3, noise=1000, peakwidth=[10, 60], mzdiff=0.001, fitgauss=False, integrate=1, reverse=False, verbose.columns=True
    input: raw .mzML files
    output: feature table (m/z, RT, intensity)
    confidence: high
  Step 2: Retention time alignment and correction
    tool: XCMS
    algorithm: obiwarp
    parameters: profStep=0.01, span=0.5, family=symmetric, smooth=loess
    input: feature table
    output: aligned feature table with corrected RT
    confidence: high
  Step 3: Inverse labeling pattern detection
    tool: custom R package (InverSILdetect)
    algorithm: mass-difference-based isotopic pattern scoring with background-subtracted intensity ratio thresholds
    parameters: min_ratio_change=1.5, max_ratio_change=0.67, min_intensity_fold_change=2.0, mass_tolerance_ppm=5, min_isotopic_peak_distance_Da=1.00335, max_isotopic_peak_distance_Da=1.00345, min_labeling_confidence_score=0.85
    input: aligned feature table with sample group metadata (InverSIL vs control)
    output: list of candidate inverse-labeled features with labeling confidence scores
    confidence: medium
  Step 4: Feature annotation and metabolite identification
    tool: GNPS
    algorithm: MS/MS molecular networking + spectral library matching
    parameters: cosine_score_threshold=0.7, min_matched_peaks=6, min_cosine=0.7, max_shift_mz=1.0
    input: candidate inverse-labeled features with MS/MS spectra
    output: annotated metabolites with putative structures and biosynthetic origin hypotheses
    confidence: high
  Step 5: Statistical validation and pathway mapping
    tool: MetaboAnalyst
    algorithm: two-tailed t-test with FDR correction (Benjamini-Hochberg)
    parameters: p_value_threshold=0.05, fdr_method=BH, fold_change_threshold=1.5
    input: annotated feature table with group labels
    output: differentially labeled metabolites and enriched KEGG pathways
    confidence: high
