complete_workflow_description: The primary bioinformatic and computational procedures included: (1) GEO data preprocessing in R: raw MINiML files downloaded from NCBI; unnormalized data log2-transformed; quantile normalization applied via preprocessCore::normalize.quantiles; probe-to-gene mapping using platform-specific annotation files (multi-probe genes averaged, multi-gene probes excluded); batch effect correction using limma::removeBatchEffect with explicit batch labeling for inter-dataset/platform integration; quality control via boxplots and PCA before/after correction. (2) Core gene identification: PPI network constructed using STRING database (confidence score ≥ 0.4), imported into Cytoscape v3.10.1; hub genes identified using cytoHubba plugin with Maximum Clique Centrality (MCC) algorithm; top 11 MCC-ranked genes selected. (3) Differential expression analysis: DEGs identified using DEGseq (for RNA-seq) with thresholds |log2(fold change)| ≥ 1.0 and adjusted p-value < 0.001; for microarray, FC > 1.3 and p < 0.05 used. (4) Gene Set Variation Analysis (GSVA): performed using the GSVA R package (default parameters, Gaussian kernel 'kcdf = "Gaussian"') on normalized (e.g., log2-TPM or log2-FPKM) gene expression matrices; input gene sets sourced from MSigDB; differential pathway activity between groups assessed via limma. (5) IP-MS data processing: immunoprecipitated complexes analyzed by LC–MS/MS on Q Exactive HF–X Orbitrap; raw spectra searched against UniProt human/mouse databases using MaxQuant (implied standard workflow); protein identification and quantification performed with default settings including FDR ≤ 0.01 at peptide-spectrum match and protein levels. (6) Molecular docking: 3D structures predicted by AlphaFold2; docking simulations executed on GRAMM web server v2.0 (default parameters for rigid-body docking); interaction analysis and visualization performed in PyMOL v2.4; binding topology diagrams generated based on hydrogen bond and electrostatic interaction detection.

========== paper_workflow entry 2 ==========
related_tool: GSEA
sample_description: The study used male C57BL/6 N mice (RRID: MGI:2159965) from Taconic, Denmark, aged 8–9 weeks at acclimatization onset and 16 weeks at experiment conclusion. Mice were housed under controlled conditions (22 ± 1°C, 12-hr light/dark cycle, lights on at 06:00), initially group-housed (3–4 per cage) on NIH-31 chow diet (8% calories from fat), then single-housed for experimental duration to avoid social thermogenesis bias. Two main studies were conducted: Study 1 (n = 15 mice) assessed diet–temperature interactions via indirect calorimetry using three dietary groups — Control (Ctrl; 0.8% methionine), Methionine-restricted (MetR; 0.12% methionine), and Methionine-supplemented (MetS; 2% methionine) — fed for 6 days at 22°C followed by 5 days at 4°C. Study 2 (n = 28 mice) performed integrated physiological and molecular analyses with four experimental groups: Ctrl or MetR diets at either room temperature (RT, 22°C) for 7 days + 1 day at 4°C (cold exposure, CE), or RT for 8 days total. Tissues analyzed included liver, epididymal white adipose tissue (eWAT), inguinal white adipose tissue (iWAT), and brown adipose tissue (BAT); RNA was extracted from these tissues for sequencing. For RNA-seq, seven biological replicates per group and tissue were sequenced, except for iWAT and iBAT where one sample each was lost during preparation. Sample sizes were determined empirically based on prior metabolic and transcriptomic experience; no formal a priori power calculation was performed. All sacrifices occurred between 09:00–11:00 during the light phase; investigators were not blinded during animal handling/tissue collection, but downstream molecular and computational analyses used coded identifiers to minimize bias. No animals were excluded from physiological analyses; RNA-seq outlier exclusion was performed post hoc using PCA and robustPCA (rrcov v1.7.7), with specific exclusions reported per tissue and condition (e.g., in eWAT: 3 in Ctrl_RT, 1 in MetR_RT).
complete_workflow_description: The transcriptomic analysis pipeline involved multiple software tools and rigorous parameterized steps. First, raw sequencing reads were aligned to the mouse reference genome mm10/GRCm38 (GENCODE vM25) using STAR aligner (v2.7.9a; RRID: SCR_004463) with the following parameters: --outSAMunmapped Within, --outFilterType BySJout, --outSAMattributes NH HI AS NM MD, --outFilterMultimapNmax 10, --outFilterMismatchNoverReadLmax 0.04, --alignIntronMin 20, --alignIntronMax 1000000, --alignMatesGapMax 1000000, --alignSJoverhangMin 8, and --alignSJDBoverhangMin 1. Gene-level quantification was performed using featureCounts (v2.0.3; RRID: SCR_012919). Concurrently, transcript-level quantification was carried out using Salmon (v1.9.0) with Gencode vM25, applying parameters --seqBias, --useVBOpt, and --numBootstraps 30; transcript abundances were then imported and summarized to gene-level counts using tximport (Soneson et al., 2015). Quality control across all samples was aggregated using MultiQC v1.19 (RRID: SCR_014982). Differential expression analysis was conducted with DESeq2 (v1.46.0; RRID: SCR_000154), incorporating apeglm (v1.24.0; Zhu et al., 2019) for shrinkage of log2 fold changes. Prior to normalization, genes with fewer than 10 total counts across all samples were filtered out. A full factorial interaction model was fitted: ~ diet + temperature + diet:temperature, enabling detection of main effects (MetR vs. Ctrl; cold exposure vs. room temperature) and their statistical interaction. Significance thresholds were adjusted p-value < 0.05 and |log2FC| ≥ 0.585 (equivalent to |FC| ≥ 1.5). Outlier detection employed both visual inspection of PCA plots and robustPCA from rrcov (v1.7.7; Todorov, 2004). Classification of transcriptional interaction patterns (e.g., co-dependent, concordant, discordant, masked, synergistic, antagonistic) relied on a custom R script adapted from Pantaleón García et al. (2022), implementing four key contrasts: Ctrl_CE vs Ctrl_RT (A), MetR_RT vs Ctrl_RT (B), MetR_CE vs Ctrl_RT (AB), and the interaction term (A×B); only genes significant (padj < 0.05 and |FC| > 1.5) in at least one contrast were included. Synergy scores were computed as log2|log2FC{AB} / (log2FC{A} + log2FC{B})|, with undefined scores when the denominator approached zero. All computation was executed on the UCloud interactive HPC system managed by the eScience Center at the University of Southern Denmark.

========== paper_workflow entry 5 ==========
related_tool: GSEA
sample_description: The analytical sample set comprised 275 postmenopausal women from the Michigan Site of the Study of Women's Health Across the Nation (MI-SWAN), a subset of the larger SWAN cohort. Participants were recruited between 1996–1997 and followed for up to 17 visits; this study used data and biospecimens from the 2010 annual follow-up visit. Of the 403 women who attended that visit, 345 underwent hepatic ultrasound; after excluding 14 with cirrhosis or chronic liver disease (viral hepatitis or hemochromatosis) and accounting for unavailable serum (n = 47) and non-postmenopausal status (n = 3), 275 fasting serum samples were available for extracellular vesicle (EV) isolation. All participants provided informed consent, and the study was approved by institutional review boards at each clinical site. Serum was collected after an overnight fast, refrigerated for 1–2 h, centrifuged, aliquoted, and stored at −80 °C prior to EV isolation.
complete_workflow_description: Proteomic analysis was conducted using liquid chromatography–data-independent acquisition mass spectrometry (LC-DIA/MS) on a nanoElute LC system coupled to a timsTOF HT Pro 2 mass spectrometer (Bruker Daltonics). EVs were isolated from 500 µL fasting serum via size exclusion chromatography using qEVoriginal 70 nm Gen 2 columns (Izon Science), collecting fractions F7–F12, which were combined and concentrated to 500 µL using 50 kDa Amicon filters (Millipore). For proteomics, EVs were lysed in 2% sodium deoxycholate buffer, sonicated (UTR2000, Hielscher Ultrasonics; 30 s total: 15 s on/1 s off, 50% amplitude, three rounds), clarified by centrifugation, and quantified via BCA assay. Forty micrograms of protein per sample were processed; a pooled reference spectral library (1.39 mg total) was generated from 5 µg protein per sample. Peptides underwent offline high-pH reverse-phase fractionation on an Ultimate 3000 HPLC system (Thermo Scientific) using a Waters XBridge C18 column (10 cm, 4.6 mm ID, 3.5 µm), eluted over 96 min into a 96-well plate, then combined into 24 fractions. All samples and library fractions were spiked with iRT peptides (Biognosys). LC-DIA/MS used a 62-min gradient at 850 nL/min on a Bruker PepSep C18 column (25 cm, 150 µm ID, 1.5 µm). DDA-PASEF library runs used MS1 range 100–1700 m/z, TIMS mobility window (1/K0) 0.70–1.50, 75 ms accumulation/ramp time, 7 PASEF ramps, 0.65 s cycle time, and collision energy ramp 20–65 eV. DIA-PASEF runs matched accumulation/ramp time. Capillary voltage was 1700 V and dry gas temperature was 200 °C. Spectral libraries were built in Spectronaut 19.8 against human SwissProt (UP000005640, June 2025), with trypsin digestion (max 2 missed cleavages), fixed carbamidomethylation of cysteine, and variable methionine oxidation and protein N-terminal acetylation; PSM/peptide FDR < 1%. DIA-MS data were searched against sample-specific libraries using default Spectronaut settings (cross-run normalization, imputation, and scaling disabled). Protein abundances were normalized using variance stabilization normalization (vsn R package). PCA was performed using PCAtools on proteins present in 100% of samples; eigencorplot assessed confounding effects on first five PCs. Differential abundance was calculated via ANCOVA adjusted for ethnicity and diabetes status, with Benjamini–Hochberg correction; significant proteins (p < 0.05) were filtered for presence in ≥50% of samples. PLS-DA was performed using the plsda function in the mixOmics R package with 95% confidence intervals; group separation significance was assessed via Hotelling’s t-squared test (Hotelling R package, p < 0.05).

Demographic details for the OA cohort included age stratification (>60 years: 35 OA, 0 controls; ≤60 years: 5 OA, 10 controls) and gender distribution (male: 18 OA, 4 controls; female: 22 OA, 6 controls). All samples were human-derived, with RNA-seq or microarray-based gene expression profiling. Outlier detection was performed via hierarchical clustering (e.g., sample 18 in GSE145412 was removed as an outlier using a cut-off value of 20,000), and batch effects were not explicitly corrected but accounted for through standard preprocessing steps implied by limma and WGCNA workflows.
complete_workflow_description: The analytical pipeline involved multiple R-based bioinformatics tools and statistical methods. Data preprocessing and differential expression analysis for GSE145412 (MS) and GSE51588 (OA) were performed using the limma package with empirical Bayes moderation of standard errors; DEGs were defined as |log2FC| > 1 and P < 0.05 for OA, and P < 0.01 for MS. Weighted Gene Co-expression Network Analysis (WGCNA) was conducted using the WGCNA R package: (1) sample clustering with cutreeDynamic for outlier removal; (2) soft-threshold power selection (power = 8 for MS, determined by scale-free topology criterion R² ≥ 0.9); (3) TOM calculation using Pearson correlation and adjacency matrix construction; (4) module detection via dynamic tree cutting with minimum module size = 30; (5) module-trait association via Pearson correlation (P < 0.05 considered significant). Hub genes were identified by Venn intersection of DEGs and key module genes (e.g., sky-blue and indianred4 modules for MS). Functional enrichment (GO and KEGG) was performed using clusterProfiler with enrichGO and enrichKEGG functions, applying P < 0.05 as significance cutoff. ssGSEA scores for KEGG pathways in GSE51588 were calculated using the GSVA R package with default settings (kernel = TRUE, min.sz = 10, max.sz = 500, parallel.sz = 1). MOHGs were identified by intersecting ssGSEA-identified differentially activated KEGG pathways (e.g., arachidonic acid metabolism, platelet activation) with OA DEGs. LASSO regression was implemented using the glmnet R package with alpha = 1 (L1 penalty), optimal lambda selected via 10-fold cross-validation (lambda.min), and coefficients extracted at the lambda.1se value. ROC analysis and AUC calculation were performed using the pROC R package with default settings (auc = TRUE, ci = FALSE, direction = 'auto'). Statistical comparisons (e.g., between groups) used Wilcoxon rank-sum test (non-parametric), and visualization employed ggplot2 for boxplots and heatmaps.
