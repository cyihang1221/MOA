sample_description: The paper does not describe any specific biological samples or experimental datasets analyzed using CAMERA; it is discussed solely as a software tool within the broader XCMS ecosystem and reviewed in the context of general untargeted metabolomics applications.
software_configuration_description: CAMERA is described as a bioinformatic tool interoperable with XCMS that operates on the XCMS peaks table and/or groups table to annotate features by identifying adducts, isotopes, in-source fragments, and artifacts. It uses correlation-based methods (e.g., retention time and intensity correlation across samples) to group related features and improve metabolite-level annotation. The paper notes that CAMERA helps address limitations of the standard XCMS diffreport — particularly its inability to distinguish true metabolites from spectral artifacts — but does not specify version numbers, parameter settings, databases used (e.g., for adduct annotation), or integration details beyond input dependency on XCMS output tables.
