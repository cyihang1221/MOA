========== reproducibility_recipe entry ==========
paper_title: Reproducible molecular networking of untargeted mass spectrometry data using GNPS.
source_paper: Aron AT et al. (2020), Nature protocols, DOI: 10.1038/s41596-020-0317-5, PMID: 32405051
overall_reproducibility_score: 92/100

workflow_steps: 6
  Step 1: Data upload and registration
    tool: GNPS
    algorithm: web-based submission
    input: raw .mzML or .mgf files containing MS/MS spectra
    output: registered dataset with unique GNPS job ID
    confidence: high
  Step 2: Spectral pre-processing
    tool: GNPS
    algorithm: peak filtering, deisotoping, dereplication
    parameters: min_peak_intensity=0.001, max_number_of_peaks_per_spectrum=100, precursor_mass_tolerance=0.02, fragment_mass_tolerance=0.02
    input: raw MS/MS spectra
    output: cleaned, centroided MS/MS spectra
    confidence: high
  Step 3: Molecular networking via spectral similarity
    tool: GNPS
    algorithm: Cosine similarity (modified dot product)
    parameters: cosine_score_threshold=0.7, min_matched_peaks=6, max_shift_mz=1.0, min_precursor_difference=5.0, max_precursor_difference=1000.0
    input: pre-processed MS/MS spectra
    output: molecular network (graph: nodes = spectra, edges = cosine scores ≥ threshold)
    confidence: high
  Step 4: Annotation propagation and spectral library matching
    tool: GNPS
    algorithm: library search against GNPS Mass Spectrometry Reference Library
    parameters: library_match_threshold=0.7, min_matched_peaks_for_annotation=6, mass_error_tolerance_ppm=20.0
    input: molecular network nodes (spectra)
    output: annotated molecular network with compound IDs and confidence levels
    confidence: high
  Step 5: Network visualization and subnetwork extraction
    tool: Cytoscape
    algorithm: force-directed layout (e.g., Prefuse Force Directed)
    parameters: node_size_attribute=number_of_spectra, edge_thickness_attribute=cosine_score
    input: GNPS-exported network (edges.csv, nodes.csv)
    output: interactive network visualization, subnetworks (e.g., molecular families)
    confidence: medium
  Step 6: Cross-dataset propagation and knowledge sharing
    tool: GNPS
    algorithm: job cloning and annotation inheritance
    input: existing GNPS job ID
    output: cloned job with inherited annotations and updated network
    confidence: high
