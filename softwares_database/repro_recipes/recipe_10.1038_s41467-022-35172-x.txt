========== reproducibility_recipe entry ==========
paper_title: pGlycoQuant with a deep residual network for quantitative glycoproteomics at intact glycopeptide level.
source_paper: Kong S et al. (2022), Nature communications, DOI: 10.1038/s41467-022-35172-x, PMID: 36477196
overall_reproducibility_score: 87/100

workflow_steps: 5
  Step 1: Read glycopeptide identification results
    tool: pGlycoQuant
    algorithm: input parsing
    input: identification results from pGlyco, Byonic, or MSFragger-Glyco (GPSMs)
    output: parsed high-confidence GPSM list
    confidence: high
  Step 2: Extract isotopic chromatograms (evidence)
    tool: pGlycoQuant
    algorithm: stepwise convolution + ppm-level m/z windowing + chromatogram extension
    parameters: mz_tolerance_ppm=[10, 20], chromatogram_extension_threshold_fraction=0.1, retention_time_window_for_MBR_minutes=2.0, chemical_labeling_reported_ion_peak_extraction=True
    input: raw .mzML/.raw files + GPSM list
    output: isotopic chromatograms ('evidence') per glycopeptide
    confidence: high
  Step 3: Quantitation using deep learning–based evidence matching
    tool: pGlycoQuant
    algorithm: ResNet18-based similarity scoring + fully connected neural network with softmax loss
    parameters: evidence_matrix_size=512x1, combined_vector_size=1024, classical_features_count=10, output_score_range=[0, 1], training_positive_pairs=3000, training_negative_pairs=3000, retention_time_difference_threshold_for_positive_pairs_minutes=2.0, intensity_difference_threshold_for_positive_pairs_percent=30.0, decoy_mass_shift_da=10.0
    input: pairs of isotopic chromatograms (evidence)
    output: matching score [0,1] + quantified intensity (area or summed reporter ions)
    confidence: high
  Step 4: False Quantitation Rate (FQR) estimation
    tool: pGlycoQuant
    algorithm: EM algorithm on Gaussian mixture model (GMM) fitted to target/decoy matching scores
    parameters: gmm_components=2, em_max_iterations=500, em_convergence_epsilon=None, fqr_threshold=0.01, decoy_generation_method=precursor_mass_shift_10Da
    input: matching scores of target and decoy glycopeptide evidences
    output: FQR estimate + filtered high-confidence quantitation results
    confidence: high
  Step 5: Match In Run (MIR) for label-free quantitation
    tool: pGlycoQuant
    algorithm: subnet-based glycan database expansion + in-run evidence matching
    parameters: glycan_infrastructure_definition=glycan structure excluding sialic acid units, candidate_glycan_subnets_count=342, sialic_acid_bias_correction=median RT shift estimation, retention_time_window_for_MIR=user-defined or real-time median-based
    input: identified glycopeptides + glycan database (GlycoWorkbench → pGlyco3 canonical strings)
    output: expanded candidate glycopeptide list + matched evidences within run
    confidence: medium
