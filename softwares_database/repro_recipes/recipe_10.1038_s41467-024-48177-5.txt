  Step 4: Contaminant removal

    algorithm: manual filtering by protein ID list
    parameters: contaminant_list_source=Supplementary information file 'List of contaminants'
    input: protein quantification matrix
    output: cleaned protein quantification matrix
    confidence: medium
  Step 5: Batch effect correction using BERNN
    tool: BERNN (custom neural network suite) (vnot specified)
    algorithm: batch-aware deep neural network with adversarial or contrastive loss (architecture shown in Fig. 1)
    parameters: model_type=['AE', 'VAE', 'GAN', 'Contrastive'], batch_prediction_head=True, adversarial_weight=None, latent_dim=None, epochs=None, optimizer=Adam, learning_rate=None
    input: preprocessed feature/protein matrix (log-transformed, batch-annotated)
    output: batch-corrected feature/protein matrix
    confidence: low
  Step 6: Batch effect evaluation
    tool: custom R implementation
    algorithm: k-nearest neighbors (k=20) + batch entropy + ARI + AMI
    parameters: k_neighbors=20, entropy_normalization=nBE = (log(K) - BE) / log(K), ARI_adjustment=adjusted for chance
    input: batch-corrected matrix
    output: batch mixing metrics (nBE, ARI, AMI)
    confidence: high
  Step 7: Dimensionality reduction for visualization

    confidence: medium
