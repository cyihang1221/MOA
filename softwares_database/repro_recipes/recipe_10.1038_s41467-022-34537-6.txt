========== reproducibility_recipe entry ==========
paper_title: Metabolite annotation from knowns to unknowns through knowledge-guided multi-layer metabolic networking.
source_paper: Zhou Z et al. (2022), Nature communications, DOI: 10.1038/s41467-022-34537-6, PMID: 36333358
overall_reproducibility_score: 87/100

workflow_steps: 5
  Step 1: Seed metabolite annotation using standard MS/MS and RT libraries
    tool: MetDNA (v1.3.2) (v1.3.2)
    algorithm: library matching with orthogonal constraints
    parameters: ms1_match_tolerance_ppm=15, rt_match_tolerance_s=20, ms2_dot_product_score_threshold=0.8, adducts_positive_mode=11, adducts_negative_mode=8
    input: raw .mzML files
    output: seed metabolite annotations (level 1–2)
    confidence: high
  Step 2: Construction of knowledge-based metabolic reaction network (KMRN)
    tool: BioTransformer (v1.0.8)
    algorithm: EC-based in silico enzymatic transformation
    parameters: reaction_types=193, enzymes_used=114, elemental_restriction=['C', 'H', 'O', 'N', 'P', 'S'], tanimoto_similarity_threshold=0.7, inchikey_layer=14, kegg_rclass_date=2017-03-07, hmdb_version=4.0, hmdb_release_date=2018-12-18
    input: KEGG metabolites (6397) and reactions
    output: KMRN graph (41,336 nodes, 52,137 edges)
    confidence: high
  Step 3: Knowledge-guided MS/MS similarity network construction and annotation propagation
    tool: MetDNA (v1.3.2) (v1.3.2)
    algorithm: recursive neighbor annotation guided by KMRN
    parameters: ms1_match_tolerance_ppm=15, rt_match_tolerance_percent=30, ms2_dot_product_score_threshold=0.5, min_matched_fragments=4, rf_descriptors_hilic=8, rf_descriptors_rp=5, rf_cross_validation_folds=10, rf_package=caret, rf_package_version=6.0.90, ms2_scoring_method=dot_product_with_sqrt
    input: seed annotations + KMRN + LC–MS/MS feature table
    output: putatively annotated metabolites (levels 3.1–3.2)
    confidence: high
  Step 4: Global peak correlation network construction
    tool: Custom R/Python implementation (described in Methods)
    algorithm: ion form recognition via co-elution, mass deviation, and correlation
    parameters: rt_window_s=3, mass_deviation_tolerance_ppm=25, isotope_ratio_max_deviation_percent=500, pearson_correlation_threshold=0.3, adduct_types_count=28, neutral_loss_types_count=57, isf_fragment_count=5, empirical_rules_check=True, conflict_resolution_strategy=keep_largest_subnetwork, redundancy_resolution_strategy=keep_largest_subnetwork
    input: feature table + putative annotations
    output: global peak correlation network (subnetwork list → merged network)
    confidence: medium
  Step 5: Annotation confidence assignment per MSI guidelines
    tool: Manual curation + MetDNA framework (v1.3.2)
    algorithm: MSI level classification
    parameters: msi_level_1_criteria=['MS1', 'RT', 'MS/MS'], msi_level_2_criteria=['MS1', 'MS/MS'], msi_level_3.1_criteria=['MS1', 'Pred.RT', 'Surro.MS/MS'], msi_level_3.2_criteria=['MS1', 'Pred.RT', 'Surro.MS/MS']
    input: annotated features with evidence types
    output: MSI-confidence-ranked metabolite annotation table
    confidence: high
