sample_description: The study used age-matched serum samples from 9 healthy, 10 Barrett's esophagus (BE), and 10 esophageal adenocarcinoma (EAC) male patients. Serum glycoprotein enrichment was performed using 20 individual lectin-coated magnetic beads (AAL, BPL, DSA, EPHA, GNL, JAC, LPHA, MAA, NPL, SNA, STL, UEA, HPA, PSA, WFA, WGA, SBA, ConA, HAA, and ECA) targeting sub-glycoproteomes. Each sample contained 50 μg of serum, to which 10 picomoles of chicken ovalbumin (a non-homologous, lectin-binding internal standard) was spiked prior to denaturation. For biomarker qualification, an independent patient cohort was screened using LeMBA-MRM-MS for six lectins (AAL, EPHA, JAC, NPL, PSA, WGA); lectin-beads were prepared in a single batch to minimize experimental variation, and serum samples were randomized. Additional 19 population control (electoral roll) serum samples were included to assess confounders (reflux frequency, BMI, smoking, alcohol). All samples underwent standardized processing including on-bead trypsin digestion, LC-MS/MS or MRM-MS analysis, and rigorous quality control (e.g., 100 fmol/μl predigested BSA peptides pre/post plate; reference ion monitoring; iRT calibration; repeated runs for reproducibility).
software_configuration_description: The study employed sparse partial least squares-discriminant analysis (sPLS-DA) coupled with stability analysis using the R package mixOmics (version referenced as '39'). The sPLS-DA was configured to generate ranked lists of lectin–protein candidates, with stability >70% used as a threshold for candidate selection (supplemental Table S10). Stability analysis was integrated into the GlycoSelector pipeline and performed via repeated subsampling to assess feature selection consistency. The multivariate analysis incorporated data normalization (peptide-level ovalbumin normalization), sample outlier detection (via graphical outputs across four dimensions: PCA, hierarchical clustering, correlation circle, and sample network), exclusion of common contaminant proteins (supplemental Table S3), and group binding analyses. The Shiny mixOmics web application (http://mixomics-projects.di.uq.edu.au/Shiny) was used for downstream univariate/multivariate statistical analyses, ROC curve plotting, and visualization. Parameters included default mixOmics settings for sPLS-DA: tuning of the number of components (ncomp), sparsity parameters (keepX for variables and keepY for groups), and cross-validation for optimal complexity. Functional annotation clustering was performed via DAVID using plasma proteome gene list as background, with adjusted FDR p < 0.05 and cluster scores >3.
