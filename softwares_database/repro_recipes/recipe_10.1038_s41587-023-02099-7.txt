reproducibility_gaps:
  - Orbitrap Astral mass spectrometer is proprietary hardware not widely accessible
  - FAIMS Pro interface settings only partially specified (CV = −50 V, but no details on dispersion field or compensation voltage sweep)
  - Exact gradient profiles for Evosep ONE runs referenced only in Supplementary Table 2 (not provided in text)
  - No public code repository for custom analysis scripts (e.g., MaxLFQ post-processing in DIA-NN R package)
  - Spectronaut v.17/v.18 are commercial tools requiring license; no open-source alternative provided for library-free DIA
reproducibility_strengths:
  - Raw and processed data deposited in PRIDE (PXD042312) with full metadata
  - Detailed instrument parameters and acquisition methods reported for both nDIA and DDA
  - Use of standard, community-accepted tools (DIA-NN 1.8.1, Spectronaut, UniProt reference DB)
  - Explicit reporting of modifications, filtering thresholds, and quantification strategies
