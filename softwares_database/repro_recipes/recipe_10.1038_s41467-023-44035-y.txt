========== reproducibility_recipe entry ==========
paper_title: Open access repository-scale propagated nearest neighbor suspect spectral library for untargeted metabolomics.
source_paper: Bittremieux W et al. (2023), Nature communications, DOI: 10.1038/s41467-023-44035-y, PMID: 38123557
overall_reproducibility_score: 92/100

workflow_steps: 10
  Step 1: Raw data ingestion from MetaboLights
    tool: GNPS/MassIVE
    algorithm: mirroring
    parameters: ion_mode=positive, sample_count=10000
    input: raw .mzML or .mgf files from MetaboLights
    output: mirrored dataset collection on GNPS/MassIVE
    confidence: high
  Step 2: Molecular networking (first round, per-dataset)
    tool: GNPS
    algorithm: MS-Cluster + GNPS molecular networking
    parameters: precursor_mass_tolerance_mz=2.0, fragment_mass_tolerance_mz=0.5, cosine_similarity_threshold=0.8, min_matched_peaks=6, min_spectra_per_cluster=2, max_edges_per_node=10, mscluster_mixture_probability_threshold=0.05, mscluster_rounds=3, preprocessing={'remove_ions_near_precursor': True, 'remove_window_da': 17.0, 'top_ions_per_50_mz_window': 6}
    input: MS/MS spectra (.mgf)
    output: per-dataset molecular networks and consensus spectra
    confidence: high
  Step 3: Molecular networking (second round, cross-dataset)
    tool: GNPS
    algorithm: MS-Cluster + GNPS molecular networking
    parameters: precursor_mass_tolerance_mz=0.1, fragment_mass_tolerance_mz=0.1, cosine_similarity_threshold=0.8, min_matched_peaks=6, min_spectra_per_cluster=2, max_edges_per_node=10, preprocessing={'remove_ions_near_precursor': True, 'remove_window_da': 17.0, 'top_ions_per_50_mz_window': 6}
    input: consensus spectra from first-round networks
    output: integrated molecular network (13.2M edges)
    confidence: high
  Step 4: Spectral library searching for annotation
    tool: GNPS spectral library search
    algorithm: modified cosine similarity
    parameters: precursor_mass_tolerance_mz=2.0, fragment_mass_tolerance_mz=0.5, cosine_similarity_threshold=0.7, min_matched_peaks=6, reference_libraries_count=22, reference_spectra_count=221224
    input: MS/MS spectra
    output: annotated spectra (5.3% annotation rate)
    confidence: high
  Step 5: Nearest neighbor suspect identification
    tool: custom GNPS pipeline
    algorithm: propagated annotation via spectral similarity in molecular network
    parameters: max_precursor_mass_tolerance_ppm=20, cosine_similarity_threshold=0.8, min_matched_peaks=6, require_nonzero_precursor_delta=True, min_occurrence_of_delta_mass=10
    input: molecular network edges with one annotated and one unannotated spectrum
    output: suspect MS/MS spectra with structural relationship metadata
    confidence: high
  Step 6: Molecular formula prediction
    tool: SIRIUS (v4.5.2)
    algorithm: CSI:FingerID + CANOPUS
    parameters: precursor_mass_tolerance_ppm={'Orbitrap': 10, 'Q-TOF': 25}, input_data_type=MS/MS only, other_settings=default
    input: MS/MS spectra
    output: predicted molecular formulas (SIRIUS)
    confidence: high
  Step 7: Molecular formula prediction
    tool: BUDDY (v1.3)
    algorithm: elemental composition enumeration + scoring
    parameters: precursor_mass_tolerance_ppm={'FT-ICR': 5, 'Orbitrap': 10, 'Q-TOF': 25}, fragment_mass_tolerance_ppm=2× precursor tolerance, allowed_elements_initial=['C', 'H', 'N', 'O', 'P', 'S'], allowed_elements_extended=['C', 'H', 'N', 'O', 'P', 'S', 'F', 'Cl', 'Br', 'I']
    input: MS/MS spectra
    output: predicted molecular formulas (BUDDY)
    confidence: high
  Step 8: Delta mass calibration and modification annotation
    tool: UNIMOD + custom list
    algorithm: mass difference matching to biochemical modifications
    parameters: modification_sources=['UNIMOD', 'Supplementary Data 3'], min_delta_frequency=10
    input: precursor mass differences between suspect and reference
    output: putative modification annotations (e.g., 'oxidation', 'acetylation')
    confidence: medium
  Step 9: Suspect spectral library curation and naming
    tool: custom script
    algorithm: structured nomenclature generation
    parameters: naming_template=Suspect related to [compound name] (predicted molecular formula: [SIRIUS and/or BUDDY]) with delta m/z [sign delta] (putative explanation: [modification])
    input: suspect spectra + SIRIUS/BUDDY formulas + UNIMOD matches
    output: nearest neighbor suspect spectral library (87,916 entries)
    confidence: high
  Step 10: Library validation via spectral searching
    tool: GNPS spectral library search
    algorithm: cosine similarity search
    parameters: precursor_mass_tolerance_mz=2.0, fragment_mass_tolerance_mz=0.5, cosine_similarity_threshold=0.8, min_matched_peaks=6, test_datasets_total=1407, test_spectra_total=592000000, independent_test_set_size=72
    input: public MS/MS datasets on GNPS/MassIVE
    output: annotation gain metrics (e.g., % increase in identifications)
    confidence: high
