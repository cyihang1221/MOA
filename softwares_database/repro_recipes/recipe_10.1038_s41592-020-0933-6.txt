========== reproducibility_recipe entry ==========
paper_title: Feature-based molecular networking in the GNPS analysis environment.
source_paper: Nothias LF et al. (2020), Nature methods, DOI: 10.1038/s41592-020-0933-6, PMID: 32839597
overall_reproducibility_score: 87/100

workflow_steps: 4
  Step 1: Chromatographic feature detection and alignment
    tool: MZmine
    algorithm: GNPSExport module
    input: raw .mzML files
    output: feature table (peak list with RT, m/z, intensity)
    confidence: medium
  Step 2: Feature-based molecular networking (FBMN)
    tool: GNPS
    algorithm: feature-based clustering using MS/MS spectral similarity (cosine score)
    parameters: min_cosine_score=0.7, min_matched_peaks=6, max_shift_mz=0.02, precursor_mass_tolerance=0.02
    input: feature table + MS/MS spectra
    output: molecular network (graph of related features)
    confidence: high
  Step 3: Spectral clustering and annotation propagation
    tool: MZmine
    algorithm: spectral clustering (SIRIUS export integration)
    input: MS/MS spectra
    output: clustered spectra with putative annotations
    confidence: low
  Step 4: Cross-platform data export and integration
    tool: OpenMS, XCMS, MS-DIAL, MetaboScape
    algorithm: GNPSExport tools for format conversion
    input: platform-specific processed data (e.g., peak tables)
    output: GNPS-compatible .mgf + feature metadata
    confidence: medium
