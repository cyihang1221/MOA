workflow_steps: 7
  Step 1: Sample preparation and extraction
    tool: Manual protocol
    parameters: centrifugation_speed_rpm=13000, centrifugation_time_min=10, extraction_solvent=100% HPLC-grade methanol, dilution_ratio=1:10, diluent_composition=50% LC-MS grade methanol + 50% LC-MS grade water
    input: cell culture supernatant
    output: extracted metabolite samples ready for LC-MS
    confidence: high
  Step 2: LC-MS data acquisition
    tool: Thermo Fisher Scientific Vanquish UHPLC + Q Exactive HF Hybrid Quadrupole-Orbitrap
    parameters: chromatography_mode=HILIC, column=Syncronis HILIC, 100 mm × 2.1 mm, 2.1 μm, column_conditioning_injections=400, temperature_celsius=35, co2_percent=1.5, incubation_time_hours=72, time_points=[0, 72], biological_replicates=3
    input: extracted metabolite samples
    output: raw .raw files
    confidence: high
  Step 3: Data conversion
    tool: MSConvert GUI
    algorithm: ProteoWizard MSConvert
    parameters: output_format=mzXML
    input: raw .raw files
    output: mzXML files
    confidence: high
  Step 4: Metabolite detection and quantification
    tool: El-Maven (vv0.12.0)
    algorithm: peak integration with reference library matching
    parameters: library_type=in-house metabolite library (MetaSci), quantification_method=external standard curves, standards_source=Sigma-Aldrich
    input: mzXML files
    output: quantified metabolite table (intensity or concentration)
    confidence: high
  Step 5: Boundary flux calculation
    tool: Custom calculation (eq 1)
    algorithm: empirical boundary flux estimation
    parameters: formula=ΔC_sp / ΔC_med, time_delta_hours=72, normalization_target=medium control to correct evaporation & batch effects
    input: quantified metabolite table (0h and 72h, species + medium controls)
    output: boundary flux table (metabolite-wise flux values with STD and z-score)
    confidence: high
  Step 6: Statistical significance testing
    tool: Student t-test (paired)
    algorithm: paired sample t-test
    parameters: alpha=0.05
    input: metabolite concentration time-series (0h vs 72h)
    output: list of significantly changing metabolites (p < 0.05)
    confidence: high
  Step 7: Metabolic network refinement
    tool: MINNO
    algorithm: empirical network curation using metabolomics data
    parameters: genomic_input=NCBI refSeq, data_integration=metabolite presence/absence, flux directionality, orphan reaction inference
    input: species-specific genomic network + metabolomics-derived flux/concentration data
    output: refined metabolic network (KEGG-aligned with orphan reactions)
    confidence: medium

  - El-Maven peak picking parameters (e.g., m/z tolerance, RT window, noise threshold) not reported
  - No code or scripts provided for boundary flux calculation (eq 1) or z-score derivation
