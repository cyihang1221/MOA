  Step 5: DIA data quantification

    confidence: medium
  Step 6: DIA data quantification
    tool: PEAKS

    input: raw DIA .d files + spectral library
    output: protein-level quantification matrix
    confidence: medium
  Step 7: Sparsity reduction
    tool: DIA-NN built-in
    algorithm: SR75 (75% feature completeness threshold)
    parameters: completeness_threshold=0.75
    input: peptide/protein quantification matrix
    output: filtered quantification matrix
    confidence: high
  Step 8: Missing value imputation
    tool: Custom/Not specified
    algorithm: Zero imputation (evaluated negatively)

    input: quantification matrix with missing values
    output: imputed quantification matrix
    confidence: low
  Step 9: Normalization
    tool: Custom/Not specified
    algorithm: Quantile normalization (QN), Sum, Median, No normalization
    parameters: methods_evaluated=['QN', 'Sum', 'Median', 'none']
    input: imputed or raw quantification matrix
    output: normalized quantification matrix
    confidence: medium
  Step 10: Batch effect correction
    tool: Combat-NP, Combat-P, limma, Scanorama
    algorithm: Empirical Bayes (Combat), linear modeling (limma), manifold alignment (Scanorama)
    parameters: combat_method=['NP', 'P'], scanorama_stability=less stable
    input: normalized quantification matrix
    output: batch-corrected quantification matrix
    confidence: medium
  Step 11: Statistical differential expression analysis
    tool: DESeq2, limma-voom, limma-trend, edgeR-LRT
    algorithm: Negative binomial GLM (DESeq2), linear modeling on log-transformed counts (limma-voom), trended dispersion (limma-trend), likelihood ratio test (edgeR-LRT)
    parameters: p_value_threshold=0.05, log2_fold_change_threshold=0.263, fc_threshold_log2=0.263
    input: batch-corrected quantification matrix
    output: differential protein list (p < 0.05, |log2FC| > log2(1.2) or log2(1.5))
    confidence: high
  Step 12: Functional enrichment analysis
    tool: GO and Reactome enrichment tools
    algorithm: Hypergeometric test with multiple testing correction
    parameters: adjusted_p_value_threshold=0.05, enrichment_databases=['Gene Ontology', 'Reactome']
    input: differential protein list
    output: enriched biological terms table
    confidence: medium
  Step 13: Workflow performance ranking & interpretation
    tool: XGBoost + SHAP
    algorithm: Learning-to-rank with extreme gradient boosting; Shapley additive explanations
    parameters: top_percentile=25, feature_importance_metric=mean_absolute_shap, interaction_metric=shap_interaction_value, minimum_frequency_per_method=3
    input: matrix of method combination performances (metrics)
    output: feature importance and interaction rankings
    confidence: high

  - LC gradient profiles only partially specified (Supplementary Table 3 referenced but not provided in text)
