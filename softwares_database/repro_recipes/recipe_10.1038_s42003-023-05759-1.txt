reproducibility_gaps:

  - Progenesis QI is commercial software requiring license; no open-source alternative or parameter export details provided
  - No description of peak picking parameters (e.g., mass tolerance, RT window, min peak width) in Progenesis QI
  - No access to self-built metabolite database used for annotation
  - No code/scripts shared for correlation analysis (Step 8), OPLS-DA validation, or integration figures
  - 16S sequence data not linked to public repository (e.g., SRA, ENA); only 'Shanghai Majorbio' sequencing mentioned
  - R version 3.6.0 is outdated and unsupported; no script reproducibility guarantees

  - Internal standard (L-2-chlorophenylalanine) and QC usage described
  - MetaboAnalyst 5.0 web platform ensures partial computational reproducibility for pathway analysis
