sample_description: The sample used in the research consists of centroided liquid chromatography/mass spectrometry (LC/MS) data in the open-source .mzML format across N_tot samples in a cohort. Each sample file contains data points x = (rt, m/z, u), where rt is retention time, m/z is mass-to-charge ratio, and u is intensity. An individual peak is defined as a subset of data points from a single sample with nearly identical m/z values (corresponding to the same ion) and intensities forming a bell-shaped profile along the rt axis. Peaks corresponding to the same underlying ion across multiple samples constitute a peak group (or feature), characterized by similar shapes, nearly equal m/z values (with small variations due to machine precision), and non-linear rt drift across samples.
