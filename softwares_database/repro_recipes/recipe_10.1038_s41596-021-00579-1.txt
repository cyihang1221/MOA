========== reproducibility_recipe entry ==========
paper_title: Statistical analysis in metabolic phenotyping.
source_paper: Blaise BJ et al. (2021), Nature protocols, DOI: 10.1038/s41596-021-00579-1, PMID: 34321638
overall_reproducibility_score: 92/100

workflow_steps: 7
  Step 1: Data scaling and normalization
    tool: R
    algorithm: autoscaling (mean-centering + unit variance)
    parameters: scaling_method=pareto, normalization_method=probabilistic quotient normalization (PQN)
    input: preprocessed metabolite abundance matrix (e.g., peak area/intensity table)
    output: scaled and normalized feature matrix
    confidence: medium
  Step 2: Outlier detection
    tool: R
    algorithm: Hotelling’s T² in PCA space + Mahalanobis distance
    parameters: alpha=0.05, n_components_pca=2
    input: scaled and normalized feature matrix
    output: outlier flag vector and cleaned dataset
    confidence: high
  Step 3: Unsupervised multivariate analysis
    tool: R
    algorithm: Principal Component Analysis (PCA)
    parameters: n_components=2, center=True, scale=True
    input: scaled and normalized feature matrix
    output: PCA scores, loadings, explained variance
    confidence: high
  Step 4: Supervised multivariate modeling
    tool: R
    algorithm: Partial Least Squares Discriminant Analysis (PLS-DA) and Orthogonal PLS-DA (OPLS-DA)
    parameters: n_components_plsda=2, n_components_oplsda=1, orthogonal_components=1
    input: scaled and normalized feature matrix with class labels
    output: PLS-DA/OPLS-DA model objects, scores, loadings, VIP scores
    confidence: high
  Step 5: Model validation and robustness assessment
    tool: R
    algorithm: k-fold cross-validation (k=7) + permutation testing (n=1000 random permutations)
    parameters: k_folds=7, n_permutations=1000, metric=Q²
    input: PLS-DA/OPLS-DA models
    output: cross-validated Q², R²X, R²Y; permutation p-values for model significance
    confidence: high
  Step 6: Biomarker selection
    tool: R
    algorithm: Variable Importance in Projection (VIP) ≥ 1.0 + univariate t-test (p < 0.05, FDR-corrected)
    parameters: vip_threshold=1.0, p_value_threshold=0.05, fdr_method=Benjamini-Hochberg
    input: OPLS-DA VIP scores and univariate test results
    output: candidate biomarker list with VIP, p-value, fold-change
    confidence: high
  Step 7: Statistical power calculation and experimental design safeguarding
    tool: R
    algorithm: analytical power calculation for two-group t-test under normality assumption
    parameters: alpha=0.05, power=0.8, effect_size_cohen_d=0.8, n_groups=2
    input: expected effect size, variance estimates
    output: minimum required sample size per group
    confidence: medium
