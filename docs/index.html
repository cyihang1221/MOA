MassAgent

数据与科学问题进，分析方案、结果图与报告出

面向代谢组学等科研数据分析的任务驱动智能体：Agent A 规划、Agent B 执行、Agent C 可视化与报告；Web 端编排上传、计划评审、执行与出图。

工作流

从任务到报告的闭环

用户只提供原始数据与分析目标；系统完成需求理解、Pipeline 构建、工具调用、科研级可视化与报告撰写。未确认计划不得启动执行。

  1. 01 输入 上传 mzML / RAW / 特征表，描述分析目标，可选参考文献与元数据
  2. 02 规划 Agent A 生成结构化分析方案：流程、工具、预期结果与目标图表
  3. 03 评审 用户确认或提出修改；反馈修订后再次评审，直至锁定计划
  4. 04 执行 Agent B 按计划调用预处理、统计、注释、通路等工具
  5. 05 展示 Agent C 出图、解读并汇总 Markdown/PDF 报告；支持改图与拼图迭代

智能体分工

三个角色，一条契约

A → B → C 串行协同；分析计划文档是唯一接口契约。网页对用户透明地编排三者。

Agent A

分析规划

理解数据与科研问题，设计 Pipeline：步骤目标、工具调配、预期输出、可视化方案与报告结构。

  • 目的驱动，禁止套固定模板
  • 输出可评审的方案文档
  • 文献 / Skill / RAG 辅助选型

入 数据 + 任务 → 出 分析方案

Agent B

分析执行

解析已确认计划，自动调用质谱与统计工具，完成预处理、建模与结果整理，写入标准化结果目录。

  • 须先通过用户计划确认
  • 日志可复现（参数与版本）
  • 失败可降级或结构化报错

入 方案 + 数据 → 出 分析结果

Agent C

可视化与报告

按方案与 B 的结果生成科研图表、结果解释与最终报告；支持完成后的改图、拼图与报告迭代。

  • 图随分析目的设计，非固定套图
  • 结论绑定图表与结果文件
  • Markdown / PDF 输出

入 方案 + 结果 → 出 图 + 报告

Web 编排器

一个会话走完上传到报告

前端是 A/B/C 的编排界面：聊天式交互、侧栏五步进度与计划评审卡片，执行态避免幻觉进度。

欢迎与上传

拖放上传、分析目标示例、服务器路径导入大体积 RAW（硬链接，不经浏览器）。

计划评审

可滚动计划卡片与目录；确认执行或自然语言修改意见；锁定前可多轮修订。

状态机进度

侧栏同步 WAITING → PLANNING → 待确认 → EXECUTING → REPORTING；重置会真正清空任务与工作区。

图与报告

出图后可取色改图、拼图；顶栏进入报告；流式回复贴底跟随，支持中英文界面。

能力范围

代谢组学分析链路

  • 格式转换 / 峰检测对齐
  • XCMS · MZmine · OpenMS
  • 归一化与差异统计
  • 分子网络 / 谱库注释
  • 通路富集 · KEGG
  • PCA / OPLS · 火山图 · 热图
  • 文献 Skill 与参数 RAG
