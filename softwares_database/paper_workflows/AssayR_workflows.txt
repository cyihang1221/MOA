========== paper_workflow entry 1 ==========
related_tool: AssayR
sample_description: MRC5 primary human fibroblasts were metabolically labeled by switching to DMEM medium containing 25 mM 13C6-glucose for either 5 or 60 minutes. After incubation, the medium was aspirated, cells were rapidly washed with ice-cold PBS, and intracellular metabolites were extracted using a cold solvent mixture of 50:30:20 methanol/acetonitrile/water. Samples were prepared in biological triplicates for subsequent LC-MS analysis.
complete_workflow_description: The workflow begins with conversion of raw LC-MS data (Thermo .raw files) into standardized mzML format using msconvert_all(), a wrapper for ProteoWizard's msconvert utility (versions 11–12), generating separate positive- and negative-mode mzML files. AssayR, implemented in R, then loads these mzML files via the mzR package. For each analyte defined in the config file, AssayR extracts ion chromatograms across the specified m/z range (accounting for ppm tolerance and configured isotopologue offsets) and all relevant isotopic variants. Retention times are interpolated to a common grid, and the maximal chromatographic profile across all isotopologues and samples is used for peak detection—ensuring robust identification even when only one isotopologue shows a clear signal. Peak detection employs a Mexican hat (Ricker wavelet) convolution filter applied via R's filter() function; the filter width ('seconds') is adjustable and critical for handling poor chromatography (e.g., glucose on ZIC-pHILIC). Detected peaks are localized by start/end indices, and peak areas are computed by summing intensities over those ranges. When multiple peaks occur within the RT window, AssayR separates and colors them distinctly (e.g., green/yellow in Figure 3C) to support manual curation. The interactive peak picking interface allows real-time adjustment of filter width, m/z bounds, and intensity thresholds, with updated parameters written back to the config file upon user approval. Final outputs include: (1) a .csv file with samples as columns and metabolite-isotopologue combinations as rows (containing absolute peak areas), (2) PNG images of all extracted ion chromatograms (EICs) for quality control and metabolite identification—even in non-interactive mode, (3) stacked bar charts (both absolute and relative %) for each metabolite visualizing isotopologue distribution across samples, and (4) automated outlier detection based on inter-sample variance in labeling patterns.
