workflow_steps: 8
  Step 1: Data preprocessing and normalization for amplicon sequencing
    tool: microeco
    algorithm: various normalization methods (e.g., CSS, TSS, DESeq2-like variance-stabilizing)
    input: amplicon sequencing count tables (e.g., ASV/OTU tables)
    output: normalized abundance matrices
    confidence: medium
  Step 2: Alpha and beta diversity analysis
    tool: microeco
    algorithm: Shannon, Simpson, Chao1, observed ASVs (alpha); Bray-Curtis, Jaccard, weighted/unweighted UniFrac (beta)
    parameters: distance_method=bray-curtis, tree_file=None
    input: normalized abundance matrices
    output: diversity indices and distance matrices
    confidence: high
  Step 3: Core taxa identification
    tool: microeco
    algorithm: prevalence- and abundance-based core definition
    parameters: prevalence_threshold=0.5, abundance_threshold=0.01
    input: normalized abundance matrices
    output: core taxa lists
    confidence: high
  Step 4: Differential abundance testing with parametric community simulation
    tool: microeco
    algorithm: parametric simulation-based evaluation of testing methods (e.g., ANCOM-BC, ALDEx2, DESeq2, edgeR, limma-voom)
    parameters: n_simulations=100, effect_size=1.5, false_discovery_rate=0.05
    input: normalized abundance matrices + metadata
    output: differentially abundant features with performance metrics
    confidence: medium
  Step 5: Machine learning modeling (e.g., classification, regression)
    tool: microeco
    algorithm: random forest, SVM, XGBoost (via caret or mlr3 interfaces)
    parameters: cv_folds=5, repeats=3, tuning_grid_size=10
    input: normalized abundance matrices + metadata
    output: trained models, feature importance, cross-validated performance
    confidence: medium
  Step 6: Metagenomic data import and preprocessing
    tool: microeco
    algorithm: read and reformat gene/KEGG/EC abundance tables; functional profile normalization
    parameters: normalization_method=relative_abundance
    input: metagenomic functional abundance tables (e.g., HUMAnN3 output)
    output: normalized functional profile matrices
    confidence: low
  Step 7: Untargeted metabolomics differential testing
    tool: microeco
    algorithm: statistical testing (t-test, Wilcoxon, ANOVA) on metabolite intensities
    parameters: p_adjust_method=BH, alpha=0.05
    input: metabolite intensity matrix (features × samples)
    output: differentially abundant metabolites
    confidence: medium
  Step 8: Metabolite–microbe association analysis
    tool: microeco
    algorithm: Spearman/Pearson correlation, Mantel test, or generalized linear modeling
    parameters: correlation_method=spearman, p_adjust_method=BH, min_correlation=0.4
    input: metabolite intensity matrix + microbial abundance matrix
    output: significant microbe–metabolite associations
    confidence: medium
