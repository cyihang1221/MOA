========== reproducibility_recipe entry ==========
paper_title: An MSstats workflow for detecting differentially abundant proteins in large-scale data-independent acquisition mass spectrometry experiments with FragPipe processing.
source_paper: Kohler D et al. (2024), Nature protocols, DOI: 10.1038/s41596-024-01000-3, PMID: 38769142
overall_reproducibility_score: 78/100

workflow_steps: 4
  Step 1: DIA raw data processing with FragPipe
    tool: FragPipe
    algorithm: MSFragger + Philosopher
    input: raw .d or .raw DIA files
    output: peptide-level quantification table (PSMs, peptides, proteins)
    confidence: medium
  Step 2: Statistical analysis of protein abundance differences
    tool: MSstats
    algorithm: linear mixed-effects model
    parameters: model_formula=~ condition + (1|run) + (1|sample), normalization_method=global median, imputation_method=minProb, qvalue_threshold=0.05
    input: peptide-level quantification table from FragPipe
    output: protein-level differential abundance results (log2FC, p-value, q-value)
    confidence: high
  Step 3: Scalable analysis for memory-constrained large datasets
    tool: MSstatsBig
    algorithm: chunked linear mixed-effects modeling
    parameters: chunk_size=10000, n_cores=None
    input: peptide-level quantification table from FragPipe
    output: protein-level differential abundance results (log2FC, p-value, q-value)
    confidence: medium
  Step 4: Interactive exploration and visualization
    tool: MSstatsShiny
    algorithm: web-based R Shiny interface
    input: MSstats output (protein-level results)
    output: interactive plots (volcano, PCA, boxplots, etc.)
    confidence: high
