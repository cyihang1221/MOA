  Step 2: N-glycan release and labeling
    tool: nQuant
    algorithm: isotopic labeling quantification module
    input: raw LC-MS/MS data from isotopically labeled samples (e.g., 13C/15N metabolic labeling or chemical labeling)
    output: ratio-based quantified N-glycan table
    confidence: medium
  Step 3: Feature detection and alignment
    tool: nQuant
    algorithm: chromatographic peak detection and retention time alignment
    parameters: rt_tolerance_sec=10, mz_tolerance_ppm=10
    input: converted mzML files
    output: aligned feature table with RT-m/z clusters
    confidence: high
  Step 4: Glycan identification
    tool: nQuant
    algorithm: MS1 + MS/MS spectral matching against in-house N-glycan library
    parameters: min_ms2_matches=3, score_threshold=0.7
    input: feature table + MS/MS spectra
    output: annotated N-glycan list with structural assignments
    confidence: high
  Step 5: Quantitative normalization and statistical analysis
    tool: nQuant
    algorithm: within-run median normalization + between-run batch correction
    parameters: normalization_method=median, batch_correction=combat-like
    input: annotated feature table
    output: normalized, statistically tested glycan abundance matrix
    confidence: medium
