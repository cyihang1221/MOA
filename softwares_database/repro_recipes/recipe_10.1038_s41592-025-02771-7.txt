workflow_steps: 5
  Step 1: MSI peak calling (image generation)
    tool: uMAIA
    algorithm: Watershed-inspired two-step binning: (1) seeding via histogram maxima (Algorithm 1), (2) boundary expansion by local monotonicity (Algorithm 2)
    parameters: mz_bin_size=0.0001, gaussian_kernel_bandwidth=0.001, mass_tolerance_ppm=2, mz_range_min=400, mz_range_max=1200
    input: raw MALDI-MSI spectra (.imzML or vendor format)
    output: normalized ion images (.h5ad) and peak interval mapping (.csv)
    confidence: high
  Step 2: Peak matching across MSI datasets
    tool: uMAIA
    algorithm: Network flow-based optimization for unified feature space construction
    parameters: matching_constraint=closer m/z peaks preferred, no_external_reference_required=True
    input: peak lists with m/z intervals and intensities from multiple MSI acquisitions
    output: unified feature table (aligned m/z features across all samples)
    confidence: medium
  Step 3: Intensity normalization and batch effect removal
    tool: uMAIA
    algorithm: Total ion current (TIC) normalization per pixel + batch correction
    parameters: normalization_method=TIC per pixel, batch_correction_strategy=unspecified (described as 'intensity normalization for batch effect removal')
    input: unified feature table
    output: batch-corrected, normalized feature intensity matrix
    confidence: low
  Step 4: Lipid quantification (bulk LC-MS/MS)
    tool: TraceFinder (v4.1)
    algorithm: Stable isotope dilution quantification in timed SRM mode
    parameters: ionization_modes=['positive', 'negative'], adducts_positive=['[M+H]+', '[M+NH4]+'], adducts_negative=['[M+AcO]-', '[M-2H]-', '[M-H]-'], lipid_classes_quantified=['glycerolipids', 'glycerophospholipids', 'cholesterol esters', 'sphingolipids', 'free FAs'], number_of_lipids_quantified=1166, internal_standards_count=75, extraction_solvent=isopropanol prespiked with IS mixture
    input: raw LC-MS/MS .raw files
    output: concentration-estimated lipid abundance table
    confidence: high
  Step 5: Spatial transcriptomics processing (HybISS)
    tool: Spotiflow
    algorithm: Pretrained HybISS model for spot detection; starfish-inspired nearest-neighbor decoding
    parameters: spot_detection_model=pretrained HybISS, decoding_algorithm=starfish nearest-neighbor variant, z_projection_method=wavelet-based extended depth of field, tile_stitching_tool=ASHLAR, intercycle_registration_tool=wsireg (wraps elastix)
    input: multicycle fluorescence microscopy TIFF stacks
    output: decoded gene expression spatial maps
    confidence: high
