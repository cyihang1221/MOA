========== reproducibility_recipe entry ==========
paper_title: Building Block Extractor: An MS/MS Data Mining Tool for Targeted Discovery of Natural Products with Specified Features.
source_paper: Zhu D et al. (2023), Analytical chemistry, DOI: 10.1021/acs.analchem.3c00744, PMID: 37430188
overall_reproducibility_score: 82/100

workflow_steps: 5
  Step 1: MS/MS data preprocessing and molecular networking
    tool: GNPS
    algorithm: Molecular Networking (Cosine score)
    parameters: cosine_score_threshold=0.7, min_matched_peaks=6, max_mass_diff=1.0003
    input: centroided .mgf files
    output: molecular network graph (Cytoscape-compatible)
    confidence: medium
  Step 2: Building block definition and feature specification
    tool: Building Block Extractor (v1.0)
    algorithm: Rule-based MS/MS pattern matching
    parameters: product_ion_list=['m/z 121.065', 'm/z 107.049', 'm/z 93.033'], neutral_loss_list=['18.011', '36.022', '44.026'], sequential_neutral_loss_enabled=True, ion_abundance_weighting=True, minimum_relative_intensity=0.05
    input: molecular network nodes + corresponding MS/MS spectra
    output: filtered node list with annotated building blocks
    confidence: high
  Step 3: Targeted dereplication and novelty assessment
    tool: GNPS Library Search
    algorithm: Spectral similarity (dot product)
    parameters: min_similarity_score=0.5, top_k_matches=5
    input: extracted MS/MS spectra
    output: dereplicated candidates with library matches or novelty flags
    confidence: medium
  Step 4: Structural annotation and scaffold assignment
    tool: SIRIUS + CSI:FingerID
    algorithm: Fragmentation tree + molecular fingerprint prediction
    parameters: mass_accuracy_ppm=5.0, adducts=['[M+H]+', '[M+Na]+']
    input: feature table with MS1 and MS/MS
    output: annotated molecular formulas and compound classes
    confidence: low
  Step 5: Biological activity validation
    tool: in vitro antiviral assay
    algorithm: cell-based cytopathic effect (CPE) inhibition assay
    parameters: virus_strains=['A/Hongkong/8/68 (H3N2)', 'A/Puerto Rico/8/1934 (H1N1)', 'B/Lee/40'], cell_line=MDCK cells, assay_duration_hours=48, IC50_calculation_method=four-parameter logistic regression
    input: purified compounds
    output: IC50 values with confidence intervals
    confidence: high
