========== reproducibility_recipe entry ==========
paper_title: Sequence-to-sequence translation from mass spectra to peptides with a transformer model.
source_paper: Yilmaz M et al. (2024), Nature communications, DOI: 10.1038/s41467-024-49731-x, PMID: 39080256
overall_reproducibility_score: 92/100

workflow_steps: 8
  Step 1: Spectrum preprocessing
    tool: Custom Python pipeline
    algorithm: Peak filtering and intensity transformation
    parameters: mz_range_min=50, mz_range_max=2500, precursor_exclusion_window_da=2, intensity_threshold_percent=1, max_peaks_retained=150, intensity_transformation=square_root, intensity_normalization=sum_normalization
    input: raw .mgf or .mzML tandem mass spectra
    output: preprocessed peak list (m/z, intensity)
    confidence: high
  Step 2: Input embedding generation
    tool: Custom PyTorch implementation
    algorithm: Sinusoidal m/z embedding + linear intensity embedding
    parameters: embedding_dimension=512, lambda_min=0.001, lambda_max=10000, d_sin=256, d_cos=256
    input: preprocessed peak list
    output: d-dimensional peak embeddings
    confidence: high
  Step 3: Precursor embedding
    tool: Custom PyTorch implementation
    algorithm: Sinusoidal m/z embedding + categorical charge embedding
    parameters: precursor_mz_embedding=sinusoidal, charge_embedding_dim=16, max_charge_state=10
    input: precursor m/z and charge
    output: d-dimensional precursor embedding
    confidence: high
  Step 4: Transformer-based sequence-to-sequence modeling
    tool: PyTorch + custom transformer
    algorithm: Encoder-decoder transformer (Vaswani et al.)
    parameters: num_layers=9, embedding_size=512, num_attention_heads=8, total_parameters=47000000, vocabulary_size=28, max_peptide_length=100, stop_token_id=27
    input: peak embeddings + precursor embedding
    output: amino acid sequence logits
    confidence: high
  Step 5: Training with teacher forcing
    tool: PyTorch
    algorithm: Cross-entropy loss minimization
    parameters: batch_size=32, weight_decay=1e-05, peak_learning_rate=0.0005, warmup_steps=100000, learning_rate_schedule=linear warmup + cosine decay, training_epochs=1, validation_frequency_iterations=50000
    input: ground truth peptide sequences + spectrum embeddings
    output: trained Casanovo model weights
    confidence: high
  Step 6: Fine-tuning for non-enzymatic peptides
    tool: PyTorch
    algorithm: Transfer learning with reduced learning rate
    parameters: fine_tuning_learning_rate=5e-05, fine_tuning_epochs=5, validation_selection_criterion=minimum validation loss
    input: non-enzymatic training dataset + pretrained model
    output: fine-tuned Casanovo model
    confidence: high
  Step 7: Inference with beam search
    tool: Custom PyTorch inference
    algorithm: Autoregressive beam search decoding
    parameters: beam_width=user-specified k, termination_conditions=['stop_token', 'mass_tolerance_match', 'max_length_reached'], precursor_mass_tolerance_ppm=inference-time parameter ϵ, isotope_offset_handling=optional
    input: test spectrum + precursor info
    output: top-scoring peptide sequence
    confidence: high
  Step 8: Precursor mass filter
    tool: Custom post-processing
    algorithm: ppm mass error thresholding
    parameters: mass_error_ppm_threshold=ϵ (dataset-specific, e.g., instrument-dependent)
    input: predicted peptide sequence + precursor m/z/charge
    output: mass-filtered peptide prediction
    confidence: high
