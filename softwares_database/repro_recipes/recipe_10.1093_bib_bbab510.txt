workflow_steps: 8
  Step 1: Data clean-up
    tool: PhosPiR
    algorithm: custom R pipeline
    input: phosphoproteomic quantification table (e.g., from MaxQuant, Proteome Discoverer, or FragPipe)
    output: cleaned and normalized phosphosite-level matrix
    confidence: medium
  Step 2: Fast data overview
    tool: PhosPiR
    algorithm: descriptive statistics + PCA + sample correlation
    parameters: n_top_features=500
    input: cleaned phosphosite-level matrix
    output: summary statistics, PCA scores plot, sample correlation heatmap
    confidence: medium
  Step 3: Multiple statistical testing
    tool: PhosPiR
    algorithm: t-test, ANOVA, limma, Wilcoxon rank-sum
    parameters: adjust_method=BH, alpha=0.05, min_log2fc=0.585
    input: cleaned phosphosite-level matrix with experimental design
    output: differentially phosphorylated sites (DPS) list with p-values and FDR
    confidence: high
  Step 4: Differential expression analysis
    tool: PhosPiR
    algorithm: limma-based linear modeling
    parameters: design_matrix=user-specified, contrasts=user-defined
    input: normalized phosphosite matrix + design matrix
    output: limma results object (log2FC, t-statistics, p-values, FDR)
    confidence: medium
  Step 5: Phosphosite annotation and translation across species
    tool: PhosPiR
    algorithm: mapping via PhosphoSitePlus, UniProt, orthology inference (InParanoid/Ensembl Compara)
    parameters: source_species=human, target_species=mouse, confidence_threshold=0.8
    input: phosphosite identifiers (e.g., 'Q53H27_S23')
    output: annotated phosphosites with kinase-substrate relationships, conserved sites across species
    confidence: medium
  Step 6: Multilevel enrichment analyses
    tool: PhosPiR
    algorithm: over-representation analysis (ORA) and gene set enrichment analysis (GSEA) using clusterProfiler, DOSE, ReactomePA
    parameters: ontology=['GO_BP', 'KEGG', 'Reactome', 'DO'], p_cutoff=0.05, qvalue_cutoff=0.1
    input: list of differentially phosphorylated genes/proteins
    output: enriched pathways, biological processes, disease terms
    confidence: high
  Step 7: Proteome-wide kinase activity and substrate mapping
    tool: PhosPiR
    algorithm: kinase-substrate scoring using NetworKIN, iGPS, or PhosphoNET; activity inference via VIPER or Kinase-Substrate Enrichment Analysis (KSEA)
    parameters: ksea_score_method=z-score, ksea_permutations=1000
    input: differentially phosphorylated sites + kinase-substrate database
    output: kinase activity scores, ranked kinases, substrate networks
    confidence: medium
  Step 8: Network hub analysis
    tool: PhosPiR
    algorithm: protein-protein interaction (PPI) network construction (STRING, BioGRID), centrality analysis (degree, betweenness, closeness)
    parameters: ppi_confidence=0.7, network_type=undirected
    input: differentially phosphorylated proteins
    output: hub proteins, PPI subnetworks, centrality metrics
    confidence: medium
