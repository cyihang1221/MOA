    tool: Custom normalization in Compound Discovery/TraceFinder (vCompound Discovery 3.1, TraceFinder 4.0)

    algorithm: Chromatographic peak detection (m/z + RT)
    parameters: peak_detection_algorithm=not specified, min_peak_height=None, mz_tolerance_ppm=None, rt_tolerance_sec=None
    input: raw .raw files
    output: feature table (m/z, RT, intensity)

  Step 6: Statistical differential analysis
    tool: Custom R pipeline + MetaboAnalyst 5.0 (vMetaboAnalyst 5.0, ropls v1.26.4, pROC v1.18.0, glmnet v4.1-3)
    algorithm: Wilcoxon rank test with FDR correction + fold change filtering
    parameters: fdr_threshold=0.05, fold_change_threshold=[0.83, 1.2], normalization_method=sum normalization, scaling_method=auto scaling (mean-centered, unit variance)

    tool: Compound Discovery 3.1 + mzCloud + HMDB + ChemSpider (v3.1)

    parameters: mzCloud_score_threshold=85, annotation_levels=['identified', 'putatively_annotated'], standards_required_for_level1=True, MS_MS_matching_required=True

  Step 8: Pathway enrichment analysis
    tool: MetaboAnalyst 5.0 (v5.0)
    algorithm: KEGG pathway overrepresentation analysis
    parameters: database=KEGG, organism=Homo sapiens, statistical_method=hypergeometric test, multiple_testing_correction=FDR
    input: significantly differential annotated metabolites
    output: enriched metabolic pathways

  Step 9: Multivariate modeling (biomarker panel selection)
    tool: R glmnet (LASSO logistic regression) (vv4.1-3)
    algorithm: LASSO penalized binary logistic regression

  Step 10: Model validation and performance evaluation

reproducibility_gaps:
  - Raw .raw files require Thermo Xcalibur for conversion; no open-source converter explicitly validated
  - Compound Discovery 3.1 and TraceFinder 4.0 are commercial tools with no public parameter documentation for peak picking
  - No code repository provided for LASSO modeling, ROC analysis, or data preprocessing pipelines
  - Gradient details for negative mode lack exact pH adjustment method (e.g., ammonia addition volume/concentration)
  - No description of missing value imputation strategy or feature filtering thresholds (e.g., % present across samples)

  - Complete LC-MS parameters (gradients, temperatures, voltages, resolutions) provided for both polarities
  - Reference-based batch correction methodology fully described with QC injection scheme
  - Metabolite annotation criteria (mzCloud score >85, MS/MS matching) clearly defined
