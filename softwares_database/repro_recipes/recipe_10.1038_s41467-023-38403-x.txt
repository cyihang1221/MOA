reproducibility_gaps:
  - Raw MSI and LC/MS data not deposited in public repository (e.g., MetaboLights, MassIVE, or Zenodo)
  - Compound Discoverer 3.3 is commercial software requiring license; no open-source alternative workflow provided
  - No details on spatial segmentation or region-of-interest definition for MSI quantification
  - No description of Isotopologue Spectral Analysis (ISA) implementation — algorithmic and computational details missing
  - Gradient profile for HILIC is described but lacks dwell time, equilibration specifics, and system dispersion corrections
  - No metadata schema or sample annotation file provided (e.g., MAF or ISA-tab)
reproducibility_strengths:
  - Custom Python code for CCS calculation publicly available on GitHub
  - Detailed instrument parameters and acquisition settings reported for all platforms (DESI, MALDI, LC/MS, TWIMS)
  - Explicit chemical standards, matrix, solvents, and concentrations listed
  - Clear biological experimental design (n, labeling, controls, endpoints)
