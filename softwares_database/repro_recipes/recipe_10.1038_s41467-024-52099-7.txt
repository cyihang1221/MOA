paper_title: Uncovering missing glycans and unexpected fragments with pGlycoNovo for site-specific glycosylation analysis across species.
source_paper: Zeng WF et al. (2024), Nature communications, DOI: 10.1038/s41467-024-52099-7, PMID: 39277585
overall_reproducibility_score: 87/100

workflow_steps: 7
  Step 1: Full-range glycan enumeration
    tool: pGlycoNovo
    algorithm: combinatorial glycan composition enumeration
    parameters: max_HexNAc=15, max_Hex=20, max_Fuc=4, max_NeuAc=4, max_NeuGc=4, max_HexA=1, max_Xyl=1, mass_bin_resolution_Da=0.01
    input: user-defined monosaccharide constraints
    output: indexed glycan composition table (168,000 entries)
    confidence: high
  Step 2: Y-ion complementary mass matching
    tool: pGlycoNovo
    algorithm: glycan-first dynamic search
    input: MS2 spectrum peak list + precursor mass
    output: list of candidate glycan compositions per MS2 spectrum
    confidence: high
  Step 3: Y-complementary glycan graph construction
    tool: pGlycoNovo
    algorithm: directed acyclic graph (DAG) based on glyco-unit vector inclusion and max gap k
    parameters: max_glyco_gap_k=3
    input: matched glycan composition vectors
    output: directed graph G = (V, E) with glycan zero as source node
    confidence: high
  Step 4: Glycan deduction via dynamic programming
    tool: pGlycoNovo
    algorithm: longest-path dynamic programming on DAG
    parameters: normalization_by_glycan_size=True, top_n_candidates_kept=100
    input: Y-complementary glycan graph
    output: coarse-scored glycan candidates
    confidence: high
  Step 5: Glycan filtration
    tool: pGlycoNovo
    algorithm: core Y-ion count filter + diagnostic B-ion validation
    parameters: min_core_Y_ions_N-glycan=2, min_core_Y_ions_O-glycan=1, NeuAc_diagnostic_ions_mz=[274, 292], NeuGc_diagnostic_ions_mz=[290, 308]
    input: coarse-scored glycan candidates
    output: filtered glycan candidates
    confidence: high
  Step 6: Peptide retrieval and glycopeptide scoring
    tool: pGlycoNovo (within pGlyco3 environment)
    algorithm: peptide mass lookup + pGlyco3 peptide/glycan scoring fusion
    parameters: scoring_schema=identical to pGlyco3, theoretical_Y_ions_set=gj - gi for all gi < gj in matched glycan set
    input: filtered glycan candidates + precursor mass
    output: top-1 scored glycopeptide identifications per spectrum
    confidence: high
  Step 7: False discovery rate estimation
    tool: pGlycoNovo/pGlyco3
    algorithm: target-decoy approach (peptide-level FDR)
    parameters: fdr_threshold=None, glycan_level_qc_method=empirical score cutoff (not specified numerically)
    input: glycopeptide identifications
    output: FDR-controlled glycopeptide identifications
    confidence: medium
