workflow_steps: 6
  Step 1: Raw data conversion to IBF format
    tool: MS-DIAL 4 (v4)
    algorithm: Ion Mobility Base Framework (IBF) conversion
    parameters: im_binning_precision=3, mass_tolerance_ppm=10, lc_duration_min=20
    input: vendor raw files (.d for Bruker, .raw for Thermo, etc.)
    output: IBF format (.ibf) with accumulated IM-MS1 spectra and calibration metadata
    confidence: high
  Step 2: Peak picking in RT–m/z–IM space
    tool: MS-DIAL 4 (v4)
    algorithm: Three-dimensional peak detection (RT + m/z + IM)
    parameters: mass_tolerance_ppm=10, rt_peak_width_s=[10, 30], im_peak_width_ms=[30, 60], min_peak_height=None, min_snr=None
    input: IBF files
    output: feature table with RT, m/z, CCS (Å²), peak height/area, and assigned MS/MS
    confidence: medium
  Step 3: CCS calculation
    tool: MS-DIAL 4 (v4)
    algorithm: Mason–Schamp equation (Bruker), single-field method (Agilent), IM calibration function (Waters)
    parameters: ccs_tolerance_Å2=[2, 3, 5, 7]
    input: IM-MS raw data with calibrant parameters (beta, intercept, t0, exponent, coefficient)
    output: collision cross-section (CCS) values in Å² per feature
    confidence: high
  Step 4: Lipid annotation using hybrid scoring system
    tool: MS-DIAL 4 (v4)
    algorithm: Decision tree + spectral similarity (dot/reverse dot product) + fragment ion logic
    parameters: dot_product_threshold=0.1, reverse_dot_product_threshold=0.5, fragment_relative_abundance_cutoff_percent=0.1, rt_tolerance_min=0.75, ccs_tolerance_Å2=[2, 3, 5, 7], fdr_target_percent=1.0, lipid_subclasses_count=117
    input: Feature table + MS/MS spectra + lipid spectral library
    output: Annotated lipid features with molecular species-level or species-level identification and FDR estimate
    confidence: high
  Step 5: Semi-quantification and normalization
    tool: MS-DIAL 4 (v4)
    algorithm: Peak area-based semi-quantification with internal standard correction (not explicitly detailed)
    parameters: normalization_method=internal_standard_based, estimated_fdr_percent=1.0, lipids_annotated=8051
    input: Annotated feature table with peak areas
    output: Semi-quantified lipid abundance matrix
    confidence: low
  Step 6: Hierarchical clustering of lipid subclass counts
    tool: MS-DIAL 4 or external tool (unspecified)
    algorithm: Hierarchical clustering with scaling (−1 to 1)
    parameters: scaling_range=[-1, 1], clustering_metric=Euclidean distance, linkage_method=average
    input: Lipid subclass count matrix
    output: Clustered heatmap of lipid subclass distribution across samples
    confidence: medium
