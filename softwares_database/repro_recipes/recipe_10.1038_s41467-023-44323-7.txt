  Step 5: Baseline de novo tool execution

    output: candidate peptide sequences + scores

  Step 6: Baseline de novo tool execution

    algorithm: attention-based de novo sequencing

    input: MGF files
    output: candidate peptide sequences + scores
    confidence: low
  Step 7: Spectral bin reclassification
    tool: PyTorch (v1.8.1)
    algorithm: AA-gapped convolutional neural network
    parameters: bin_resolution_da=1.0, max_mz=2000, num_layers=16, filters_per_layer=20, dropout_rate=0.3, learning_rate=4e-05, batch_size=512, optimizer=Adam, loss_function=focal loss, early_stopping=True, lr_scheduler=reduce on plateau, amino_acid_masses=20 canonical + Met(O), dilation_scheme=AA-mass-based
    input: binned spectrum (intensity sums, Prosit-predicted intensities, ground truth b/y labels)
    output: per-bin b-ion/y-ion probability predictions
    confidence: high
  Step 8: Guided mutation via graph-based random walks
    tool: custom Python implementation
    algorithm: weighted random walk on b/y-complement graph
    parameters: min_probability_threshold=0.35, source_mz=19.0, target_mz_rounding=discretized experimental precursor mass + proton, edge_labeling_rule=amino acid masses matching m/z difference, y-ion_prior_weight=0.01
    input: bin reclassification probabilities + candidate peptide
    output: mutated peptide candidates
    confidence: medium
  Step 9: Peptide-spectrum confidence scoring (Spectralis-score)
    tool: scikit-learn (v0.24.2)
    algorithm: random forest regression
    parameters: target_transform=log2(d + 1), loss=squared_error, n_features=114, feature_groups=['similarity', 'counting', 'bin_reclassification_threshold_changes'], thresholds_for_bin_changes=[0.25, 0.3, 0.35, 0.4, 0.45, 0.5], spectral_comparison_tolerance_ppm=20, intensity_threshold=0.02, similarity_metrics=['spectral_angle', 'pearson', 'cosine', 'mean_abs_diff', 'std_abs_diff', 'quantiles', 'max', 'min'], counting_metrics=['#corresponding_peaks', 'fraction_corresponding_peaks', '4-way_zero_nonzero_combinations']
    input: experimental vs Prosit-predicted spectra + bin reclassification outputs
    output: Levenshtein distance estimate → Spectralis-score
    confidence: high
