  Step 1: Acquisition of GC-MS analytical descriptors
    tool: Gas Chromatography-Mass Spectrometry (GC-MS)

    input: chemical standard mixtures and contaminated oil samples
    output: analytical descriptors: retention index (RI) and mass spectral features (e.g., m/z intensities)
    confidence: medium
  Step 2: Feature engineering from analytical descriptors
    tool: Custom preprocessing pipeline
    algorithm: spectral binning and RI normalization
    parameters: mz_bin_width_da=0.1, ri_range=[500, 5000], ri_bin_width=10
    input: raw GC-MS chromatograms and spectra
    output: numerical feature vector per compound (RI + binned m/z intensities)
    confidence: low
  Step 3: Model training with XGBoost
    tool: XGBoost
    algorithm: gradient boosting decision trees
    parameters: n_estimators=1000, max_depth=6, learning_rate=0.01, subsample=0.8, colsample_bytree=0.8, objective=reg:squarederror
    input: analytical descriptor feature matrix and reference property/toxicity values
    output: trained QSAR regression models per endpoint
    confidence: medium
  Step 4: Model validation and performance evaluation
    tool: Custom Python script
    algorithm: cross-validation and RMSE calculation
    parameters: cv_folds=5, metric=RMSE
    input: test set predictions vs. experimental reference values
    output: RMSE scores per endpoint
    confidence: low
  Step 5: Web deployment and inference
    tool: Detective-QSAR web application
    algorithm: XGBoost model serving
    input: user-submitted GC-MS analytical descriptors (RI + spectrum)
    output: predicted physicochemical properties and toxicities
    confidence: high
