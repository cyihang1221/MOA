========== reproducibility_recipe entry ==========
paper_title: Expanding Urinary Metabolite Annotation through Integrated Mass Spectral Similarity Networking.
source_paper: Neto FC et al. (2021), Analytical chemistry, DOI: 10.1021/acs.analchem.1c02041, PMID: 34436864
overall_reproducibility_score: 82/100

workflow_steps: 10
  Step 1: Raw data conversion to mzXML
    tool: ProteoWizard MSConvert
    algorithm: mzXML conversion
    parameters: encoding_precision=32-bit, compression=zlib
    input: vendor .d files (Agilent Q-TOF)
    output: mzXML files
    confidence: high
  Step 2: Peak detection, alignment, and deconvolution
    tool: Progenesis QI (v2.2.5826.42898)
    algorithm: proprietary peak picking and alignment
    input: mzXML files
    output: feature table (.CSV) and MS2 spectral summary (.MSP)
    confidence: medium
  Step 3: MS1-based metabolite annotation
    tool: Progenesis QI (v2.2.5826.42898)
    algorithm: database search (exact mass + RT)
    parameters: databases=['HMDB', 'Urine Metabolome Database']
    input: feature table (MS1)
    output: MSI level 1/2 annotations (putative identifications)
    confidence: medium
  Step 4: MS2 library matching (GNPS workflow)
    tool: GNPS METABOLOMICS-SNETS
    algorithm: molecular networking with cosine similarity scoring
    parameters: parent_mass_tolerance_da=0.02, fragment_mass_tolerance_da=0.02, precursor_exclusion_window_da=17, min_cosine_score=0.7, topk_neighbors=10, max_connected_component_size=100, min_matched_peaks=2, min_cluster_size=1
    input: mzXML files uploaded to GNPS FTP
    output: molecular network clusters with library-matched annotations
    confidence: high
  Step 5: Substructure discovery via MS2LDA
    tool: MS2LDA
    algorithm: unsupervised motif extraction (Mass2Motifs)
    input: MS2 spectra (.MSP or GNPS-formatted)
    output: Mass2Motifs with substructure annotations (via MotifDB)
    confidence: medium
  Step 6: In silico annotation propagation
    tool: Network Annotation Propagation (NAP)
    algorithm: neighborhood-aware candidate re-ranking using in silico fragmentation and spectral library matching
    input: molecular network + MS2LDA motifs + GNPS annotations
    output: propagated candidate annotations (MSI level 2/3)
    confidence: medium
  Step 7: Integrated network construction and annotation merging
    tool: MolNetEnhancer
    algorithm: multilayered molecular network integration
    input: GNPS network, MS2LDA motifs, NAP predictions
    output: enhanced molecular network with merged annotations
    confidence: low
  Step 8: Chemical ontology classification
    tool: ClassyFire
    algorithm: hierarchical chemical classification
    input: annotated molecular network nodes (SMILES or InChI)
    output: chemical superclass/subclass/class annotations
    confidence: high
  Step 9: Feature-based molecular networking (FBMN)
    tool: GNPS FBMN workflow
    algorithm: molecular networking using feature-aligned MS2 spectra
    parameters: parent_mass_tolerance_da=0.02, fragment_mass_tolerance_da=0.02, precursor_exclusion_window_da=17, min_cosine_score=0.7, topk_neighbors=10, max_connected_component_size=100, min_matched_peaks=2, min_cluster_size=2
    input: Progenesis QI feature table (.CSV) and MS2 spectral summary (.MSP)
    output: feature-aligned molecular network
    confidence: high
  Step 10: Network visualization
    tool: Cytoscape (v3.2.1)
    algorithm: graph layout and annotation mapping
    input: MolNetEnhancer-enhanced molecular network (graph format)
    output: annotated network figures (e.g., Figures 3–5)
    confidence: high

reproducibility_gaps:
  - Progenesis QI is commercial software requiring license and is not open-source
  - Exact chromatographic gradient profile lacks flow rate ramping details and dwell time specifications
  - No public link to full Supporting Information containing QTOF/MS parameters and sample preparation details
  - No code or scripts provided for MolNetEnhancer integration pipeline (only GitHub repo without workflow execution instructions)
  - ClassyFire input format (SMILES/InChI generation method) and version not specified
reproducibility_strengths:
  - Raw LC-MS/MS data publicly available in MassIVE (MSV000087011, MSV000087012)
  - All web tools used (GNPS, MS2LDA, NAP, ClassyFire) are freely accessible with documented parameters
  - MolNetEnhancer source code available on GitHub under MIT license
  - Full parameter sets reported for GNPS and FBMN workflows
  - Explicit MSI confidence level reporting (level 2: 275 compounds; level 3: 459+/578+)
