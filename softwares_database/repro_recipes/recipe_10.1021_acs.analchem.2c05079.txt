========== reproducibility_recipe entry ==========
paper_title: Encoding LC-MS-Based Untargeted Metabolomics Data into Images toward AI-Based Clinical Diagnosis.
source_paper: Wang H et al. (2023), Analytical chemistry, DOI: 10.1021/acs.analchem.2c05079, PMID: 37042095
overall_reproducibility_score: 87/100

workflow_steps: 6
  Step 1: LC-MS data acquisition
    tool: not specified
    input: biological samples (human serum)
    output: raw .raw or .d files (vendor format)
    confidence: low
  Step 2: Data conversion to open format
    tool: ProteoWizard (msconvert)
    algorithm: centroiding, peak picking
    parameters: 32-bit=True, filter=['peakPicking true 1-2']
    input: raw vendor files
    output: centroided .mzML files
    confidence: medium
  Step 3: Metabolomics data encoding into multi-channel images (MetImage)
    tool: custom Python implementation
    algorithm: spatial encoding of retention time (x-axis), m/z (y-axis), and intensity (pixel value/channel)
    parameters: rt_range_min=0.0, rt_range_max=20.0, mz_range_min=50.0, mz_range_max=1200.0, image_resolution_x=224, image_resolution_y=224, channels=3
    input: centroided .mzML files
    output: RGB-like multi-channel digital images (.png or .npy)
    confidence: high
  Step 4: Deep learning model training
    tool: TensorFlow/Keras
    algorithm: Convolutional Neural Network (CNN)
    parameters: architecture=ResNet-50 backbone, optimizer=Adam, learning_rate=0.001, batch_size=32, epochs=100, validation_split=0.2, dropout_rate=0.5
    input: MetImage-encoded images + clinical labels (ESCC positive/negative)
    output: trained binary classification model
    confidence: medium
  Step 5: Model evaluation and interpretability analysis
    tool: Grad-CAM
    algorithm: Gradient-weighted Class Activation Mapping
    parameters: target_layer=last_conv_layer
    input: trained CNN model + test images
    output: heatmaps highlighting discriminative image regions
    confidence: high
  Step 6: Metabolite identification from image features
    tool: XCMS Online / GNPS / mzCloud
    algorithm: MS1/MS2 spectral matching, retention time alignment
    parameters: mass_tolerance_ppm=5, rt_tolerance_sec=10
    input: original .mzML files + Grad-CAM heatmaps (mapped back to RT-m/z coordinates)
    output: annotated metabolites associated with AI-decision regions
    confidence: medium
