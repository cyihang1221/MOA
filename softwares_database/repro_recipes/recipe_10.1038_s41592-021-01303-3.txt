========== reproducibility_recipe entry ==========
paper_title: Metabolite discovery through global annotation of untargeted metabolomics data.
source_paper: Chen L et al. (2021), Nature methods, DOI: 10.1038/s41592-021-01303-3, PMID: 34711973
overall_reproducibility_score: 82/100

workflow_steps: 6
  Step 1: Ion peak detection and feature table generation
    tool: XCMS
    algorithm: centWave
    parameters: ppm=5, peakwidth=[10, 60], snthr=10, prefilter=[5, 100], noise=1000
    input: raw .mzML files
    output: feature table (m/z, RT, intensity)
    confidence: medium
  Step 2: Retention time alignment and correction
    tool: XCMS
    algorithm: obiwarp
    parameters: profiling=true, span=0.3
    input: feature table
    output: aligned feature table with corrected RT
    confidence: medium
  Step 3: Global network-based annotation (NetID)
    tool: NetID (v1.0)
    algorithm: global network optimization using atom difference rules and retention time consistency
    parameters: mass_tolerance_ppm=5, rt_tolerance_sec=30, max_atom_diff=10, min_rt_correlation=0.7, decoy_strategy=target-decoy, fdr_threshold=0.05
    input: aligned feature table + MS2 spectra (if available) + reference databases (HMDB, YMDB, PBCM, PBCM_BIO)
    output: annotated network (nodes = peaks, edges = chemically plausible relationships)
    confidence: high
  Step 4: Annotation validation and FDR estimation
    tool: custom R script
    algorithm: target-decoy strategy with 10 randomized decoy libraries
    parameters: n_decoy_libraries=10, fdr_method=Benjamini-Hochberg
    input: NetID output network + ground truth annotations (n=314)
    output: FDR-validated annotations with confidence scores
    confidence: medium
  Step 5: Isotope tracer analysis and flux validation
    tool: custom Python/R scripts
    algorithm: M+X labeling pattern matching and isotopic envelope fitting
    parameters: labeling_source=[U-13C]glucose, incubation_time=24 h, temperature=30
    input: LC-MS feature table from labeled/unlabeled samples
    output: isotopologue distribution table and flux-informed metabolite assignments
    confidence: low
  Step 6: Structural confirmation via NMR
    tool: SelTOCSY
    algorithm: 2D NMR spectral assignment
    parameters: pulse_sequence=SelTOCSY, mixing_time_ms=80, temperature=25
    input: chemically synthesized N-glucosyl-taurine
    output: NMR-confirmed structure and stereochemistry (α-linkage)
    confidence: high
