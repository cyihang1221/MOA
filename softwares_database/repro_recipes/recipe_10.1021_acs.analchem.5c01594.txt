    output: domain-adapted embedding model
    confidence: high
  Step 5: Compound retrieval via cross-modal similarity search
    tool: CSU-MS²
    algorithm: cosine similarity search in unified embedding space
    parameters: top_k=10, similarity_threshold=None
    input: query MS/MS spectrum
    output: ranked list of candidate molecular structures (SMILES)
    confidence: high
  Step 6: Database construction: Spectrum-searchable Structural Feature Database (SSFDB)
    tool: Custom pipeline
    algorithm: structural feature extraction + embedding indexing
    parameters: source_databases=23, feature_representation=ECFP4 + RDKit descriptors, indexing_method=FAISS
    input: molecular structures from 23 structural databases
    output: searchable structural feature database (SSFDB)
    confidence: medium
