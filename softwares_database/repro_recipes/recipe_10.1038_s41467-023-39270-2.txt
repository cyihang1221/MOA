  Step 2: Raw file conversion to mzML

    input: raw .raw and .wiff files
    output: .mzML files
    confidence: high
  Step 3: Glycopeptide search with MSFragger-Glyco
    tool: MSFragger-Glyco (vv3.5)
    algorithm: non-specific cleavage search with sequon filtering
    parameters: variable_modifications=['methionine oxidation', 'N-terminal acetylation', 'cysteinylation'], glycan_list_size=198, peptide_length_class_II=[7, 25], peptide_length_class_I=[7, 12], peptide_length_proteome=[7, 50], enzymatic_cleavage=non-specific for class II/I; fully enzymatic for proteome, sequon_filter=N-X-S/T (target) and reversed sequon (decoy), oxonium_ion_threshold=summed intensity ≥ 10% of base peak, mass_tolerance_precursor_ppm=20, mass_tolerance_fragment_ppm=15, monoisotopic_error_allowed=[1, 2], parameter_optimization=per-study, built-in in MSFragger
    input: mzML files + protein database (UniProt Swiss-Prot UP000005640 + contaminants + reversed decoys)
    output: PSM-level search results (glycosylated and non-glycosylated)
    confidence: high
  Step 4: FDR-controlled filtering with Philosopher
    tool: Philosopher (vv4.5.1-RC10)
    algorithm: group-specific semi-parametric FDR filtering
    parameters: fdr_level=0.01, delta_mass_cutoff_da=145, peptideprophet_model=semi-parametric, f_value_contributor=expectation value, ntt_model_disabled=True, filtering_sequence=['group-specific PSM FDR', 'peptide-level FDR', 'protein-level FDR', 'sequential removal of PSMs mapping to non-FDR-passing proteins']
    input: MSFragger-Glyco PSM results
    output: FDR-filtered glycosylated and non-glycosylated PSMs at 1% level
    confidence: high
  Step 5: Glycan assignment
    tool: PTM-Shepherd
    algorithm: N-glycan deconvolution using default database
    parameters: glycan_database=default N-glycan database, q_value_threshold=0.05
    input: FDR-filtered PSMs
    output: confidently assigned glycopeptides with glycan structures
    confidence: medium
  Step 6: HLA-binding motif deconvolution (MoDec)
    tool: MoDec
    algorithm: clustering-based motif discovery
    parameters: max_clusters=10, max_runs=20, min_peptide_length=12, grouping_unit=subject (replicate instances)
    input: glycosylated HLA peptides
    output: HLA motif clusters requiring manual annotation
    confidence: medium
  Step 7: HLA-binding motif deconvolution (NetMHCIIpan)
    tool: NetMHCIIpan (v4.1)
    algorithm: percentile rank–based allele assignment
    parameters: percentile_rank_threshold=20, assignment_rule=assign to lowest-scoring (best-binding) allele per subject, alleles_considered=all MHC alleles expressed per subject
    input: unique glycosylated peptides + subject-specific HLA alleles
    output: allele-assigned glycopeptides without manual intervention
    confidence: high
  Step 8: Data processing and visualization
    tool: Python (Anaconda) + R (vPython 3.9, R 4.1.2)
    algorithm: custom analysis pipeline
    parameters: python_packages=['Biopython==1.79', 'Matplotlib==3.5.1', 'Plotly==4.14.3', 'Scikit-learn==1.0.2', 'Pandas==1.4.1', 'Pyteomics==4.5.3', 'Matplotlib-venn==0.11.6', 'Seaborn==0.11.2', 'UMAP-learn==0.5.2', 'HDBSCAN==0.8.28', 'xlrd==2.0.1', 'Logomaker==0.8'], r_packages=['R-essentials', 'R-base==4.1.2', 'R-devtools==2.4.3']
    input: filtered glycopeptides + allele assignments + metadata
    output: figures, tables, HLA-Glyco resource
    confidence: high
