========== reproducibility_recipe entry ==========
paper_title: Metabolic profiling stratifies colorectal cancer and reveals adenosylhomocysteinase as a therapeutic target.
source_paper: Vande Voorde J et al. (2023), Nature metabolism, DOI: 10.1038/s42255-023-00857-0, PMID: 37580540
overall_reproducibility_score: 87/100

workflow_steps: 9
  Step 1: Data acquisition via untargeted LC-MS and MSI
    tool: mass spectrometry
    input: snap-frozen intestinal tissue samples
    output: raw .raw or .d files (vendor format)
    confidence: low
  Step 2: Peak detection and feature extraction
    tool: XCMS
    algorithm: centWave
    parameters: peakwidth=[10, 60], ppm=5, snthr=10
    input: raw vendor files
    output: feature table (m/z, RT, intensity)
    confidence: medium
  Step 3: Retention time alignment and peak matching
    tool: XCMS
    algorithm: obiwarp
    parameters: method=obiwarp, profiling=True
    input: feature list from multiple samples
    output: aligned feature table with sample-matched peaks
    confidence: medium
  Step 4: Gap filling and missing value imputation
    tool: XCMS
    algorithm: fillpeaks
    parameters: minfrac=0.5, max=100
    input: aligned feature table
    output: complete feature matrix (samples × features)
    confidence: medium
  Step 5: Statistical analysis and biomarker discovery
    tool: R (DESeq2, limma, stats) (vDESeq2 v1.22.2)
    algorithm: Wald test (DESeq2), moderated t-test (limma)
    parameters: alpha=0.05, padj=BH, log2FC_threshold=1.0
    input: normalized feature matrix
    output: differentially abundant metabolites (DAIs)
    confidence: high
  Step 6: Multivariate statistical modeling (PCA, PLS-DA)
    tool: R (mixOmics, factoextra)
    algorithm: PCA, PLS-DA
    parameters: ncomp=3, scale=True
    input: scaled/centered feature matrix
    output: scores plots, loadings, variable importance (VIP)
    confidence: medium
  Step 7: Metabolite annotation and identification
    tool: GNPS, HMDB, METLIN, mzCloud
    algorithm: MS1 accurate mass matching, MS/MS spectral library matching
    parameters: mass_tolerance_ppm=5, rt_tolerance_sec=30, cosine_score_threshold=0.7
    input: feature table with MS/MS spectra
    output: putatively annotated metabolites (level 2)
    confidence: medium
  Step 8: Pathway enrichment analysis
    tool: MetaboAnalyst
    algorithm: hypergeometric test, impact analysis
    parameters: organism=Mus musculus, database=KEGG, p_value_cutoff=0.05
    input: list of significantly altered metabolites
    output: enriched metabolic pathways (e.g., methionine cycle)
    confidence: high
  Step 9: Integration with transcriptomics (RNA-seq)
    tool: R (DESeq2, clusterProfiler) (vDESeq2 v1.22.2)
    algorithm: correlation (Spearman), joint pathway enrichment
    parameters: correlation_method=spearman, p_adj_cutoff=0.05, rho_threshold=0.6
    input: metabolite fold-changes + gene fold-changes
    output: co-regulated metabolite-gene modules, integrated pathway maps
    confidence: medium
