========== reproducibility_recipe entry ==========
paper_title: Analysis of DIA proteomics data using MSFragger-DIA and FragPipe computational platform.
source_paper: Yu F et al. (2023), Nature communications, DOI: 10.1038/s41467-023-39869-5, PMID: 37438352
overall_reproducibility_score: 78/100

workflow_steps: 12
  Step 1: Raw data conversion to mzML
    tool: ProteoWizard (v76)
    algorithm: vendor peak picking and demultiplexing
    input: raw vendor files (.raw, .d, .wiff)
    output: mzML files
    confidence: medium
  Step 2: Direct DIA spectral library search
    tool: MSFragger-DIA (v3.5)
    algorithm: fragment ion indexing-based database search
    parameters: enzyme=restricted trypsin, fixed_modifications=['Carbamidomethyl C'], variable_modifications=['Protein N-terminal acetylation', 'Oxidation M'], max_missed_cleavages=1, decoy_generation=reversed sequences
    input: mzML files (DIA)
    output: peptide-spectrum matches (PSMs)
    confidence: high
  Step 3: Deep learning-based score refinement
    tool: MSBooster
    algorithm: deep learning rescoring
    input: PSMs from MSFragger-DIA
    output: boosted PSM scores
    confidence: low
  Step 4: Posterior error probability estimation and FDR control
    tool: Percolator (v33)
    algorithm: semi-supervised machine learning for PSM rescoring
    parameters: fdr_threshold=0.01
    input: boosted PSMs
    output: FDR-filtered PSMs (1% PSM FDR)
    confidence: high
  Step 5: Protein inference
    tool: ProteinProphet (v34)
    algorithm: probabilistic protein inference
    input: FDR-filtered PSMs
    output: protein groups with posterior probabilities
    confidence: low
  Step 6: FDR filtering at peptide and protein levels
    tool: Philosopher (v55)
    algorithm: global and run-specific FDR filtering
    parameters: global_peptide_fdr=0.01, global_protein_fdr=0.01, run_specific_precursor_fdr=0.01, run_specific_protein_fdr=0.01
    input: ProteinProphet output
    output: FDR-filtered peptide and protein lists
    confidence: high
  Step 7: Spectral library building
    tool: EasyPQP
    algorithm: library generation from identified peptides
    parameters: fdr_threshold=0.01
    input: FDR-filtered peptides
    output: PQP-formatted spectral library
    confidence: medium
  Step 8: DIA quantification using spectral library
    tool: DIA-NN (v1.8.1)
    algorithm: library-based extraction and quantification
    input: mzML files + PQP library
    output: precursor-, peptide-, and protein-level quantification tables
    confidence: high
  Step 9: Peptide-to-protein roll-up and normalization
    tool: iq R package
    algorithm: MaxLFQ normalization
    input: DIA-NN quantification table
    output: normalized protein intensity matrix
    confidence: medium
  Step 10: Alternative quantification (Spectronaut)
    tool: Spectronaut (v14 and 17)
    algorithm: directDIA / directDIA+
    parameters: precursor_fdr=0.01, run_specific_protein_fdr=0.01, global_protein_fdr=0.01
    input: raw vendor files
    output: normalized protein intensity matrix
    confidence: high
  Step 11: Library-free DIA quantification
    tool: DIA-NN (v1.8.1)
    algorithm: in silico spectral library prediction
    input: mzML files + FASTA database
    output: quantification table
    confidence: high
  Step 12: Hybrid DIA/DDA analysis
    tool: MSFragger (DDA mode) + MSFragger-DIA (v3.5)
    algorithm: integrated DDA-assisted DIA search
    parameters: enzyme=restricted trypsin, fixed_modifications=['Carbamidomethyl C'], variable_modifications=['Protein N-terminal acetylation', 'Oxidation M'], max_missed_cleavages=1
    input: mzML files (DIA and DDA)
    output: combined spectral library and quantification
    confidence: high
