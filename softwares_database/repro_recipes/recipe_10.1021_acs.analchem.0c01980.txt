  Step 2: Data conversion to open format
    tool: MS-DIAL (vv4.0 or later (implied by CorrDec integration))
    algorithm: vendor file conversion
    input: raw DIA-MS files
    output: converted peak list and MS2 spectra in MS-DIAL internal format
    confidence: medium
  Step 3: Feature detection and chromatographic alignment
    tool: MS-DIAL (vv4.0 or later)
    algorithm: centWave-like (for DIA) + retention time alignment
    parameters: peak_width_min=5, peak_width_max=60, min_peak_height=1000, rt_shift=0.2, rt_criterion=0.3
    input: converted DIA-MS files
    output: aligned feature table with precursor m/z, RT, and intensity matrix
    confidence: medium
  Step 4: Correlation-based MS2 deconvolution (CorrDec)
    tool: MS-DIAL (CorrDec module) (vv4.0+ (integrated into MS-DIAL))
    algorithm: correlation-based spectral deconvolution using Pearson/Spearman correlation across samples
    parameters: min_correlation_coefficient=0.7, min_sample_count_for_correlation=10, correlation_method=Pearson, fragment_intensity_threshold=0.01, precursor_fragment_correlation_window=0.5
    input: aligned feature table + DIA MS2 spectra
    output: deconvoluted, compound-specific MS2 spectra
    confidence: high
  Step 5: Metabolite annotation and identification
    tool: MS-DIAL (vv4.0+)
    algorithm: spectral matching against in-house and public MS2 libraries (e.g., MassBank, GNPS, HMDB)
    parameters: mass_tolerance_ppm=5, retention_time_tolerance_sec=5, match_factor_threshold=700, reverse_match_factor_threshold=700
    input: CorrDec-deconvoluted MS2 spectra
    output: annotated metabolite list with confidence levels (Level 1–2)
    confidence: high
  Step 6: Validation and performance assessment
    tool: Custom R/Python scripts (not shared)
    algorithm: randomized subsampling + dilution series evaluation
    parameters: n_subsamples=100, sample_subset_sizes=[10, 20, 50, 100, 224], dilution_factors=[1, 2, 4, 8, 16]
    input: CorrDec vs MS2Dec output comparisons
    output: deconvolution accuracy metrics (e.g., % correctly deconvoluted spectra, FDR-adjusted recall)
    confidence: low
