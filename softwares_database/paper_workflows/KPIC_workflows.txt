complete_workflow_description: The end-to-end workflow begins with raw LC-MS data from two untargeted metabolomics datasets (liquor and left-sided colon cancer). First, pure ion chromatograms are extracted using KPIC2 — a method that applies K-means clustering to deconvolve co-eluting features and isolate chemically pure signals. Next, the resulting feature matrix is subjected to uniform manifold approximation and projection (UMAP) for nonlinear dimensionality reduction and visualization of group separation. Finally, extreme gradient boosting (XGBoost) is applied to build discriminant classification models using the KPIC2-extracted features. Model performance is evaluated on test sets, achieving 100% classification accuracy for both datasets — outperforming XCMS-based feature extraction followed by XGBoost (92% and 96%, respectively). The integration of UMAP and XGBoost into the KPIC2 package constitutes a unified, automated pipeline extending beyond feature extraction to include visualization and supervised modeling.
