paper_title: Symbolic Aggregate Approximation Improves Gap Filling in High-Resolution Mass Spectrometry Data Processing.
source_paper: Müller E et al. (2020), Analytical chemistry, DOI: 10.1021/acs.analchem.0c00899, PMID: 32786516
overall_reproducibility_score: 87/100

workflow_steps: 5
  Step 1: Raw data conversion to mzML
    tool: ProteoWizard msconvert
    algorithm: default conversion settings
    input: vendor raw files (.raw, .d, .wiff)
    output: centroided .mzML files
    confidence: medium
  Step 2: Feature detection and alignment
    tool: MZmine 2 (v2.38)
    algorithm: CentWave detector
    parameters: mass_tolerance_ppm=5, rt_tolerance_sec=0.5, sn_threshold=10, min_time_span_sec=0.05, min_height=10000
    input: centroided .mzML files
    output: aligned feature table (CSV/peak list)
    confidence: high
  Step 3: Gap filling using SAX
    tool: Custom R implementation
    algorithm: Symbolic Aggregate Approximation (SAX)
    parameters: window_size=10, alphabet_size=3, paa_segments=5, distance_metric=euclidean, similarity_threshold=0.85
    input: aligned feature table with missing values
    output: gap-filled feature table
    confidence: high
  Step 4: Comparison with baseline gap filling
    tool: MZmine 2 Peak Finder (v2.38)
    algorithm: Peak Finder (intensity-based interpolation)
    parameters: min_peak_height_ratio=0.1, max_rt_gap_sec=5, min_intensity_ratio=0.05
    input: aligned feature table with missing values
    output: gap-filled feature table (MZmine baseline)
    confidence: high
  Step 5: Performance evaluation of gap filling
    tool: Custom R scripts
    algorithm: Recall-precision analysis using spiked standards
    parameters: spike_concentration_range_ng_mL=[0.1, 1, 10, 100], n_replicates=3, true_positive_threshold_intensity_ratio=0.2
    input: gap-filled tables + spiked standard metadata
    output: recall, precision, F1-score per compound
    confidence: medium
