========== reproducibility_recipe entry ==========
paper_title: Utilizing Skyline to analyze lipidomics data containing liquid chromatography, ion mobility spectrometry and mass spectrometry dimensions.
source_paper: Kirkwood KI et al. (2022), Nature protocols, DOI: 10.1038/s41596-022-00714-6, PMID: 35831612
overall_reproducibility_score: 87/100

workflow_steps: 9
  Step 1: Data import and setup
    tool: Skyline
    algorithm: vendor-neutral raw file import
    input: raw LC-IMS-CID-MS files (e.g., .d, .raw, .wiff)
    output: loaded Skyline document (.sky)
    confidence: high
  Step 2: Library import and lipid definition
    tool: Skyline
    algorithm: small-molecule spectral library matching
    parameters: library_source=manually validated 500+ lipid library, library_format=Skyline spectral library (.skylib), filtering_enabled=True, indexed_retention_time_filtering=True, ion_mobility_filtering=True
    input: custom lipid spectral library (.skylib), transition lists (Supplementary Table 1)
    output: annotated precursor/transition list in Skyline document
    confidence: high
  Step 3: Retention time prediction and calibration
    tool: Skyline
    algorithm: iRT (indexed Retention Time) calibration
    parameters: iRT_calibrants=positive-mode iRT calibrants, calibration_method=linear regression, reference_peptides=iRT kit peptides
    input: iRT calibrant chromatograms (Fig. 4), peptide standards
    output: iRT-predicted retention times for lipids
    confidence: high
  Step 4: Ion mobility drift time alignment and filtering
    tool: Skyline
    algorithm: indexed ion mobility (IM) filtering
    parameters: IM_tolerance_ms=5.0, IM_calibration_enabled=True
    input: LC-IMS-CID-MS raw data with IM dimension
    output: IM-aligned and filtered peak groups
    confidence: medium
  Step 5: Peak detection and integration
    tool: Skyline
    algorithm: chromatogram-based peak picking with integrated area calculation
    parameters: peak_detection_method=integrated peak area, integration_algorithm=smoothed baseline + valley detection, minimum_peak_width_seconds=2.0, signal_to_noise_threshold=3.0
    input: processed LC-IMS-CID-MS chromatograms
    output: quantified peak areas per lipid per sample
    confidence: medium
  Step 6: Annotation validation
    tool: Skyline
    algorithm: manual and semi-automated spectral match validation
    parameters: match_score_threshold=0.7, MS_MS_library_matching=True, fragment_mass_tolerance_ppm=10.0, precursor_mass_tolerance_ppm=5.0
    input: MS/MS spectra, spectral library entries (Fig. 7), chromatographic co-elution evidence
    output: validated lipid annotations with confidence flags
    confidence: high
  Step 7: Replicate consistency assessment
    tool: Skyline
    algorithm: coefficient of variation (CV) and correlation-based replicate comparison
    parameters: CV_threshold_percent=20.0, Pearson_r_threshold=0.85
    input: quantified peak areas across technical/biological replicates
    output: replicate agreement metrics (Fig. 8)
    confidence: high
  Step 8: iRT performance evaluation
    tool: Skyline
    algorithm: iRT calibration residual analysis
    parameters: residual_threshold_minutes=0.5, calibration_curve_R2_threshold=0.98
    input: iRT calibrant retention times vs. predicted iRT
    output: iRT calibration quality report (Fig. 9)
    confidence: high
  Step 9: Results export and library curation
    tool: Skyline
    algorithm: CSV/TSV export and spectral library editing
    parameters: export_format=TSV, include_MS_MS_spectra=True, include_chromatograms=False, library_editing_mode=manual curation
    input: validated Skyline document (.sky)
    output: quantification table, updated spectral library (.skylib)
    confidence: high
