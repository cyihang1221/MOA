  Step 4: Library search and metabolite annotation
    tool: NIST MS Search
    algorithm: spectral matching (dot product or similar)
    parameters: match_threshold=None, mass_tolerance_ppm=None, min_match_peaks=None

    output: annotated DMED-FAHFA identifications

  Step 6: Integrated annotation using in silico library

    input: MS-DIAL feature table + .msp library

    confidence: medium
