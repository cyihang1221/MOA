========== reproducibility_recipe entry ==========
paper_title: Evaluating the Effect of Data Merging and Postacquisition Normalization on Statistical Analysis of Untargeted High-Resolution Mass Spectrometry Based Urinary Metabolomics Data.
source_paper: Brix F et al. (2024), Analytical chemistry, DOI: 10.1021/acs.analchem.3c01380, PMID: 38113356
overall_reproducibility_score: 87/100

workflow_steps: 9
  Step 1: Data acquisition
    tool: FT-ICR-MS
    parameters: ionization=ESI, polarity=['positive', 'negative']
    input: raw urine samples
    output: raw .d files (Bruker format)
    confidence: medium
  Step 2: Data conversion
    tool: CompassXtract
    parameters: output_format=mzML
    input: raw .d files
    output: mzML files
    confidence: low
  Step 3: Feature detection and alignment
    tool: OpenMS (v2.7.0)
    algorithm: FeatureFinderCentroided
    parameters: mass_tolerance_ppm=2, rt_tolerance_sec=15, min_charge=1, max_charge=3
    input: mzML files
    output: featureXML files
    confidence: high
  Step 4: Peak table generation
    tool: OpenMS (v2.7.0)
    algorithm: FeatureLinkerUnlabeledQT
    parameters: link_rt_tolerance_sec=30, link_mz_tolerance_ppm=3
    input: featureXML files
    output: consensusXML → peak table (CSV/TSV)
    confidence: high
  Step 5: Data merging strategy evaluation
    tool: R
    algorithm: custom workflow comparing merge-before-normalize vs. merge-after-normalize
    parameters: merge_modes=['positive+negative before norm', 'positive+negative after norm'], normalization_methods=['PQN', 'CVSN', 'QC-RSV', 'TSS', 'Median', 'SVD', 'LOESS', 'Creatinine']
    input: peak table (per mode)
    output: merged normalized feature tables
    confidence: medium
  Step 6: Postacquisition normalization
    tool: R packages: metid, norm, or custom scripts
    algorithm: Probabilistic Quotient Normalization (PQN)
    parameters: reference_quantile=0.95, qnorm_method=median
    input: peak table (unnormalized)
    output: normalized peak table
    confidence: medium
  Step 7: Quality control assessment
    tool: R
    algorithm: PCA on QC samples
    parameters: n_components=2, metric=euclidean
    input: normalized peak table
    output: QC sample similarity metrics (e.g., CV%, clustering distance)
    confidence: medium
  Step 8: Statistical analysis and classification
    tool: R
    algorithm: PLS-DA, RF, t-test
    parameters: n_components_plsda=3, n_trees_rf=500, p_value_threshold=0.05, fdr_method=BH
    input: normalized peak table with metadata
    output: differential features, classification accuracy, feature importance
    confidence: medium
  Step 9: Evaluation of normalization performance
    tool: R
    algorithm: five-criteria scoring: (1) QC CV reduction, (2) biological group separation (PLS-DA R²Y/Q²), (3) feature stability (CV across QCs), (4) correlation with creatinine, (5) preservation of biological variance (ANOVA F-statistic)
    parameters: criteria_weights=[0.2, 0.25, 0.2, 0.15, 0.2]
    input: normalized peak table + metadata + QC metrics
    output: normalization method ranking scores
    confidence: high
