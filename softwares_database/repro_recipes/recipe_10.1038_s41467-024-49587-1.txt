========== reproducibility_recipe entry ==========
paper_title: Discovering type I cis-AT polyketides through computational mass spectrometry and genome mining with Seq2PKS.
source_paper: Yan D et al. (2024), Nature communications, DOI: 10.1038/s41467-024-49587-1, PMID: 38918378
overall_reproducibility_score: 42/100

workflow_steps: 8
  Step 1: BGC identification
    tool: antiSMASH (v24)
    algorithm: HMMER-based homology search
    parameters: flanking_region_bp=10000
    input: microbial genome FASTA (contigs)
    output: polyketide biosynthetic gene clusters (BGCs)
    confidence: high
  Step 2: PK domain and tailoring enzyme annotation
    tool: HMMER (v43)
    algorithm: hidden Markov model profile matching
    input: BGC nucleotide/protein sequences
    output: domain architecture (AT, KR, DH, ER, tailoring enzymes)
    confidence: high
  Step 3: AT substrate specificity prediction
    tool: Seq2PKS (custom Extra-Trees model)
    algorithm: Extremely Randomized Trees
    parameters: n_estimators=150, max_depth=10, cross_validation_folds=5
    input: 24-residue AT active site sequences (one-hot encoded)
    output: predicted AT substrate (e.g., malonyl, methylmalonyl, ethylmalonyl)
    confidence: high
  Step 4: Module-level substructure prediction
    tool: Seq2PKS (rule-based)
    algorithm: domain logic rules (KR→DH→ER cascade)
    input: AT substrate + presence/absence of KR/DH/ER domains per module
    output: hypothetical polyketide core substructures
    confidence: medium
  Step 5: Assembly line order prediction
    tool: Seq2PKS (custom logistic regression)
    algorithm: logistic regression on BLAST bit-score features
    parameters: n_neighbors=3, positive_samples=382, negative_samples=382, W_forward=1.0, W_backward=1.0
    input: docking domain sequences (N-terminal 50 aa, C-terminal 100 aa)
    output: ranked candidate assembly pathways
    confidence: high
  Step 6: Post-assembly modification prediction
    tool: Seq2PKS (rule-based + Ullman subgraph isomorphism)
    algorithm: Ullman algorithm for motif matching + SMILES-based reaction application
    input: core polyketide structures + tailoring enzyme inventory
    output: set of hypothetical mature polyketide structures (SMILES)
    confidence: medium
  Step 7: Mass spectral database search
    tool: Dereplicator+ (v25)
    algorithm: exact mass spectral matching
    input: hypothetical SMILES + LC-MS/MS spectra (mzML or .raw)
    output: matched compound candidates with scores
    confidence: high
  Step 8: Variable mass spectral search
    tool: Variable Dereplicator+ (v25)
    algorithm: variable modification-aware spectral matching
    input: hypothetical SMILES + LC-MS/MS spectra
    output: matched compounds with unknown modifications
    confidence: high
