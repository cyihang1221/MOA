paper_title: Power of mzRAPP-Based Performance Assessments in MS1-Based Nontargeted Feature Detection.
source_paper: El Abiead Y et al. (2022), Analytical chemistry, DOI: 10.1021/acs.analchem.1c05270, PMID: 35671103
overall_reproducibility_score: 87/100

workflow_steps: 4
  Step 1: Benchmark molecule selection and spike-in
    tool: mzRAPP
    algorithm: internal benchmark list generation
    parameters: n_benchmark_molecules=10
    input: raw .mzML files with known internal standard compounds
    output: benchmark peak list (true positives with expected m/z, RT, intensity)
    confidence: medium
  Step 2: MS1 feature detection
    tool: XCMS
    algorithm: centWave
    parameters: peakwidth=[10, 60], ppm=5, snthresh=10, prefilter=[5, 100]
    input: raw .mzML files
    output: feature table (m/z, RT, intensity matrix)
    confidence: high
  Step 3: Feature table performance assessment against benchmark
    tool: mzRAPP
    algorithm: completeness and abundance accuracy evaluation
    parameters: completeness_threshold=0.95, abundance_error_threshold=0.2
    input: feature table + benchmark peak list
    output: performance metrics (completeness %, abundance RMSE, false discovery rate)
    confidence: high
  Step 4: Parameter optimization guided by mzRAPP metrics
    tool: mzRAPP
    algorithm: iterative parameter sweep
    parameters: parameter_space=['ppm', 'peakwidth', 'snthresh'], grid_resolution=coarse
    input: performance metrics across parameter sets
    output: optimized parameter configuration for XCMS
    confidence: medium
