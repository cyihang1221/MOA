sample_description: The study used standard reference material NIST SRM 1950 (human plasma) samples, with five replicate injections analyzed in both positive and negative ionization modes. Samples were prepared according to standard metabolomics protocols for plasma, and full-scan high-resolution mass spectrometry data were acquired. The raw data included 6715 features in positive mode and 4666 features in negative mode after initial xcms feature extraction.
software_configuration_description: RAMClustR (the R implementation of RAMClust) was used as a comparative method for pseudo-spectrum annotation and redundant peak removal. It was applied to the same filtered MS1 feature table generated by xcms (after retention time filtering, IPO-optimized peak picking, retention time correction, peak filling, intensity-based filtering [3× fold change over matrix], and RSD filtering [<30% in SRM replicates]). RAMClustR performed clustering based on peak correlation and predefined paired-mass distances to group adducts, isotopes, and in-source fragments into pseudo-spectra; however, the paper does not specify version number, distance thresholds, correlation cutoffs, or other algorithmic parameters — only that it was used 'as a precursor peaks selection algorithm' alongside CAMERA and PMDDA for benchmarking.
source_paper: Miao et al. (2022), Journal of cheminformatics, DOI: 10.1186/s13321-022-00586-8, PMID: 35172886

sample_description: Two distinct biological datasets were analyzed: (1) a cerebrospinal fluid (CSF) dataset derived from equine CSF samples, and (2) a human urine dataset. The CSF samples were processed with leupeptin (a protease inhibitor) added prior to processing, and both datasets were acquired using liquid chromatography–mass spectrometry (LC-MS) with data-dependent MS/MS acquisition across both low- and high-collision-energy conditions. The analysis involved ~120,000 feature-level measurements across samples, with features extracted from raw LC-MS data — though the specific number of biological replicates, species (e.g., human vs. equine), sample collection protocols, extraction methods, or instrument parameters are not detailed in the provided text.
software_configuration_description: RAMClustR (the R implementation of RAMClust) was applied directly to the full feature matrix (xset) to perform feature clustering based on both low- and high-collision-energy MS/MS data. It generated compound-level spectra by aggregating features within clusters, enabling spectral matching against reference libraries (e.g., NIST). Performance was benchmarked against CAMERA functions (groupFWHM, groupCorr, groupDen) using default parameter settings; RAMClustR yielded higher MS/MS similarity scores (0.382 for CSF, 0.228 for Urine), more clusters containing ≥2 features (3248 for CSF, 827 for Urine), and moderate singleton rates (15.47% for CSF, 32.75% for Urine). The tool is available as an R package on GitHub, but specific algorithmic parameters (e.g., distance metrics, clustering thresholds, or spectral reconstruction rules) are not detailed in the provided text.
source_paper: Broeckling et al. (2014), Analytical Chemistry, DOI: 10.1021/ac501530d
