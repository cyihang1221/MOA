  Step 2: Metabolite and lipid categorization
    tool: KEGG database, LIPID MAPS Structure Database (LMSD)
    algorithm: manual curation / database mapping
    parameters: polar_categories=['amino acids', 'carbohydrates', 'lipids', 'nucleotides', 'peptides', 'vitamins and cofactors', 'xenobiotics', 'others'], lipid_categories=['fatty acyls', 'glycerolipids', 'glycerophospholipids', 'sphingolipids', 'sterol lipids']
    input: annotated metabolite/lipid identifiers (e.g., KEGG IDs, LMSD IDs)
    output: categorized metabolite/lipid table
    confidence: high
  Step 3: Differential abundance (DA) scoring per pathway
    tool: custom R implementation
    algorithm: non-parametric DA test (Benjamini–Hochberg corrected Mann–Whitney U test)
    parameters: fdr_threshold=0.05, da_score_formula=upregulated_count - downregulated_count / total_measured_in_pathway
    input: metabolite-level fold changes and p-values (tumor vs normal)
    output: pathway-level DA scores (up/down/combined), range [-1, 1]
    confidence: high
  Step 4: Metabolomic clustering (SNF-based integrative clustering)
    tool: R package SNFtools
    algorithm: Similarity Network Fusion (SNF)
    parameters: fdr_threshold=0.01, log2fc_threshold=1.0, sd_filter_metabolites=200, sd_filter_lipids=400, k_clusters=3, cluster_estimation_method=['Eigen-gap best', 'rotation cost best']
    input: filtered polar metabolite and lipid abundance matrices
    output: three metabolomic subtypes (C1, C2, C3)
    confidence: high
  Step 5: Metabolite–gene reaction-level matching
    tool: Recon3D human metabolic network reconstruction
    algorithm: substrate/product–gene mapping via enzymatic reactions
    parameters: reaction_reversibility_considered=True, excluded_complex_lipid_mappings=True
    input: polar metabolite identifiers, Recon3D reaction database
    output: gene–metabolite reaction pairs (Supplementary Table S7)
    confidence: medium
  Step 6: Association analysis: somatic mutations ↔ metabolites/lipids
    tool: R (linear regression)
    algorithm: logistic regression (logit link)
    parameters: covariates=['metabolomic_subtype', 'tumor_size', 'lymph_node_count', 'age', 'BMI'], mutation_threshold=≥6% prevalence in at least one subtype, binary_mutation_encoding=True, significance_metric=T-statistic and p-value, fdr_correction=True
    input: binary mutation matrix, metabolite/lipid subclass abundance matrix
    output: mutation–metabolite association statistics (T, p, FDR)
    confidence: high
  Step 7: Association analysis: SCNAs ↔ metabolites/lipids
    tool: R (linear regression)
    algorithm: linear regression
    parameters: scna_peaks=97, scna_source=GISTIC2.0 all_lesions.conf_95.txt, covariates=['metabolomic_subtype', 'tumor_size', 'lymph_node_count', 'age', 'BMI'], lipid_summarization=mean log2 abundance per subclass
    input: SCNA segment matrix (GISTIC peaks), metabolite/lipid subclass abundance matrix
    output: SCNA–metabolite association statistics (T, p)
    confidence: high
  Step 8: Association analysis: mRNA expression ↔ metabolites/lipids
    tool: R (linear regression)
    algorithm: linear regression
    parameters: expression_threshold={'log2fc': 1.0, 'fdr': 0.01}, cancer_gene_source=network of cancer gene datasets, breast_cancer_oncogene_filter=True, included_genes=27
    input: RNA-seq expression matrix, metabolite/lipid subclass abundance matrix
    output: mRNA–metabolite association statistics (T, p)
    confidence: high
  Step 9: Machine-learning classification of BLIS tumors
    tool: R packages glm, e1071, glmnet, pROC
    algorithm: LASSO-penalized logistic regression & SVM
    parameters: resampling=bootstrap, cross_validation=5-fold, tuning_parameter=lambda, performance_metric=AUC (ROC), feature_contribution_definition=abs(coefficient_i) / sum(abs(coefficients))
    input: metabolite abundance matrix (BLIS subset)
    output: subtype classifier model, AUC scores, feature importance ranking
    confidence: high
  Step 10: Transcriptomic/metabolic-gene-based subtyping of cell lines
    tool: R packages GSVA, Rtsne
    algorithm: ssGSEA + t-SNE
    parameters: ssgsea_parameters={'min_size': 10, 'max_size': 500, 'n_permutations': 10000}, tsne_parameters={'perplexity': 30, 'max_iter': 1000}
    input: RNA-seq data (cohort & CCLE), metabolic pathway gene sets
    output: cell line subtyping assignments (transcriptomic, metabolic-gene-based, metabolomic)
    confidence: medium
