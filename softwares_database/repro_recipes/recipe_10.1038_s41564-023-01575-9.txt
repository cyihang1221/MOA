========== reproducibility_recipe entry ==========
paper_title: microbeMASST: a taxonomically informed mass spectrometry search tool for microbial metabolomics data.
source_paper: Zuffa S et al. (2024), Nature microbiology, DOI: 10.1038/s41564-023-01575-9, PMID: 38316926
overall_reproducibility_score: 82/100

workflow_steps: 10
  Step 1: Public MS/MS data collection from GNPS/MassIVE
    tool: ReDU
    algorithm: manual and systematic curation
    parameters: date_range=May–July 2022, ionization_modes=['positive', 'negative'], sample_type=monocultures only
    input: publicly deposited .mzML/.mzXML files in GNPS/MassIVE
    output: curated list of 60,781 LC–MS/MS files from 537 datasets
    confidence: high
  Step 2: Metadata harmonization and taxonomic curation
    tool: NCBI Taxonomy API + manual curation
    algorithm: BLAST-based taxonomic name resolution + manual NCBI ID assignment
    parameters: mass_tolerance_da=0.02, taxonomic_ranks_kept=['kingdom', 'phylum', 'class', 'order', 'family', 'genus', 'species', 'strain', 'subgenus', 'subspecies', 'variety']
    input: raw metadata from GNPS/MassIVE + ReDU outputs
    output: microbe_masst_table.csv (with MassIVE IDs, NCBI IDs, taxonomy, QC/blank flags)
    confidence: high
  Step 3: Taxonomic tree generation
    tool: taxize (v0.9.100)
    algorithm: NCBI lineage retrieval
    parameters: r_version=4.2.2, python_version=3.10, ete3_tree_method=NCBI-based
    input: microbe_masst_table.csv (NCBI IDs)
    output: Newick tree → JSON tree with sample counts per taxon and QC/blank nodes
    confidence: high
  Step 4: MASST fast search execution
    tool: Fast Search Tool (FASST) API
    algorithm: precursor-mass-indexed spectral similarity search (modified cosine score)
    parameters: precursor_mass_tolerance=0.05, fragment_mass_tolerance=0.05, min_cosine_score=0.7, min_matched_peaks=3, analogue_search=False
    input: USI or .mgf file (MS/MS spectra)
    output: list of matching spectra with metadata and cosine scores
    confidence: high
  Step 5: Taxonomic tree visualization
    tool: D3.js
    algorithm: JSON tree filtering + D3 hierarchical rendering
    input: FASST search results + microbeMASST taxonomic JSON tree
    output: interactive HTML taxonomic tree
    confidence: medium
  Step 6: Batch spectral filtering (mouse study)
    tool: custom Python script
    algorithm: cosine similarity + delta parent mass filtering
    parameters: cosine_threshold=0.7, delta_parent_mass_da=0.02
    input: Molecular network output (.mgf, .tsv, .qza), networkedges_selfloop file
    output: filtered .mgf file (n = 2,425 spectra)
    confidence: medium
  Step 7: Compound class prediction
    tool: SIRIUS + CANOPUS
    algorithm: machine learning–based compound class annotation
    parameters: max_mz=850
    input: MS/MS spectra (.mgf)
    output: compound class predictions (e.g., flavonoid, lipid)
    confidence: high
  Step 8: Cross-dataset spectral matching
    tool: FASST API (again)
    algorithm: same as step 4
    parameters: precursor_mass_tolerance=0.05, fragment_mass_tolerance=0.05, min_cosine_score=0.7, min_matched_peaks=3
    input: filtered .mgf (n = 2,425)
    output: matched spectra against MSV000080918 (antibiotic-treated mice)
    confidence: high
  Step 9: Set-based analysis (Venn/UpSet)
    tool: VennDiagram, UpSetR, ComplexUpset (v1.7.3, 1.4.0, 1.3.3)
    algorithm: intersection analysis of spectral matches across conditions/datasets
    input: lists of USIs or spectrum IDs from multiple searches
    output: Venn diagram / UpSet plot
    confidence: high
  Step 10: Human disease/body site mapping
    tool: GNPS web interface + ReDU metadata
    algorithm: metadata-driven aggregation
    input: USIs of matched spectra
    output: distribution table of spectra across diseases and anatomical sites
    confidence: medium
