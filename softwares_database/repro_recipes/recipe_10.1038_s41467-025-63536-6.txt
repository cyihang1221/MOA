========== reproducibility_recipe entry ==========
paper_title: Knowledge and data-driven two-layer networking for accurate metabolite annotation in untargeted metabolomics.
source_paper: Zhang H et al. (2025), Nature communications, DOI: 10.1038/s41467-025-63536-6, PMID: 40885726
overall_reproducibility_score: 82/100

workflow_steps: 6
  Step 1: Raw data conversion
    tool: ProteoWizard MSConvert (v3.0.20360 (Orbitrap) / 3.0.24214 (Astral))
    algorithm: file format conversion
    parameters: input_format=.raw, output_formats=['.mzXML', '.mgf']
    input: raw .raw files
    output: .mzXML (MS1) and .mgf (MS2) files
    confidence: high
  Step 2: Feature detection and alignment (Orbitrap datasets)
    tool: XCMS (v3.12.0)
    algorithm: centWave
    parameters: ppm=10, snthr=3, peakwidth=[5, 30], minfrac=0.5
    input: .mzXML files
    output: feature table (peak matrix)
    confidence: high
  Step 3: Feature detection and alignment (Astral datasets)
    tool: Met4DX (v2.2.0)
    algorithm: centWave
    parameters: peakwidth_min=5, peakwidth_max=30, snthr=6, minfrac=0.5
    input: .mzXML files
    output: feature table (peak matrix)
    confidence: high
  Step 4: Metabolite annotation via two-layer networking
    tool: MetDNA3 (v3.1)
    algorithm: knowledge- and data-driven two-layer interactive networking
    parameters: lc_mode=['HILIC', 'RP'], collision_energy_setting=SNCE_20_30_40%, ion_mode=['ESI+', 'ESI-']
    input: feature table + .mgf MS2 spectra
    output: annotated metabolite table with confidence levels (seed vs. propagated)
    confidence: high
  Step 5: Knowledge-based metabolic reaction network (MRN) curation
    tool: Custom GNN pipeline + BioTransformer + RDKit (vBioTransformer 3.0; RDKit unspecified)
    algorithm: GNN-based reaction relationship prediction + Δmass prefiltering + structural similarity (Dice ≥ 0.7) filtering
    parameters: inchikey_layer=1, elemental_composition=['C', 'H', 'O', 'N', 'P', 'S'], delta_mass_filtering=True, structural_overlap_coefficient_threshold=0.7, dice_similarity_threshold=0.7
    input: KEGG (2023-09-11), MetaCyc (2023-09-16), HMDB (2023-09-09) databases
    output: Curated MRN: 47,748 metabolites × 1,447,443 reaction pairs
    confidence: medium
  Step 6: Network expansion with in-silico metabolites
    tool: BioTransformer (v3.0)
    algorithm: biotransformation prediction
    parameters: database=BioTransformer default biotransformation rules, stereoisomer_removal=InChIKey layer 1, elemental_restriction=CHONPS
    input: Known metabolites from MRN
    output: Expanded MRN with predicted unknown metabolites and associated reaction pairs
    confidence: medium
