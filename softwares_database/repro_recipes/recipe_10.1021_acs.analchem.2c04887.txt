========== reproducibility_recipe entry ==========
paper_title: Mechanistic Understanding of the Discrepancies between Common Peak Picking Algorithms in Liquid Chromatography-Mass Spectrometry-Based Metabolomics.
source_paper: Guo J et al. (2023), Analytical chemistry, DOI: 10.1021/acs.analchem.2c04887, PMID: 36972195
overall_reproducibility_score: 82/100

workflow_steps: 10
  Step 1: Data collection and curation
    tool: public repositories
    parameters: n_datasets=10, diversity_criteria=['various LC-MS analytical conditions']
    input: raw vendor files (e.g., .raw, .d, .wiff)
    output: curated set of 10 public LC-MS metabolomics datasets
    confidence: medium
  Step 2: Optimal parameter tuning for each peak picking algorithm
    tool: XCMS
    algorithm: CentWave
    parameters: mass_ppm=5, peak_width=[10, 60], snthresh=10, prefilter=[3, 100]
    input: raw vendor files
    output: optimized CentWave parameters per dataset
    confidence: high
  Step 3: Peak picking using five algorithms
    tool: MS-DIAL
    algorithm: linear-weighted moving average
    parameters: smoothing_level=default, min_peak_height=1000, min_snr=10
    input: raw vendor files
    output: feature tables (one per algorithm)
    confidence: medium
  Step 4: Peak picking using five algorithms
    tool: MZmine 2
    algorithm: ADAP
    parameters: noise_threshold=1000, minimum_height=10000, min_time_span=5
    input: raw vendor files
    output: feature tables (one per algorithm)
    confidence: medium
  Step 5: Peak picking using five algorithms
    tool: El-MAVEN
    algorithm: Savitzky-Golay
    parameters: window_length=11, polynomial_order=2, deriv_order=0
    input: raw vendor files
    output: feature tables (one per algorithm)
    confidence: medium
  Step 6: Peak picking using five algorithms
    tool: OpenMS
    algorithm: FeatureFinderMetabo
    parameters: mass_trace_mz_tolerance=0.01, intensity_threshold=1000, chromatographic_peak_snr=5
    input: raw vendor files
    output: feature tables (one per algorithm)
    confidence: medium
  Step 7: False feature filtering based on chromatographic peak shape
    tool: custom R program
    algorithm: chromatographic quality scoring
    parameters: peak_shape_thresholds={'asymmetry': 0.8, 'asymmetry_upper': 1.2}, baseline_ratio=0.1, r2_fit=0.95
    input: feature tables + extracted ion chromatograms
    output: filtered feature tables (removing poor-shape features)
    confidence: low
  Step 8: True feature identification and undetected peak evaluation
    tool: custom R program
    algorithm: reference-based truth set matching
    parameters: reference_database=HMDB + in-house standards, rt_tolerance_sec=5, mz_tolerance_ppm=5
    input: feature tables + reference standard runs
    output: true/undetected/false feature classification per algorithm
    confidence: medium
  Step 9: Quantification of six peak attributes
    tool: custom R program
    algorithm: peak attribute measurement
    parameters: attributes=['ideal_slope', 'sharpness', 'peak_height', 'mass_deviation_ppm', 'peak_width_sec', 'scan_number']
    input: true and undetected features (aligned to reference standards)
    output: attribute matrix (features × 6 attributes)
    confidence: high
  Step 10: Statistical analysis of attribute–algorithm relationships
    tool: R
    algorithm: principal component analysis (PCA)
    parameters: center=True, scale=True, n_components=2
    input: attribute matrix
    output: PCA biplot coordinates and loadings
    confidence: high
