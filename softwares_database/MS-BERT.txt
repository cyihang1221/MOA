========== sample_description&software_configuration_description entry ==========
sample_description: The study is a computational/tool development paper on MS/MS spectral analysis. It used publicly available tandem mass spectrometry (MS/MS) spectral datasets: the GNPS dataset (training and testing), the MoNA dataset, and the MTBLS1572 dataset (testing). No biological samples were collected; the input is MS/MS spectra from LC-MS experiments requiring compound identification. Evaluation used a GNPS test subset with structures not in the training set (recall@1/5/10 = 0.7871/0.8950/0.9080), compared against Spec2Vec and DreaMS, with embedding rationality demonstrated via t-SNE visualization, structural similarity, spectra clustering, compound identification, and analogous compound searching.
software_configuration_description: MSBERT embeds MS/MS spectra into chemically rational embedding space. It adopts a Transformer encoder as the backbone with mask learning (mask_ratio 0.1) and uses the same spectra with different masks for contrastive learning (self-supervised). Model is trained on the GNPS data set. Downstream usage: library matching via cosine similarity search in embedding space (top_k 10); analogous compound searching via k-nearest neighbors in embedding space plus Tanimoto similarity on RDKit fingerprints; embedding evaluation via t-SNE (perplexity 30, n_iter 1000). A user-friendly web server is provided, and source code is available at https://github.com/zhanghailiangcsu/MSBERT. The paper reports recall@1/5/10 of 0.7871/0.8950/0.9080 on the GNPS test subset, outperforming Spec2Vec and DreaMS.
source_paper: H et al. (2024), Analytical chemistry, DOI: 10.1021/acs.analchem.4c02426, PMID: 39397717
