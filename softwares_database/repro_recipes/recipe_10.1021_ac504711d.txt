paper_title: Ion Trace Detection Algorithm to Extract Pure Ion Chromatograms to Improve Untargeted Peak Detection Quality for Liquid Chromatography/Time-of-Flight Mass Spectrometry-Based Metabolomics Data
source_paper: Wang SY et al. (2015), Analytical Chemistry, DOI: 10.1021/ac504711d, PMID: 25622715
overall_reproducibility_score: 42/100

workflow_steps: 4
  Step 1: Relative mass difference tolerance estimation
    tool: PITracer
    algorithm: Gaussian kernel density estimation with intensity-weighted adaptive tolerance
    parameters: mass_tolerance_ppm=10, intensity_ratio_threshold=0.6745, saturation_intensity_reference=Isaturated, default_retention_time_merge_window_s=1.0, minimum_trace_length_scans=None, density_threshold_method=mean_density_plus_std
    input: raw .mzXML or .mzML files (centroid mode)
    output: estimated relative mass difference tolerance (δ̂i,j) per ion
    confidence: high
  Step 2: Optional m/z calibration using reference ion
    tool: PITracer
    algorithm: base ion–driven m/z recalibration
    parameters: calibration_enabled=optional, reference_ion_selection=most abundant base ion
    input: raw LC/TOF-MS profile (mzXML/mzML)
    output: calibrated m/z values
    confidence: medium
  Step 3: Pure ion trace detection
    tool: PITracer
    algorithm: graph-based ion tracking with edge selection and trace merging
    parameters: edge_connection_condition=|(m/z′)i,j − (m/z′)i−1,k| / (m/z′)i,j ≤ max(δ̂i,j, δi,b) / 1e6, trace_merging_mz_tolerance=same as δ̂overall, trace_merging_rt_window_s=1.0, minimum_trace_length_scans=None
    input: calibrated (or raw) m/z-intensity matrix
    output: pure ion chromatograms (one per trace ID)
    confidence: high
  Step 4: Chromatographic peak detection on pure ion chromatograms
    tool: TIPick
    algorithm: recursive peak detection using scoring function
    parameters: peak_detection_algorithm=TIPick scoring function, mass_correction_enabled=optional (user-specified metabolite)
    input: pure ion chromatograms
    output: detected peaks (m/z, RT, intensity, peak boundaries)
    confidence: medium
