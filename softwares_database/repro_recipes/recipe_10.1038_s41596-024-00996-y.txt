========== reproducibility_recipe entry ==========
paper_title: Reproducible mass spectrometry data processing and compound annotation in MZmine 3.
source_paper: Heuckeroth S et al. (2024), Nature protocols, DOI: 10.1038/s41596-024-00996-y, PMID: 38769143
overall_reproducibility_score: 87/100

workflow_steps: 7
  Step 1: Raw data import
    tool: MZmine 3 (v3.4.0 or later (implied by 'third version'))
    algorithm: Native vendor file parser
    input: raw instrument files (.raw, .d, .mzML, .cdf, etc.)
    output: imported project with raw scans
    confidence: medium
  Step 2: Chromatogram building / feature detection
    tool: MZmine 3 (v3.4.0 or later)
    algorithm: Local minimum resolver
    parameters: min_time_span_sec=5, min_height=10000, mz_tolerance_ppm=10, noise_level=5000, search_radius_rt_sec=5, min_peak_width_rt_sec=0.1, max_peak_width_rt_sec=30
    input: raw scans
    output: feature list (peak table)
    confidence: high
  Step 3: Retention time alignment
    tool: MZmine 3 (v3.4.0 or later)
    algorithm: Join aligner
    parameters: mz_tolerance_ppm=10, rt_tolerance_sec=30, weight_for_mz=1, weight_for_rt=1
    input: feature lists from multiple samples
    output: aligned feature table
    confidence: high
  Step 4: Gap filling
    tool: MZmine 3 (v3.4.0 or later)
    algorithm: Fill peaks
    parameters: mz_tolerance_ppm=10, rt_tolerance_sec=30, min_peak_height_ratio=0.01, min_peak_area_ratio=0.01
    input: aligned feature table
    output: gap-filled feature table
    confidence: high
  Step 5: Feature filtering
    tool: MZmine 3 (v3.4.0 or later)
    algorithm: Row filter
    parameters: min_samples=2, min_fraction_in_any_group=0.5, min_intensity=10000
    input: gap-filled feature table
    output: filtered feature table
    confidence: high
  Step 6: MS/MS spectral processing and annotation
    tool: MZmine 3 (v3.4.0 or later)
    algorithm: Spectral library search (e.g., GNPS, MassBank, MoNA)
    parameters: mass_tolerance_ppm=5, min_matched_peaks=3, min_relative_intensity_percent=1, library_score_threshold=0.3
    input: MS2 spectra linked to features
    output: annotated MS2 spectral list with compound IDs
    confidence: medium
  Step 7: Ion mobility data processing (for LC-IMS-MS and IMS-MS imaging)
    tool: MZmine 3 (v3.4.0 or later)
    algorithm: IMS drift time calibration and mobility-aligned feature detection
    parameters: mobility_resolution=20, drift_time_tolerance_ms=2, mobility_trend_correction=True
    input: IMS-enabled raw files (.imzML, .d, vendor IMS formats)
    output: mobility-resolved feature table and 3D (RT–m/z–mobility) features
    confidence: medium
